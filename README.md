# graphploter

公開ページ: https://miasf.github.io/graphploter/

ブラウザで動く 3D グラフソフト。目標は「Desmos くらい使いやすく、多次元の媒介変数表示・陰関数・特殊関数・複素数を 3 次元空間に自由に描ける」こと。

現在できること:

- 陽関数の曲面 `z = f(x, y)`（`y = f(x, z)`、`x = f(y, z)` も可）
  - 形が急に変わる所（極の近く、定義域の縁、表示範囲の上下の端を横切る急な斜面）だけ、三角形を二分して細かくする（6 回まで。
    `core/src/adaptive.rs`）。最も新しい頂点の向かいの辺を二分する方式なので、継ぎ目に隙間ができない。
    `1/sqrt(1 - x^2 - y^2)` の縁や `abs(gamma(x + i y))` の細い極もなめらかに描ける。なめらかな曲面は一様な格子のまま。
    スライダー・回転の再生中は細かくしない（止まったら細かく計算し直す）
  - 格子の点がたまたま乗らないと見えない、格子より細い山・谷・極（`5 exp(-2000((x-1.23)^2 + (y-0.77)^2))` など）も探して細かくする。
    初等関数の式では、区間演算で格子の小さいブロック（細かさ 150 なら 2 × 2 マス）ごとに値の範囲を求め、格子の点の値から
    考えられないほど広ければ、箱を四つに分けて調べ直す（1 マスの 1/32 まで）。格子の値の補間から離れた点が見つかれば、
    そこを含む三角形は必ず細かくする（その所だけ 16 回まで）。特殊関数・複素数の色分けの式では、マスの中心と辺の中点を調べるだけなので
    （格子の計算が 3 ms 以上の重い式では調べない）、見落としがあり得る
  - 表示範囲の上端・下端と、定義域の縁で、三角形を切ってから描く。交わる点は実際の関数で二分法で求めるので、
    急な斜面が表示範囲の端を横切る所（`1/sqrt(1 - x^2 - y^2)` の上端の円など）も、格子の細かさに関係なくなめらかな縁になる。
    頂点の一部だけが定義される三角形も、定義される部分を描く（捨てると、定義域の縁の近くに穴が空く）
  - 値が飛ぶ所（`floor` の段差、`tan` の極など）では三角形を切り分けて、段差の縁をまっすぐにする。
    高さの差が大きい格子の辺を二分法で 12 回狭め、差がほとんど縮まらなければ「飛んでいる」とみなす。
    表示範囲の高さの 0.5% より大きい段差を切り分ける（再生・ドラッグ中は 3%）。
    段差の線が交わる所・終わる所は、そこだけ細かくする（針のような三角形が立たない）。
    差の大きい段差（極かもしれない所）は、さらに二分して極のすぐそばまで狭める（細い極でも、壁が上下の端まで届く）。
    細い極の線（`nCr(x, y)` の x = −1, −2, … など）は、格子の辺の上で位置を探して切り分け、線に沿って隣の辺をたどる（細分で追いかけない）
    ⚙ の「値が飛ぶ所に壁を描く」で、段差の上下の縁を結ぶ縦の壁も描ける
- 陰関数の曲面 `F(x, y, z) = G(x, y, z)`（例: `x^2 + y^2 + z^2 = 4`）
  - 1つの小さな立方体（セル）を2枚以上の曲面が通るとき（近い曲面どうし）は、曲面ごとに頂点を分けるのでくっつかない。
    角のうち少ないほうの符号の角を、セルの辺でつながっているものどうしで組に分け、組ごとに頂点を1つ置く
  - 面が自分と交わる線・尖った点（ローマ曲面 `x^2 y^2 + y^2 z^2 + z^2 x^2 = x y z` の座標軸、ケーリーの 3 次曲面 `x^2 + y^2 + z^2 + 2xyz = 1` の 4 点、
    円錐の先）は、X の字・円錐の先のまま描く。1 セルに頂点 1 つの作り方では交わりが丸まって消えるので、∇F = 0 でヘッセ行列が鞍の形の点を
    ニュートン法で求め、その周りの三角形を作り直す（`mesh/singular.rs`）。交わる角度が 0 になる所（ローマ曲面のピンチ点）は、まだ 1〜2 マス欠ける
  - F が飛ぶ所（`tan(x) = z` の極 x = π/2 など、F が +∞ から −∞ へ飛ぶ所や、`floor` の段差）には面を張らない。
    符号の変わる辺を二分して、|F| が縮まなければ零点ではないとみなす（2D 表示の陰関数の曲線も同じ）。
    隣の辺と傾きがそろっている辺は、なめらかに 0 を横切っているだけなので調べない
  - 極のすぐ隣を走る面（`1/(x y) = z` の壁、`tan(x) = z y` の極の両側）も描く。極の近くのセル（零点でない辺や、定義されない角を持つセル）
    だけ、辺を 32 等分して零点を数え直し、零点がちょうど 1 つの辺に面を張る（極と零点が 1 つずつ入った辺は、両端の符号がそろうので、
    ふつうは見落とす）。極に近すぎる部分（辺の 1/32 より薄い所）は描けない。1 つのセルの中で、極をはさんで両側に零点がある所も頂点は 1 つ
  - 定義されない所との境目（`sqrt(36 - x^2 - y^2) - z = 0` の円、`ln(x) + ln(y) + ln(z) = 1` の x = 0 など）は、縁まで延ばしてから切り落とす。
    定義されない格子点を、隣の定義される点から縁に近づいたときの値で 1 層埋め（斜めの縁で穴が空かないよう、2 層目には隣の値を写す）、
    縁をまたぐ辺に本当の零点があれば二分で求める。できた面のうち定義されない所に出た部分は、三角形の辺の上で縁を二分して切り落とす。
    1 層だけ定義されない所（`1/(x y)` の x = 0 のような極）は埋めない
  - `floor`・`mod`・`round`・`ceil`・`sign` を含む式の段差は、段の番号（枝の番号）が同じ領域ごとに、段の番号を固定した
    なめらかな式で面を作り、段差の所で切り取る（面が段差で終わる縁がまっすぐになる）。段差をまたぐセルだけをこの方法で作り、
    ほかのセルはふつうに作る。面の間隔が格子より狭くなる所（`mod(x y, z) = 1` の z = 1 の近くなど）は描けない
  - 極・値が飛ぶ所・定義域の縁の近くにできる小さな破片（三角形 12 個以下・2 マス以下の成分で、零点ではない辺や定義されない角のあるセルにあるもの、
    または閉じていないもの）は消す。本当に小さい閉じた図形（小さい球）は残す。`mod(x y, z) = 1` のように面が格子より細かく詰まった所は、
    破片を消すとそこが空になるので、1,000 個より多く消したら式の説明に「（細かすぎて描けない部分あり）」と出す
  - 三角形が 150 万個を超える式（細かさ 200 の `mod(x y z, 4) = 2` など）は、F の格子を 2 個・4 個おきに間引いた版を本体にして、
    式の説明に「（粗くして表示）」と出す（画面が固まらないように）
  - 符号が変わらずに 0 に接するだけの式（例: `(x^2 + y^2 + z^2 - 4)^2 = 0`）も描ける。格子の線に沿って |F| が
    減ってから増える所を三分探索で調べ、極小がほぼ 0 なら曲面が通るとみなす。三角形の向きは、隣どうしでそろえてから
    重心から見て外向きにする
  - 面にならず、線・点だけになると式の形から分かる式（0 以上の項の和 = 0。例: `(x^2 + y^2 - 4)^2 + z^2 = 0` の円、
    `x^2 + y^2 + z^2 = 0` の原点）は、$A^2 + B^2 = 0 \iff A = B = 0$ として、交わる線・点で描く。$A = 0$ の面の上で $B$ の値 0 の線を
    取り出し、ニュートン法で 2 つの面の上へ寄せる（寄らない点、`tan` の極などは捨てる）。項が 3 つ以上なら、はじめの 2 つの線の上で
    3 つ目の符号が変わる所から点を求める（`core/src/system.rs`）。面になる因数と混ざる式（`(x^2 + y^2)(z - 1) = 0`）の線・点は、まだ描かない。
    2D 表示では、今までどおり陰関数の曲線として描く
  - 複素数の陰関数（`e^(i x) = y + i z` のらせん、`(x + i y)^2 - z = 0` の放物線 2 本）: 値が複素数の F = 0 は、Re F = 0 と Im F = 0 の交わる線として描く
    （連立方程式の曲線と同じ道）。式に i（または複素数のパラメータ）があり、表示範囲の中の点の 2 割以上で F が実数にならないときだけ。
    `|x + i y| = z^2 + 1` のように値が実数の式、`sqrt(x)` のように i を含まない式は、ふつうの陰関数のまま。
    片側が座標 1 つの式（`z = (x + i y)^2`）は、今までどおり陽関数（複素数の色分け）。2D 表示では交点を点で描く
    - ⚙ の「複素数の色分け」で、曲面にして色を付けることもできる: |F| = 1 の曲面（色は arg F）、Re F = 0 の曲面、Im F = 0 の曲面。
      色は陽関数の色分けと同じ（色相が偏角、|F| が 2 倍になるごとに明るさの縞）。Re F = Im F = 0 の線は、縞が集まる所に見える
    - 座標を複素数にする（式の ⚙ のチェック）: 式の x, y, z を x + i w, y + i w₂, z + i w₃ に置き換えて描く（次元は 6 にする）。
      `x^2 + y^2 + z^2 = 1` のまま、座標が複素数の図形（実数で 4 次元）の断面を見られる。x, y, z を表示すれば実数の部分（球面）。
      書き換えた式を手で書いても同じ（`(x + i w)^2 + (y + i w_2)^2 + (z + i w_3)^2 = 1`）。表示する座標を (x, w, y) にして、z を「等値面を何枚も」で動かすと、
      w = 0 の面の円と x = 0 の面の双曲線の族になる
  - 連立方程式の曲線（等式 2 本）: 1 本目の式の曲面の上で 2 本目の式の線を取り出し、ニュートン法で 2 つの曲面の上へ寄せる。
    寄らない点（`tan` の極など）は捨てる。線が自分と交わる点は、格子の半マスほど丸まる。1 点で接するだけの交わりは描かれない
  - 等式に不等式を足すと、その条件を満たす部分だけを描く（`x^2 + y^2 + z^2 = 4, z ≥ 0` → 半球）。等式の行を今までの道
    （陽関数・陰関数・回した陽関数）で描いてから、三角形・線分を切る。境目は辺の上で、はさみうち法で求める（`system::trim_mesh`・`clip_segments`）
  - 不等式の領域（`x ≤ y ≤ z`・`abs(x) ≤ 2, abs(y) ≤ 2, abs(z) ≤ 2`）: 境目の面 $G_i = 0$ ごとに陰関数の道で作り、ほかの不等式で切り取るので、角が立つ。
    表示範囲の端と切り口には、ふたをする（ふたは色が薄く、格子線が無いので、式の境目と見分けられる）。最初は半透明（不透明度 0.45）。
    `<` と `≤` は 3D では同じ絵。$G$ が飛ぶ面・定義されなくなる面（`1/x ≤ z` の $x = 0$）は描かれない
  - 連立方程式の点（等式 3 本）: 2 本の交わる線の上で 3 本目の式の符号が変わる所を探し、3 本の式のニュートン法で寄せる。丸で描く
  - 格子より小さい図形（小さい球、細い輪・管）も描く。疑わしい所（1 辺 8 マスのブロック）を探し、その所だけ 2 倍・4 倍の細かさで
    作り直して差し替える。疑わしい所は、(a) 区間演算が使える式では「曲面があるかもしれない」のに頂点が無いブロック
    （箱を 8 等分して 3 段まで調べ直し、どこも 0 を含まなくなれば外す）、(b) 使えない式では、周りの符号が全部同じなのに
    |F| < 0.87 |∇F| h になる格子点のあるブロック、(c) 隣の頂点どうしの法線が 35° 以上ずれる、角ばった所。
    作り直す範囲の外側の面を曲面が横切らないことを確かめてから差し替えるので、継ぎ目にひびはできない。
    区間演算が使えない式（特殊関数・虚数を使う式）では見落としがあり得る。区間演算が使える式でも、大きい曲面のすぐそばの小さい図形は
    見落とし得る。大きい曲面につながった細い部分（円錐の先、細い首）は、隣どうしの頂点の法線が 35° を超えてずれる所のブロックだけを
    2 倍の細かさの格子で作り直す。面は「符号の変わる、一番細かい辺」ごとに、その辺を囲むセル（細かさが違ってよい）の頂点を結ぶので、
    細かさの境目にひびができない。ただし、極・値が飛ぶ所・定義域の縁・接する所・近い曲面・段差のある式では行わない（それらの処理と両立しないため）。
    小さい図形（囲む箱が元の格子で 40 マスより小さい成分）は、元の格子の倍率ではなく、図形を囲む箱のいちばん長い辺を 40 マスに分けた
    格子で作り直す。囲む箱は区間演算で 8 等分を繰り返して狭め（使えない式では頂点から決め）、作った形が箱よりずっと小さければ形に合わせて
    作り直す。曲面が箱からはみ出せば箱を広げ、箱が成分の外の曲面にかかれば諦める。なので半径 0.0001 の球も 1 の球も同じ細かさになり、
    スライダーで半径を動かしても、境目（40 マス）で急に粗くならない。
    再生・ドラッグ中も、この小さい図形の作り直しだけは軽い版（24 マス）で行う（大きい曲面の角ばった所は止まってから）。
    範囲で重ねた立体は作り直さない。⚙ の「陰関数の細かい図形を念入りに探す（遅くなる）」で、探す手間と細かさ（8 倍まで、小さい図形は 64 マス）の上限を上げる
- 媒介変数表示の曲線 `(x(t), y(t), z(t))` と曲面 `(x(u,v), y(u,v), z(u,v))`、立体 `(x(u,v,t), y(u,v,t), z(u,v,t))`。範囲は `2pi` のような式でも書ける
  - 曲面でも、値が飛ぶ所（`floor` の段差、`tan` の極）で面を切る（段と段・極の両側を結ぶ偽の面を描かない）。
    細かくした後の辺のうち、両端の点が離れているものを (u, v) の上で二分し、離れたまま縮まなければ飛んでいるとみなす。
    極の先の点は、表示範囲の対角線の 2 倍の所にそろえる。陽関数と同じく、段差の線が終わる・交わる所だけ細かくする
  - 立体（媒介変数3つ。u, v, t か t₁, t₂, t₃）は、媒介変数の範囲の直方体の6つの面の像を描く。面は外向きになるよう、
    囲まれた体積の符号を見て向きをそろえる。曲面をパラメータの「範囲で重ねる」と、これも立体になる
  - **多変数（媒介変数が4つ以上）**: `(x(t₁, …, t₄), y(t₁, …, t₄), …)` のように、媒介変数 t₁, t₂, … を8個まで使える。
    4つ以上の図形は3次元の画面に中身をそのまま描けないので、媒介変数を2つだけ動かした面（残りは固定）をたくさん描いて表す。
    固定する値が範囲の両端だけなら、媒介変数の範囲の「k 次元の直方体」の2次元の面の像になる
    （k 個なら kC2 · 2^(k−2) 枚。`(t₁, t₂, t₃, t₄)` は4次元の立方体の面 24 枚、5個なら 80 枚）。
    ⚙ の「中の面」を増やすと、範囲を等分した途中の値に固定した面（中を通る面）も描く。
    ⚙ の「辺だけ描く」（媒介変数が3つ以上の式）では、媒介変数を1つだけ動かし残りを範囲の両端に固定した線
    （範囲の直方体の辺の像。k 個なら k · 2^(k−1) 本、`(t₁, t₂, t₃, t₄)` なら正八胞体の辺 32 本）だけを描く
    面が増えるほど1枚を粗くして、頂点の数の合計をおよそ一定（6 × 細かさ²）に保つ
  - 曲線は曲がっている所だけ細かく計算する（適応サンプリング）。値が飛ぶ所では線を切る
  - 曲面（媒介変数2つ）も、急に曲がる所・定義域の縁だけ三角形を二分して細かくする（陽関数と同じ `core/src/adaptive.rs`。
    n 次元の点のずれが表示範囲の対角線の 10⁻³ 倍を超える所。回転・射影してもこの許容量に収まるので、回転の再生では計算し直さない）。
    立体（媒介変数3つ）・多変数の図形は一様な格子のまま
  - 曲面の格子線は u, v に沿って引ける（範囲を何等分するかをスライダーで選ぶ）
  - 入力欄では成分を x =, y =, z =, w =, w₂ = … の縦に並べて編集できる（「1行で編集」で元に戻せる）。
    「＋ w₂ 成分を追加」で次の座標の成分を足せる（次元が足りなければ自動で増やす）
- 数式の見た目のまま入力できる欄と、スマホ用の数式キーボード（括弧の自動補完、pi → π などの自動変換つき）
  - 文字の後ろに数字を打つと添字になる（`w2` → w₂、`t10` → t₁₀、`a1` → a₁）。添字の後ろで ⌫ を押すと、添字の数字を1つ消す。
    定数の e と i、名前に数字がある関数（`hyp2F1`、`hankelH1`）の途中では添字にしない
  - 開き括弧の直後で ⌫ を押すと、括弧の組を外して中身を残す。括弧の前が関数名なら関数名も消す（`sin(x)` → `x`。Desmos と同じ）
  - 日本語（JIS）配列のキーボードでも、記号（`]`、`*` など）は US 配列と同じように入る（MathLive はキーの位置を US 配列として読むので、打った文字に合わせて渡し直している）
  - 数式キーボードの「変数」のタブに、今の次元で使える座標（x, y, z, w, w₂, …）と媒介変数（t, u, v, t₁〜t₈）が並ぶ。
    4次元目以降の座標の名前を覚えていなくても入れられる
  - 次元が足りない式（成分が多い・`w₂` を使ったなど）のエラーには「次元を 5 にする」ボタンが出る
  - キーにカーソルを 0.6 秒当てる（スマホでは 0.45 秒長押しする）と、キーの名前（特殊関数なら日本語名と書き方）が出る。長押しで名前を出したときは、指を離してもそのキーを入力しない
  - 数式キーボードの「abc」タブに、文字（abc・ABC）と、LaTeX で書ける数学記号（MathLive で表示できるもの全部。ギリシャ文字・黒板太字などの書体・等号と不等号・演算・集合と論理・矢印・和と積分・括弧・アクセント・図形など）が 36 ページに並ぶ。◀ ▶ でめくり、真ん中のページ名を押すと分類の目次が出る。計算エンジンが読めない記号は「… はまだ使えません」と出る
  - よく使う記号（< > ≤ ≥ ≠ ≈ ± ∞ θ φ）は、abc の文字のページと 123 タブの一番上の段にもある

- 4 次元以上: 座標は x, y, z, w（= w₁）, w₂, w₃, …（4 次元目が w、5 次元目が w₂。w₁ と書くと w と同じ）
  - 画面の横・奥・縦に表示する3つの座標を選び、残りの座標はスライダーで値を固定した断面を描く
  - 媒介変数表示 (x, y, z, w, …) は、表示する3つの座標の成分を描く（射影）
- 表示していない座標の見せ方（式ごと。⚙ の「w の見せ方」）: 表示していない座標（w 以降）を使う式は、次から選べる。
  断面以外では、式の下に、その座標の範囲の欄が出る（最初は断面のスライダーの範囲。パラメータも使える）
  - 断面（今まで）: スライダーの値 1 つでの図形。⚙ の「w の値をこの式だけで決める」で、式の下にこの式だけの w のスライダーを出せる（× で次元の設定の値に戻す）
  - 見せ方を切り替えると、面の濃さをその見せ方の既定値にする（等値面 35%・断面の塗り分け 60%・伝達関数 100%・範囲で重ねる 45%。自分で動かした値は変えない）
  - 範囲の欄は、1 つ目の座標だけ断面のスライダーの範囲にし、ほかは今の断面の値に固定して用意する（動かしたい座標だけ範囲を広げる）
  - 等値面を何枚も: 範囲を等分した値ごとの図形を重ね、値で色を付ける（曲線も色分けする）。座標が 2 つ以上なら全部の組み合わせ（64 枚まで。色は 1 つ目の座標）
  - 断面の塗り分け: 表示範囲の中の平面（各軸に等間隔）を、w = f の値で塗る
  - 伝達関数: w = f の値に色と不透明度を割り当て、表示範囲の箱の中で視線を少しずつ（格子の 1 辺の点の数の 1.5 倍の歩数）進めて重ね塗りする（ボリュームレンダリング）。面の濃さが全体の不透明度になる。
    不透明度は「一様・値が大きいほど濃い・小さいほど濃い・何枚かの値の所だけ濃い（等値面風）」から選び、濃さはスライダー。範囲の外の値は描かない。
    視点が箱の中に入ると描かれない
  - 伝達関数の重ね方: 手前から重ね塗り（今まで）・視線上の最大値（最大値投影）・最小値・平均値。最大値などでは視線ごとに 1 つの値の色を出し、
    不透明度はその値での不透明度の形（最大 1 にそろえて 1.5 乗）× 濃さの 2 倍（最大値は大きめの値になりやすく、ゆるく上げると箱全体が塗りつぶされるため）
  - 不透明度の「0 の近くだけ濃い（ぼやけた面）」: 値 0 の面からの距離を |v| / |∇v|（勾配は格子の差分）で見積もり、格子の何マスかの幅でぼかす。
    値の大きさで幅を決めないので、式の大きさによらず同じ厚み。陰影を切っても、視線の向きからの光で陰を付ける（付けないと面の向きが分からず円盤に見える）
  - 勾配で陰影を付ける（⚙ のチェック。重ね塗りのとき。既定で付ける）: 値の勾配（格子の 1 マスの中心差分）を面の法線とみなし、視点の少し右上からの光を当てる
    （拡散 + 鏡面。裏表は区別しない）。暗い側の下限は元の色の 55%、光に向いた所は少し明るく（下限を低くすると、重なった面の多くが横向きなので全体が暗くくすむ）。
    格子の 1 マスで値の位置がほとんど変わらない所（ほぼ平らな所）は法線があてにならないので、光を弱めて元の色に近づける。
    ほとんど透明な点では計算を省く（勾配にテクスチャを 6 回読むため）
- 値が複素数の伝達関数（w = sin(x + iy) + z・複素数の陰関数の F の値）: 実部・虚部の組を 2 チャンネルのテクスチャにし、色は偏角
  （陽関数の複素数の色分けと同じ色。|f| が 2 倍になるごとに明るさの縞）、不透明度の形は |f| で決める。|f| の範囲は 0 〜 表示範囲の中の |f| の 9 割が入る値
  （外は端として描く）。「何枚かの値の所だけ濃い」は |f| = 2ᵏ の所、「0 の近くだけ濃い」は f = 0 の所（3 次元ではふつう線なので、線のまわりの管）。
  補間は実部・虚部で行う（偏角を補間すると ±π をまたぐ所で崩れる）。最大値・最小値は、その値をとった点の偏角の色、平均値は値の平均の偏角
- 不等式の領域の霧（⚙ の「描き方」。標準は今までどおり境目の面とふた）: G = max G_i（全部の不等式を満たす所が G ≤ 0）を格子で計算し、
  境目までの距離の見積もり G / |∇G| にして返す（計算エンジン側で勾配を求めるので、描画側は 1 回読むだけで中身か・境目に近いかが分かる）。
  中身を式の色で薄く塗り、境目（格子の 1.5 マスの幅）を濃くして、境目の近くだけ勾配で陰影を付ける。歩数は格子の 1 辺の点の数の 2.5 倍（256 まで。
  境目が 1 歩より細いと点々のムラになる）。光線は領域（境目から 3 マスまで）を囲む箱の中だけ進める。
  それでも回している間は境目の面より十数倍重い（ソフトウェア描画で 0.9 fps 対 15 fps）ので、標準にはしていない
- 伝達関数の歩幅は、格子の箱のいちばん長い辺 / 歩数でそろえる（箱の真ん中を通る光線は今までどおりの歩数。短い光線・縮めた箱では歩数が減る）
- 陰関数の F の値の伝達関数（⚙ の「描き方」。表示していない座標を使う陰関数では「w の見せ方」の選択肢）: 陰関数 F(x, y, z) = 0 の F（左辺 − 右辺）の値を
  格子で計算し、伝達関数と同じ描き方で塗る。色の範囲は、表示範囲の中の |F| の 9 割が入る値 q での −q 〜 q（外の値は端の色）。
  切り替えると「0 の近くだけ濃い」・式の色の明暗になる。表示していない座標は断面の値（次元の設定の「範囲で重ねる」より優先）
  - 範囲で重ねる: 次元の設定の「範囲で重ねる」と同じ立体を、この式だけの範囲で描く（何等分して調べるかは ⚙ の「範囲で重ねる枚数」）
  - 断面以外を選ぶと、その式が使う座標については、次元の設定の「範囲で重ねる」より式の設定が優先される（重ねたまま等値面を何枚も作ると、同じ立体が重なるだけだったため）
  - 断面の塗り分けと伝達関数は、`w = f(x, y, z)` の形（表示していない座標 = その座標を使わない式）のときだけ。その座標が絡む回転をしているときは使えない
  - 色の対応表は viridis・turbo・式の色の明暗から選ぶ（計算し直さない）。2D 表示では断面のまま
    （式の色の明暗は OKLab で明るさだけを動かす。色相を保ち、鮮やかさは式の色の明るさの所で最大。線形の色を混ぜると途中が灰色に寄ってくすむため）
- 範囲で重ねる: 表示していない座標を「範囲」にするか、パラメータの「範囲で重ねる」を押すと、
  その範囲で動かしたときに図形が通る領域を描く（曲面 → 立体、曲線 → 曲面）
  - 立体は G(p) = max(min F, −max F) ≤ 0 の領域の境界面（F を範囲の各点で計算して最小・最大をとる）
  - 範囲の式にまだ定義していない文字があると、次元の設定の欄に「a のスライダーを追加」ボタンが出る。範囲が計算できない間も、パラメータの定義の行（a = 1）は計算する
  - 座標の範囲は式で書ける。パラメータも使えるので、`0 〜 a` にすると a のスライダーで範囲を動かせる
    （両端が逆なら入れ替え、同じ値ならその値での断面にする）
- 回転: 中心 c と、座標の組 (i, j) ごとの角度（n 次元なら nC2 通り、多いときは折りたたむ）で、点を q = R(p − c) + c に動かす
  - 次元が5未満でも、w, w₂ を使った5次元の回転（5C2 = 10 通り）ができる。陰関数・陽関数はその方向にまっすぐ伸びた形、媒介変数表示はその成分が 0 の形として回す
  - 陰関数は、式に p = c + Rᵀ(q − c) を代入して回す（断面が回転で変わるので、式から計算し直す）
  - 陽関数は、回転が表示中の座標どうし（と、式が使っていない座標どうし）だけなら、曲面 (u, v, f(u, v)) をそのまま回せるので、
    媒介変数表示と同じく点を計算してから回す。
    w など表示していない方向が絡む回転でも、断面は「傾いた直交座標系 (u, v, t) の陽関数 t = g(u, v)」になることが多い。
    f が使う座標の向きが表示中の 3 次元の中で張る空間が 2 次元以下で、それに垂直な向きを高さにとれる（面が高さの向きに近すぎない）なら、
    この傾いた座標系の陽関数として描く（回さない陽関数と同じ作り方なので、段差の切り分け・壁・急な所の細分・定義域の縁・複素数の色分けが残る）。
    回転が変わるたびに、表示範囲がちょうど収まる範囲で計算し直す。
    そうならないとき（4 次元の z = f(x, y, w) を zw で回すなど、f が 3 つの独立な向きを使う場合と、面が高さの向きにほぼ平行な場合）と、
    2D 表示の切り口だけは、陰関数として計算し直す。
    点は回さないときと同じ作り方（段差の切り分け・壁・急な所を細かくする）で、回転の中心から表示範囲の角までの距離の範囲で作るので、
    階段の段差も回した後まで途切れたまま残る。広げた範囲でも表示範囲と同じくらいの格子の間隔になるよう、分割数を増やす（2 倍まで）
  - 2D 表示でも回転を反映する。`y = f(x)` は曲線を、`z = f(x, y)` は曲面を作ってから回し、平面に押しつぶす（値で塗り分け）。
    切り口では、縦の座標を使う陽関数は陰関数として計算し直し、式から直接 縦の座標 = 0 の曲線を求める（接するだけの所も描ける）
  - 媒介変数表示は、n 次元の点を一度計算して Worker に覚えておき、回転・表示する軸が変わったときは射影し直すだけ（式を計算し直さない）
- 4 次元の遠近法: 回転した後、表示していない座標 q_h の奥行きに応じて s = Π D / (D − (q_h − c_h)) 倍に縮めて描く（奥ほど小さい）。
  射影で描く図形（媒介変数表示・回した陽関数）に効く。断面（陰関数）には効かない
- 回転の再生: 回転ごとの ▶ ボタンで、角度を回し続ける。⟲ でその回転を 0° に戻す（「回転をリセット」と同じく、再生も止める）。
  その回転で描いているグラフを全部消す・非表示にすると、再生は自動で止まる
- 断面の値（w, w₂ などの「固定」のスライダー）にも ▶（最小値から最大値まで 4 秒で動かし続ける）と ⟲（0 に戻して再生も止める）がある
- スライダーの横の数値（固定した座標の値・回転角・切り口の位置・細かさ・枚数・遠近感・面の濃さ・線の太さ・格子線の間隔など）は、タップ（クリック）するとその場で数式キーボードから値を入力できる（Desmos と同じく、スライダーの範囲の外の値も入れられる。重すぎる値などは上限で止める）
- リスト: `(t, [-1, 1], [-1, 1], [-1, 1])` のように使うと、組み合わせ（直積）の数だけ図形をまとめて描く。
  陽関数・陰関数でも使える（`z = [1, 2, 3] x`、`x^2 + y^2 + z^2 = [1, 4, 9]`）。パラメータの値には使えない
- サンプルの「正八胞体（4次元の立方体）の回転」で、辺 32 本を4次元の遠近法と xw 回転の再生つきで表示する
- **複素平面の図形**: `=` の無い式が座標（x, y, z, …）を使わず、媒介変数（t / u, v / t₁, t₂, …）だけを変数に使っていれば、
  値 f を複素平面の点として描く。複素平面は x 座標 = 実部・y 座標 = 虚部の平面で、ほかの3次元の図形と同じ空間に置く
  （複素平面の「モード」に切り替えるのではない）。2D 表示にすると、そのまま複素平面の図になる
  - `e^{it}` → 単位円、`2e^{it} + e^{-3it}` → 外サイクロイドのような曲線、`[1, 2, 3] e^{it}` → リストで3つの円
  - `(u + iv)^2` → 媒介変数の長方形の像（曲面）。u, v の格子線が等角写像の像になる
  - 縦（z 座標）には「+α」として、⚙ の「縦の軸」で 0（平面の上）・媒介変数 t・|f|・arg f・Re f・Im f を選べる。
    `e^{it}` で縦を t にするとらせん、`Γ(1 + it)` で縦を |Γ| にすると、虚軸に沿った Γ の値の動きと大きさを一緒に見られる。
    中身は媒介変数表示 (Re f, Im f, 縦の値) なので、回転・4次元の射影・範囲で重ねるも、ふつうの曲線・曲面と同じように使える
  - **点**: 座標も媒介変数も使わない式は、i を書いたか、複素数のパラメータ（スライダーを「複素数」にしたもの）を使ったか、
    値が実数でなければ、複素平面の点（丸）として描く（`1 + 2i`、`c`、`c^2`、`1/c`、`[1, 2, 3] + i`）。
    複素平面でドラッグして c を動かすと、c² や 1/c の点も一緒に動く。式の下には点の値（0.28 + 0.96i など）を書く。
    縦の軸も選べる（|c| にすると、高さ |c| の所に浮かぶ）。i も複素数のパラメータも使わない実数の定数（`2`、実数の `a`）は、
    今までどおり平面 z = 2 になる
  - 長さの無い曲線（組 `(1, 2, 3)` の点など）も、丸で描くようにした（以前は見えなかった）
  - 同じ名前のパラメータ（`t = 1` など）が定義されていれば、t はパラメータになる（`e^{it}` は1つの複素数なので点、`2t` は平面）
  - `e^{ix}` のように座標 x を使う式は、今までどおり陽関数 z = f(x, y)（⚙ の「複素数の色分け」で |f| と偏角の色で描ける）。
    値がどこでも実数にならないときは、t を使えば複素平面に描けることを知らせる
- 媒介変数は t（曲線）、u と v（曲面）、u と v と t（立体）、または番号付きの t₁, t₂, t₃, t₄, …（8個まで。番号は飛んでいてもよい）。
  組 (…) の外では t, u, v はパラメータとして使える
- パラメータ: `a = 1` のように書くとスライダーになり、ほかの式で `a` を使える
  - 未定義の文字を使うと「a のスライダーを追加」ボタンが出る
  - 同じ名前を2つの行で定義すると、下の行はエラーになる（上の行を消す・名前を変えると、下の行がスライダーに戻る）
  - 刻み（Desmos の Step）: 決めると、値を最小値から刻みの整数倍の所にそろえる（式やパラメータも使える。空なら自動）
  - ▶ で値を自動で動かす（最小値から最大値まで 4 秒、最後まで行ったら最初から）
  - スライダーの最小値・最大値は式で書ける。ほかのパラメータも使える（`a ≤ c ≤ b`、`0 ≤ c ≤ 2b` など。a, b を動かすと c の範囲も変わる）。
    式の値は画面側で計算する（`web/src/lib/evalExpr.ts`。数値だけなら JS で読み、式なら計算エンジンの WASM を初めて使うときに読み込む）
  - 媒介変数の範囲にもパラメータを使える（0 ≤ t ≤ b の b を再生すると、曲線が伸びていく）
  - 「複素数」モードでは、複素平面の上で点をドラッグして複素数の値を決められる
- 計算はすべて複素数で行う（例: `z = abs(gamma(x + iy))`）
- 複素数の色分け（陽関数の ⚙）: 値 w = f(x, y) が複素数になる関数を、高さ |w|（または Re w, Im w, arg w）と、偏角 arg w の色相で描く。
  |w| が 2 倍になるごとに明るさの縞が1本入る。頂点ごとに (Re w/|w|, Im w/|w|, log₂|w|) を渡し、色相は画素ごとに計算する
  （偏角そのものを補間すると −π と π の境目で色が崩れるため）
  - 極の近くなど、値が表示範囲から大きく外れる所は、範囲の少し外にそろえて描く（頂点を捨てると穴が空くため）
  - 回転しても色分けできる。表示中の座標どうしの回転なら高さ |f|・Re f・Im f の曲面をそのまま回し、色も付ける。
    w などが絡む回転でも、傾いた座標系の陽関数として描けるなら高さ |f| などの曲面に色も付ける。
    陰関数として計算し直すときだけ（上の条件）、z = |f| などの陰関数になり、形だけで色分けはしない
- 特殊関数（すべて複素数で使える。Wolfram/Mathematica にある主なもの）: ガンマ・ベータ・ポリガンマ・不完全ガンマ／ベータ、ゼータ（フルヴィッツ）・多重対数、誤差関数・フレネル積分・指数積分・三角積分、ベッセル J/Y/I/K・ハンケル・球ベッセル・エアリー、直交多項式（ルジャンドル陪関数・エルミート・ラゲール・チェビシェフ・ゲーゲンバウアー・ヤコビ）・球面調和関数、超幾何関数 ₀F₁ ₁F₁ ₂F₁ U、楕円積分 K E F Π・ヤコビの楕円関数、ランベルトの W 関数。一覧はアプリの「書き方のヒント」。数式キーボードの「特殊」タブに全部あり、◀ ▶ でページ（ガンマ・ゼータ/erf・積分・ベッセル・多項式・超幾何/楕円・その他）をめくる
- 座標系（極座標・球座標・自作）: ⚙ 設定 →「座標系」で座標系を作り、式の ⚙ →「座標系」（または設定のチェック）で式ごとに選ぶ
  - 座標系は、座標の値 q = (x, y, z) を空間の点 T(q) へ移す写像。円柱座標（2D 表示では極座標）は T = (x cos y, x sin y, z)、
    球座標は T = (x sin y cos z, x sin y sin z, x cos y)（y が z 軸からの角 θ、z が xy 平面での角 φ）。自作は 3 つの式を自分で書く（パラメータも使える）
  - ほかに用意してある座標系（設定の「＋ 座標系を足す」）: 楕円柱（μ, ν, z。2D 表示では楕円座標）、放物柱（σ, τ, z）、双極（σ, τ, z。アポロニウスの円）、
    対数極（ρ, θ, z。r = e^ρ）、放物線（σ, τ, φ。放物面）、長球（μ, ν, φ。ラグビーボール形）、扁球（μ, ν, φ。みかん形）、トーラス（σ, τ, φ。入れ子のトーラス）、
    ねじれ（高さに比例して xy 平面が回る）。それぞれの式・範囲は設定で書き換えられる
  - 式は x, y, z か、座標系の座標の名前で書く（円柱は r, θ, z、球は r, θ, φ。設定で変えられる。英字 1 文字か θ・φ・ρ・σ・τ・μ・ν）。
    球座標の `r = 2`（`x = 2` と同じ）は半径 2 の球、`(t, t, t)` はらせん。式の説明も `r = f(θ, φ)` のように座標の名前で出す。
    座標の名前は、同じ名前のパラメータより優先する。θ は `theta` と打つか、数式キーボードの「abc」タブで入れる（φ は `phi`、ρ は `rho`、σ は `sigma`、τ は `tau`）。
    μ・ν は数式キーボードから入れる
    曲線は `(t, t, t)` と書く（`(u, u, u)` は u だけでも曲面と読まれ、つぶれた曲面になる）
  - 「移行」のスライダー s（0〜1）で、(1 − s) q + s T(q) を描く。0 は座標の値をそのまま直交座標とみなした絵、1 は座標系で移した絵。
    ▶ で 1 まで動かして止まる（1 にいるときは 0 まで）。計算エンジンは頂点ごとに T(q) を一緒に返すので、s を動かしても式を計算し直さない（法線は混ぜた形から作り直す）
  - 座標系ごとに「作る範囲」（座標の値の範囲。円柱は 0 ≤ r ≤ 5・0 ≤ θ ≤ 2π・−5 ≤ z ≤ 5、球は 0 ≤ r ≤ 5・0 ≤ θ ≤ π・0 ≤ φ ≤ 2π）を持つ。
    図形はこの範囲で作り、範囲の外にはみ出した所は計算エンジンが切り落とす。画面の箱（表示範囲）は今までどおり。r の範囲を負まで広げると、
    r < 0 の所も描く（極座標のバラ曲線 r = cos 2θ の 4 枚の花びら）
  - 回転は座標の値の空間でかかる（移した後の図形は、視点を回して見る）。座標系を使う式には、切り口のふたを作らない。
    伝達関数・霧の見せ方とは一緒に使えない
  - 格子線は座標の値に沿って引く（球座標なら緯線・経線になる）
  - 座標系の格子（座標曲線）: 作る範囲の箱の面（既定は 3 つ目の座標が最小の面。設定で選べる）の上で、座標を 1 つだけ動かした線を 8 等分ごとに引き、
    図形と同じ移行の値で一緒に曲げる。2D 表示の極座標では、方眼が同心円と放射線に変わる。座標系を使う表示中の式があるときだけ描く
- 式の追加・削除・色変更・表示切り替え、表示範囲と細かさの変更
  - 色は、よく使う色と「カスタム」（彩度・明るさの面、色相の帯、16 進の入力）から選ぶ。カスタムは今の色から始まる
    （ブラウザの色選択は、スマホで「カスタム」を開くと今の色から始まらないことがあるので、アプリの中に作った）
- サンプル: 最初は空の式だけ。「サンプル（タップで追加）」から例をタップすると、一覧の最後に追加される（今ある式は消さない）
- 保存・共有: 式と設定はブラウザに自動で保存され、次に開いたときに戻る。「共有リンクをコピー」で、状態を圧縮して URL の # の後ろに入れたリンクを作る

## 描画を軽くする工夫

- 画素密度はスマホでも 2 倍までに抑える
- 視点を動かしている間（Desmos と同じく、重いグラフでも視点はなめらかに動かす）:
  - 1コマが遅いときだけ、画素密度と細かさを段階的に下げる（`web/src/lib/motionQuality.ts`）。60 コマ/秒を保てる間は、
    止まっているときと同じ絵のまま。段階は「重い面だけ粗い版にする → 画素密度を 1.5 倍 → 1 倍 → 0.75〜0.3 倍に下げる」の順。
    粗い版にするのは三角形の多い面から順に、細かいままの三角形が 15 万個以下になるまで（軽い式は、重い式と一緒に表示していても細かいまま）。
    下げても 1 コマの時間が 15% 以上縮まなければ（三角形の数で重い場面では、画素密度を下げても速くならない）、元に戻して、その操作の間はもう下げない。
    余裕が 45 コマ続けば1段戻してみて、遅くなったら、その操作の間はもう戻さない。
    ⚙ の「見え方」の「視点を動かしている間の画質」で、自動・くっきり（画素密度は下げず、重い面の粗い版だけ）・常にそのまま（何も下げない）を選べる
    （端末ごとに向きが違うので、共有リンクには入れず、そのブラウザにだけ覚える）。
    操作が終わったときの段階を覚えておき、次の操作はそこから始める。止まったら元の画素密度・そのままの版で描き直す。
    形を差し替えたコマ（回転の再生など。受け渡しと GPU への転送の時間）と、視点が跳んだコマ（2D / 3D の切り替えなど）は数えない
  - 粗い版: 三角形が 6 万個を超える曲面は、計算担当が粗い版（約 3 万個）も作っておく。頂点は同じものを使い、
    三角形の頂点番号だけが違う。格子の曲面は点を間引く。陰関数は、計算済みの F の格子を 2 か 4 個おきに間引いた格子で
    Surface Nets をもう一度走らせて作り直す（自分の頂点を持つ。頂点をまとめる方法と違い、面が重なったり欠けたりしない）。
    段差のある陽関数（階段など）は、まとめると段差と壁が崩れるので、粗い版を作らない
- ホイールの拡大縮小: 1目盛りで約 1.25 倍。目盛りの分をためて、0.1 秒ほどでならして動かす（操作 A・B とも同じ。
  操作 A の中ドラッグも、B の右ドラッグと同じく押した位置に向かって拡大縮小する）
  - スライダー・回転の再生で形が変わっているだけ（視点は止まっている）ときは、粗い版にせず、画素密度も下げない
    （遅いのは計算のほうなので。下げると、動いていない軸・枠・方眼までぼやける）
- 何も変わっていないときは描かない（止まっているときに電池を使わない）
- 曲面の表と裏は 1 つのメッシュで描き、裏面はシェーダーで暗くする
- 目盛りの文字は HTML ではなく WebGL のスプライトで描く（回すたびに HTML を書き換えない）
- 4 次元の回転などで形だけが変わるときは、材質（シェーダー）を使い回して形のデータだけ差し替える
- スライダー・複素平面を動かしている間と回転を再生している間は、式ごとに測った計算時間から、1回の計算が 12 ms に収まる細かさを決める
  - ただし、前の返事が点の使い回し（射影だけし直し）だった式は、細かさを下げずに一度計算する。回転の再生・回転角のドラッグでは、
    あとは射影し直すだけなので、操作が終わるまで粗い形のまま回すことにならない
  （`web/src/lib/budget.ts`。計算時間は細かさの2乗（曲面）・3乗（陰関数）に比例するとみなす）。軽い式は細かいまま。指を離したら、粗く計算した式だけを細かく計算し直す。
  媒介変数表示の図形は軽いので細かいまま回せて、回転の再生では点を計算し直さず射影だけし直す。
  画素密度は、視点を動かしているときと同じ段階で決める（いつも下げるのではない）
- 止まっているときの計算でも、細かい計算が 120 ms を超えそうな式（細かさ 200 の陰関数など）は、先に 40 ms ほどで済む粗い版を出し（「計算中」と出る）、
  続けて細かく計算して1回だけ差し替える
- 非表示の式は計算しない（表示したときに計算する）
- 計算担当の Worker を CPU のコア数に合わせて最大 4 つにし、式ごとに担当を分けて並列に計算する
  - 重い陰関数・範囲で重ねた立体（前回、F の計算に 30 ms 以上かかった式）は、F の計算だけを全部の Worker に分ける。
    担当の Worker が F を計算する点を「かたまり」（密な格子なら 1 層、まばらなら 32,768 点）に分け、かたまりを Worker の数で
    等分して計算し、担当の Worker が値をつなげてメッシュを作る。かたまりの切れ目はいつも同じなので、分けても形は同じ。
    `abs(gamma(x + i y)) = z`（細かさ 80、Worker 3 つ）で約 220 ms → 約 130 ms
- 式の計算（`core/src/eval.rs`）:
  - 同じ計算（2か所に出てくる `sin(u)` など）は1回だけ行う。媒介変数表示では、成分どうしでも共有する
  - 定数だけで決まる部分は、コンパイルのときに計算しておく。媒介変数の一部を固定した面（立体の6つの面・多変数の図形の面）では、
    固定した媒介変数だけで決まる部分もまとめて定数にしてから計算する
  - 値は複素数で計算するのが基本だが、式の定数がすべて実数で、関数が初等関数だけなら、まず実数だけで計算する。
    実数に収まらない所（`sqrt` の中が負など）や、有限でない値が出た所（256 点ごとのまとまり）だけ、複素数で計算し直す。
    結果は複素数で計算したときと（丸め誤差を除いて）同じ。陰関数（細かさ 200）で約 0.97 秒 → 0.60 秒
- 陰関数の、曲面の無い所を飛ばす（`core/src/interval.rs` の区間演算）: 格子を 1 辺 8 マスのブロックに分け、ブロックの箱の上で F が取りうる値の範囲を
  区間演算で求める。0 を含まなければ、そのブロックには曲面が無いので、F も計算せず、セルも見ない。
  F の値は、あるブロックとその周りの1点だけで計算して持つ（細かさ 200 の球で、値を持つ点は全体の 1/5 以下）。
  区間演算が使えるのは、定数がすべて実数で、関数が初等関数（三角関数・指数・対数・累乗・丸めなど）だけの式。
  使えない式（特殊関数・虚数を使う式）や、ブロックの 6 割以上に曲面がありそうな式は、全部のブロックを計算する（同じ仕組みで、飛ばすブロックが無いだけ）。
  細かさ 200 の球で約 230 ms → 33 ms、トーラスで約 250 ms → 19 ms、ジャイロイドで約 640 ms → 420 ms（ネイティブで測定）。
  `sqrt(x^2 + y^2)` のように 0 以上と分かっている値は、丸めの分だけ広げて下の端が負になっても 0 とみなす（軸の上のブロックも飛ばせる）
- 陰関数の格子の走査: ブロックごとに値を小さな配列に写して（密な格子なら写さずに）、セルの8つの角の符号を1バイトにまとめる。
  四角形を作る辺は、頂点を置いたセルの辺だけを見る。計算担当から画面へ配列を渡すときのコピーは1回にする（getter ではなく取り出す）
- 陰関数の「符号が変わらずに接するだけの所」は、辺を囲むセルの角の符号がすべて同じ所だけで探し、その周りのセルだけで調べる。
  格子の平面にたまたま接するふつうの曲面（`x^2 + y^2 + z^2 = 4` の極など）を誤って拾わないので、
  球（範囲 ±5）は細かさ 80 で約 270 ms → 25 ms、細かさ 200 で約 4.2 秒 → 0.43 秒（ネイティブで測定。ブラウザでは 1.5〜2 倍ほど）

| `core/` | `cargo test --release --test systems curve_report -- --ignored --nocapture` | 連立方程式の曲線の物差し（欠け・ずれ・偽の線・途切れ・時間。式の順番を 2 通り）を表で出す |
| `core/` | `cargo test --release --test systems -- --ignored --nocapture` | 線・点だけの解の陰関数の、点の数と時間を表で出す |
| `core/` | `cargo test --release --test shape -- --ignored --nocapture` | 形の正しさの報告（数分かかる）。変な形の陽関数・陰関数を 6 通りの回転で描き、正解の面と比べた「欠け」「余計」「破片」を表で出す。`SHAPE_ONLY=floor` のように付けると、その文字を含む式だけ |

形の正しさの報告の数字の意味: 表示範囲（$x, y \in [-10, 10]$、$z \in [-6.4, 6.4]$）を $128^3$ 個の小さい箱に分け、正解の面が通る箱とメッシュが通る箱を比べる。

- **欠け**: 正解の箱のうち、1 箱以内（周りの 26 箱を含む）にメッシュが無いものの割合（%）。面が抜けている所
- **余計**: メッシュの箱のうち、1 箱以内に正解が無いものの割合（%）。針・偽の面など、あるはずの無い所
- 「欠け3」「余計3」は 3 箱以内で数えたもの（大きく外れたものだけが残る）
- **破片**: 三角形が 8 個以下の、ほかとつながっていない小さい島の数（紙吹雪のような崩れ）
- 正解は、陽関数なら元の座標で細かく点を取って間を二分で埋めたもの、それ以外（陰関数と、$xy$・$xz$・混ぜた回転の陽関数）なら軸に平行な線の上で $F$ の符号が変わる所を二分したもの。
  ふつうの `cargo test` でも、回転なしのいくつかの陽関数で欠けが 0.5% 以下かを確かめる（`shape_regression`）

画面を `?bench=1` を付けて開くと（`npm run dev` の後に `http://localhost:5173/?bench=1`）、ベンチマークの式（`core/tests/bench.rs` と同じもの。`web/src/lib/bench.ts`）を順に描いて測り、左上に表で出す（全部で 10〜20 分ほど）。
保存した式は読まず、自動保存もしないので、ふだんの状態は変わらない。

- 計算の内訳: 計算担当の中の `eval` / `mesh` / `lod` / `copy` / `total`、受け渡し、描画側への登録（`viewer.setPlot`）
- 視点を回している間: カメラを 1 周回したときのコマの間隔・`render` の呼び出しの時間・GPU の時間（`EXT_disjoint_timer_query_webgl2` が使えるとき）を、
  (そのままの版 / 粗い版) × (画素密度: 基準 / 1 / 0.5) の 6 通りで。止まった状態の絵との差 D（色の差が 24/255 を超える画素の割合）も
- 4 次元の回転の再生中: 射影し直しの往復（計算担当の `total` + 受け渡し + 登録）の時間と、1 秒あたりの返事の数
- URL の引数: `frames=60`（1 周のコマ数。既定 240）、`only=ジャイロイド`（名前にその文字を含む式だけ）、`play=4`（再生を測る秒数）
- 結果は `console.log` にも JSON で出し、`__benchResults` でも読める。式ごとの最後の計算の内訳は `__plotTimings`（式の行の番号 → 内訳の `Map`）

## 数式の書き方

入力欄は数式入力ライブラリ [MathLive](https://cortexjs.io/mathlive/) を使っていて、分数やべき乗が数式の見た目のまま表示される。

- `/` で分数、`^` でべき乗（右矢印キーで抜ける）、`(` で括弧（閉じ括弧は自動）
- `pi` → π、`sqrt` → √、`sin` などの関数名は自動で変わる
- スマホでは入力欄を押すと数式用のキーボードが出る（123 / 変数 / f(x) / 特殊 / abc のタブ）
- 入力欄の LaTeX は `web/src/lib/latex.ts` で計算エンジン用の式に変換している

計算エンジンが読む式の書き方（入力欄からの変換後）:


- 陽関数: `z = x^2 - y^2`（`z =` は省略可）、`y = sin(x) z` なども可。`z = [1, 2] x` のようにリストも使える
- 陰関数: `x^2 + y^2 + z^2 = 4`、`sin x cos y + sin y cos z + sin z cos x = 0`
- 連立方程式・不等式: 括弧の外の `,` で区切る（`y = x, z = 0`）。連鎖も書ける（`y = x = z`・`x ≤ y ≤ z`・`0 ≤ x = y`）。
  不等号は `<`・`≤`・`>`・`≥`（入力欄では `<=`・`>=` と打つ。数式キーボードの `=` を長押し）。`<` と `≤` は 3D では同じ絵になる。
  等式は 3 本まで、不等式は 8 本まで。パラメータの定義は 1 行に 1 つ（`a = 1, b = 2` はエラー）。範囲で重ねる名前は使えない。
  媒介変数表示も不等式で切り取れる（`(cos t, sin t, t), z ≥ 0`）。不等式は射影した後の表示中の座標の式で、
  不等式の中の `t`・`u`・`v` は媒介変数ではなくパラメータとして読まれる。媒介変数表示と等式は一緒に使えない。
  等式の数で形が決まる: 0 本は領域（`x ≤ y ≤ z`）、1 本は曲面（不等式で切り取り。`x^2 + y^2 + z^2 = 4, z ≥ 0` の半球）、
  2 本は曲線（`y = x, z = 0`・`sin(x) = cos(y) = tan(z)`）、3 本は点（`x = y = z = 1`）
- パラメータ: `a = 1`、`c = 1 + 2i`（x, y, z, t, u, v, e, i 以外の1文字）。ほかの式の中で使える
- 曲線: `(cos t, sin t, t/4)`（t を使う。範囲は式の下の欄で指定）
- 複素平面の曲線・曲面: `e^(i t)`、`(u + i v)^2`（組にせず、座標を使わずに t や u, v だけを使う。横 = 実部、奥 = 虚部）
- 曲面: `((3 + cos v) cos u, (3 + cos v) sin u, sin v)`（u と v を使う）
- 多変数: `(t_1, t_2, t_3, t_4)`（媒介変数 t₁, t₂, … を4つ以上。次元を成分の数に合わせる）
- 掛け算の `*` は省略可: `2xy`, `x sin(y)`, `(x+1)(x-1)`
- 括弧なしの関数: `sin x`, `sin^2 x`（= `(sin x)^2`）
- 定数: `pi`（`π`）, `e`, `i`（虚数単位）
- `theta`・`θ`, `phi`・`φ`, `rho`・`ρ`, `sigma`・`σ`, `tau`・`τ`, `mu`・`μ`, `nu`・`ν` は 1 つの名前として読む（座標系の座標の名前に使う。前は `theta` を t·h·e·t·a と読んでいた）
- 関数: `sin cos tan sec csc cot arcsin arccos arctan sinh cosh tanh arcsinh arccosh arctanh exp ln log sqrt abs floor ceil round sign Re Im conj arg`
- 特殊関数: `gamma`（Γ）, `beta`, `psi`（ψ）, `zeta`（ζ）, `polylog`, `erf`, `erfi`, `Ei`, `Si`, `besselJ`/`besselY`/`besselI`/`besselK`, `airyAi`, `legendreP`, `hermiteH`, `hyp2F1`, `ellipticK`, `jacobiSN`, `lambertW` など（Wolfram の名前の先頭を小文字にした形。一覧はアプリの「書き方のヒント」）
- 2 つの引数の関数: `mod(a, b)`（余り）, `min(a, b)`, `max(a, b)`, `nCr(n, r)`（二項係数）, `nPr(n, r)`（順列）
- 階乗: `n!`（= Γ(n + 1) なので整数でなくてもよい）
- 結果が実数にならない点（例: `x < 0` での `sqrt(x)`）は描かれない
