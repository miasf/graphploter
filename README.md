# graphploter

公開ページ: https://miasf.github.io/graphploter/

ブラウザで動く 3D グラフソフト。目標は「Desmos くらい使いやすく、多次元の媒介変数表示・陰関数・特殊関数・複素数を 3 次元空間に自由に描ける」こと。

現在できること:

- 陽関数の曲面 `z = f(x, y)`（`y = f(x, z)`、`x = f(y, z)` も可）
  - 形が急に変わる所（極の近く、定義域の縁、表示範囲の上下の端を横切る急な斜面）だけ、三角形を二分して細かくする（6 回まで。
    `core/src/adaptive.rs`）。最も新しい頂点の向かいの辺を二分する方式なので、継ぎ目に隙間ができない。
    `1/sqrt(1 - x^2 - y^2)` の縁や `abs(gamma(x + i y))` の細い極もなめらかに描ける。なめらかな曲面は一様な格子のまま。
    スライダー・回転の再生中は細かくしない（止まったら細かく計算し直す）
  - 格子の点がたまたま乗らないと見えない、格子より細い山・谷・極（`5 exp(-2000((x-1.23)^2 + (y-0.77)^2))` など）も探して細かくする。
    初等関数の式では、区間演算で格子の小さいブロック（細かさ 150 なら 2 × 2 マス）ごとに値の範囲を求め、格子の点の値から
    考えられないほど広ければ、箱を四つに分けて調べ直す（1 マスの 1/32 まで）。格子の値の補間から離れた点が見つかれば、
    そこを含む三角形は必ず細かくする（その所だけ 16 回まで）。特殊関数・複素数の色分けの式では、マスの中心と辺の中点を調べるだけなので
    （格子の計算が 3 ms 以上の重い式では調べない）、見落としがあり得る
  - 表示範囲の上端・下端と、定義域の縁で、三角形を切ってから描く。交わる点は実際の関数で二分法で求めるので、
    急な斜面が表示範囲の端を横切る所（`1/sqrt(1 - x^2 - y^2)` の上端の円など）も、格子の細かさに関係なくなめらかな縁になる。
    頂点の一部だけが定義される三角形も、定義される部分を描く（捨てると、定義域の縁の近くに穴が空く）
  - 値が飛ぶ所（`floor` の段差、`tan` の極など）では三角形を切り分けて、段差の縁をまっすぐにする。
    高さの差が大きい格子の辺を二分法で 12 回狭め、差がほとんど縮まらなければ「飛んでいる」とみなす。
    表示範囲の高さの 0.5% より大きい段差を切り分ける（再生・ドラッグ中は 3%）。
    段差の線が交わる所・終わる所は、そこだけ細かくする（針のような三角形が立たない）。
    差の大きい段差（極かもしれない所）は、さらに二分して極のすぐそばまで狭める（細い極でも、壁が上下の端まで届く）。
    細い極の線（`nCr(x, y)` の x = −1, −2, … など）は、格子の辺の上で位置を探して切り分け、線に沿って隣の辺をたどる（細分で追いかけない）
    ⚙ の「値が飛ぶ所に壁を描く」で、段差の上下の縁を結ぶ縦の壁も描ける
- 陰関数の曲面 `F(x, y, z) = G(x, y, z)`（例: `x^2 + y^2 + z^2 = 4`）
  - 1つの小さな立方体（セル）を2枚以上の曲面が通るとき（近い曲面どうし）は、曲面ごとに頂点を分けるのでくっつかない。
    角のうち少ないほうの符号の角を、セルの辺でつながっているものどうしで組に分け、組ごとに頂点を1つ置く
  - 面が自分と交わる線・尖った点（ローマ曲面 `x^2 y^2 + y^2 z^2 + z^2 x^2 = x y z` の座標軸、ケーリーの 3 次曲面 `x^2 + y^2 + z^2 + 2xyz = 1` の 4 点、
    円錐の先）は、X の字・円錐の先のまま描く。1 セルに頂点 1 つの作り方では交わりが丸まって消えるので、∇F = 0 でヘッセ行列が鞍の形の点を
    ニュートン法で求め、その周りの三角形を作り直す（`mesh/singular.rs`）。交わる角度 θ が 0 に近づく所（ローマ曲面のピンチ点の近く）は、
    2 枚の面が 1 マスの中で混ざらないよう、作り直す半径を 1.5 / θ マス（6 マスまで）に広げ、特異点までを 1 マスほどの刻みで面へ寄せた点の列でつなぐ
  - 面にならない特異点の線（ローマ曲面の座標軸の |t| > 1/2 の「ひげ」、ホイットニーの傘 `x^2 = y^2 z` の z < 0 の「柄」）は、面の色の線で描く。
    F が線の上でだけ 0 に触れて符号が変わらないので、格子では見つからない。二重線の特異点から、ヘッセ行列の 0 の固有値の向きへ 1 マスずつ進み、
    ∇F = 0 へ寄せながらたどって、ヘッセ行列のほかの 2 つの固有値の符号がそろう所（ひげ・柄）だけを線にする
  - 折れ目（`max(abs(x), abs(y), abs(z)) = 1` の立方体の辺・角、`abs(x) + abs(y) + abs(z) = 6` の八面体）は、丸めずに立てて描く。
    法線が 30° 以上ずれる隣どうしの中点で、前後の差分の勾配が食い違う（勾配が跳ぶ）所を折れ目とし、周りの頂点の接平面の
    二次誤差（QEF）を最小にする点へ頂点を動かす（Dual Contouring の頂点の置き方。`mesh/crease.rs`）。角は 2 近傍の平面で 3 つの面が交わる点を探し、
    角ごとにいちばん近い頂点を 1 つだけ寄せる。立方体の角は格子の位置によらず頂点がちょうど乗り、辺からのずれは平均 0.3 マスほど。
    abs・min・max・√・整数でない累乗を使わない式（なめらかな式と、floor・mod などの値が飛ぶだけの式）には折れ目が無いので調べない
  - 表示範囲に比べて小さい図形（不等式の領域、等式を不等式で切り取った面も）は、図形の周りだけの格子で作り直す。
    表示範囲を広げても、図形の細かさは変わらない（格子のマスの数は表示範囲の 1 辺あたりなので、前は ±6 で ±1.5 の 1/13 ほどの三角形になった）
  - F が飛ぶ所（`tan(x) = z` の極 x = π/2 など、F が +∞ から −∞ へ飛ぶ所や、`floor` の段差）には面を張らない。
    符号の変わる辺を二分して、|F| が縮まなければ零点ではないとみなす（2D 表示の陰関数の曲線も同じ）。
    隣の辺と傾きがそろっている辺は、なめらかに 0 を横切っているだけなので調べない
  - 極のすぐ隣を走る面（`1/(x y) = z` の壁、`tan(x) = z y` の極の両側）も描く。極の近くのセル（零点でない辺や、定義されない角を持つセル）
    だけ、辺を 32 等分して零点を数え直し、零点がちょうど 1 つの辺に面を張る（極と零点が 1 つずつ入った辺は、両端の符号がそろうので、
    ふつうは見落とす）。極に近すぎる部分（辺の 1/32 より薄い所）は描けない。1 つのセルの中で、極をはさんで両側に零点がある所も頂点は 1 つ
  - 定義されない所との境目（`sqrt(36 - x^2 - y^2) - z = 0` の円、`ln(x) + ln(y) + ln(z) = 1` の x = 0 など）は、縁まで延ばしてから切り落とす。
    定義されない格子点を、隣の定義される点から縁に近づいたときの値で 1 層埋め（斜めの縁で穴が空かないよう、2 層目には隣の値を写す）、
    縁をまたぐ辺に本当の零点があれば二分で求める。できた面のうち定義されない所に出た部分は、三角形の辺の上で縁を二分して切り落とす。
    1 層だけ定義されない所（`1/(x y)` の x = 0 のような極）は埋めない
  - `floor`・`mod`・`round`・`ceil`・`sign` を含む式の段差は、段の番号（枝の番号）が同じ領域ごとに、段の番号を固定した
    なめらかな式で面を作り、段差の所で切り取る（面が段差で終わる縁がまっすぐになる）。段差をまたぐセルだけをこの方法で作り、
    ほかのセルはふつうに作る。面の間隔が格子より狭くなる所（`mod(x y, z) = 1` の z = 1 の近くなど）は描けない
  - 極・値が飛ぶ所・定義域の縁の近くにできる小さな破片（三角形 12 個以下・2 マス以下の成分で、零点ではない辺や定義されない角のあるセルにあるもの、
    または閉じていないもの）は消す。本当に小さい閉じた図形（小さい球）は残す。`mod(x y, z) = 1` のように面が格子より細かく詰まった所は、
    破片を消すとそこが空になるので、1,000 個より多く消したら式の説明に「（細かすぎて描けない部分あり）」と出す
  - 三角形が 150 万個を超える式（細かさ 200 の `mod(x y z, 4) = 2` など）は、F の格子を 2 個・4 個おきに間引いた版を本体にして、
    式の説明に「（粗くして表示）」と出す（画面が固まらないように）
  - 符号が変わらずに 0 に接するだけの式（例: `(x^2 + y^2 + z^2 - 4)^2 = 0`）も描ける。格子の線に沿って |F| が
    減ってから増える所を三分探索で調べ、極小がほぼ 0 なら曲面が通るとみなす。三角形の向きは、隣どうしでそろえてから
    重心から見て外向きにする
  - 面にならず、線・点だけになると式の形から分かる式（0 以上の項の和 = 0。例: `(x^2 + y^2 - 4)^2 + z^2 = 0` の円、
    `x^2 + y^2 + z^2 = 0` の原点）は、$A^2 + B^2 = 0 \iff A = B = 0$ として、交わる線・点で描く。$A = 0$ の面の上で $B$ の値 0 の線を
    取り出し、ニュートン法で 2 つの面の上へ寄せる（寄らない点、`tan` の極などは捨てる）。項が 3 つ以上なら、はじめの 2 つの線の上で
    3 つ目の符号が変わる所から点を求める（`core/src/system.rs`）。面になる因数と混ざる式（`(x^2 + y^2)(z - 1) = 0`）の線・点は、まだ描かない。
    2D 表示では、今までどおり陰関数の曲線として描く
  - 複素数の陰関数（`e^(i x) = y + i z` のらせん、`(x + i y)^2 - z = 0` の放物線 2 本）: 値が複素数の F = 0 は、Re F = 0 と Im F = 0 の交わる線として描く
    （連立方程式の曲線と同じ道）。式に i（または複素数のパラメータ）があり、表示範囲の中の点の 2 割以上で F が実数にならないときだけ。
    `|x + i y| = z^2 + 1` のように値が実数の式、`sqrt(x)` のように i を含まない式は、ふつうの陰関数のまま。
    片側が座標 1 つの式（`z = (x + i y)^2`）は、今までどおり陽関数（複素数の色分け）。2D 表示では交点を点で描く
    - ⚙ の「複素数の色分け」で、曲面にして色を付けることもできる: |F| = 1 の曲面（色は arg F）、Re F = 0 の曲面、Im F = 0 の曲面。
      色は陽関数の色分けと同じ（色相が偏角、|F| が 2 倍になるごとに明るさの縞）。Re F = Im F = 0 の線は、縞が集まる所に見える
    - 座標を複素数にする（式の ⚙ のチェック）: 式の x, y, z を x + i w, y + i w₂, z + i w₃ に置き換えて描く（次元は 6 にする）。
      `x^2 + y^2 + z^2 = 1` のまま、座標が複素数の図形（実数で 4 次元）の断面を見られる。x, y, z を表示すれば実数の部分（球面）。
      書き換えた式を手で書いても同じ（`(x + i w)^2 + (y + i w_2)^2 + (z + i w_3)^2 = 1`）。表示する座標を (x, w, y) にして、z を「等値面を何枚も」で動かすと、
      w = 0 の面の円と x = 0 の面の双曲線の族になる
  - 連立方程式の曲線（等式 2 本）: 1 本目の式の曲面の上で 2 本目の式の線を取り出し、ニュートン法で 2 つの曲面の上へ寄せる。
    寄らない点（`tan` の極など）は捨てる。線が自分と交わる点は、格子の半マスほど丸まる。1 点で接するだけの交わりは描かれない
  - 等式に不等式を足すと、その条件を満たす部分だけを描く（`x^2 + y^2 + z^2 = 4, z ≥ 0` → 半球）。等式の行を今までの道
    （陽関数・陰関数・回した陽関数）で描いてから、三角形・線分を切る。境目は辺の上で、はさみうち法で求める（`system::trim_mesh`・`clip_segments`）
  - 不等式の領域（`x ≤ y ≤ z`・`abs(x) ≤ 2, abs(y) ≤ 2, abs(z) ≤ 2`）: 境目の面 $G_i = 0$ ごとに陰関数の道で作り、ほかの不等式で切り取るので、角が立つ。
    切り取るときは、ほかの不等式を面から中身の側へ少しずらした点で計算するので、厚さ 0 の所（`0 ≤ xy ≤ x` の $x = 0$ の面の、$y < 0$・$y > 1$ の所。
    集合には入っているが面積・体積を持たない）は描かない。2 つの面が重なる所は 1 枚だけ描く。
    境目の面 $G_i = 0$ が座標の 1 つについて 1 つの式に解ける面（その座標の 1 次式。$z = x^3 + y^3$・平面・円錐 $z = \sqrt{x^2+y^2}$。
    `core/src/solve.rs` が 2 次以下なら根の公式、1 か所にしか出てこなければ孤立法で解く）は、陰関数の格子ではなく陽関数の道
    （細かさ 150、適応的に細かくする）で作り、向きを外向き（$
abla G$ の向き）にそろえてから切り取る。格子の粗さで面と切り取った縁が
    ギザギザにならない（`x^2 + y^2 ≤ 1, 0 ≤ z ≤ x^3 + y^3` は三角形 547 個のギザギザ → 2 万個のなめらかな面）。
    2 つに分かれる面（球・円柱）は、2 枚の継ぎ目が領域の境目に来ると縞が出るので陰関数のまま
    表示範囲の端と切り口には、ふたをする（ふたは色が薄く、格子線が無いので、式の境目と見分けられる）。最初は半透明（不透明度 0.45）。
    `<` と `≤` は 3D では同じ絵。$G$ が飛ぶ面・定義されなくなる面（`1/x ≤ z` の $x = 0$）は描かれない
  - 連立方程式の点（等式 3 本）: 2 本の交わる線の上で 3 本目の式の符号が変わる所を探し、3 本の式のニュートン法で寄せる。丸で描く。
    式が多項式なら、グレブナー基底でも解いて合わせる（`core/src/groebner.rs`。2D 表示の等式 2 本の交点も同じ）:
    有理数係数（i128 の分数。あふれたら今の道だけ）の辞書式順序の被約グレブナー基底を Buchberger 法で求め、
    最後の変数だけの多項式から順に実根を求めて前の変数へ代入する。実根は導関数の根で区間を分け、符号の変化と、
    導関数の根で値が 0 に触れる所（重根）から求めるので、符号が変わらない解（接するだけの交点。`y = x^2, y = 0` の原点、
    円と接線の接点、1 点で接する 2 つの球と平面）も描く。解が無ければ空、解が無限個なら今の道だけ
  - 格子より小さい図形（小さい球、細い輪・管）も描く。疑わしい所（1 辺 8 マスのブロック）を探し、その所だけ 2 倍・4 倍の細かさで
    作り直して差し替える。疑わしい所は、(a) 区間演算が使える式では「曲面があるかもしれない」のに頂点が無いブロック
    （箱を 8 等分して 3 段まで調べ直し、どこも 0 を含まなくなれば外す）、(b) 使えない式では、周りの符号が全部同じなのに
    |F| < 0.87 |∇F| h になる格子点のあるブロック、(c) 隣の頂点どうしの法線が 35° 以上ずれる、角ばった所。
    作り直す範囲の外側の面を曲面が横切らないことを確かめてから差し替えるので、継ぎ目にひびはできない。
    区間演算が使えない式（特殊関数・虚数を使う式）では見落としがあり得る。区間演算が使える式でも、大きい曲面のすぐそばの小さい図形は
    見落とし得る。大きい曲面につながった細い部分（円錐の先、細い首）は、隣どうしの頂点の法線が 35° を超えてずれる所のブロックだけを
    2 倍の細かさの格子で作り直す。面は「符号の変わる、一番細かい辺」ごとに、その辺を囲むセル（細かさが違ってよい）の頂点を結ぶので、
    細かさの境目にひびができない。ただし、極・値が飛ぶ所・定義域の縁・接する所・近い曲面・段差のある式では行わない（それらの処理と両立しないため）。
    小さい図形（囲む箱が元の格子で 40 マスより小さい成分）は、元の格子の倍率ではなく、図形を囲む箱のいちばん長い辺を 40 マスに分けた
    格子で作り直す。囲む箱は区間演算で 8 等分を繰り返して狭め（使えない式では頂点から決め）、作った形が箱よりずっと小さければ形に合わせて
    作り直す。曲面が箱からはみ出せば箱を広げ、箱が成分の外の曲面にかかれば諦める。なので半径 0.0001 の球も 1 の球も同じ細かさになり、
    スライダーで半径を動かしても、境目（40 マス）で急に粗くならない。
    再生・ドラッグ中も、この小さい図形の作り直しだけは軽い版（24 マス）で行う（大きい曲面の角ばった所は止まってから）。
    範囲で重ねた立体は作り直さない。⚙ の「陰関数の細かい図形を念入りに探す（遅くなる）」で、探す手間と細かさ（8 倍まで、小さい図形は 64 マス）の上限を上げる
- 媒介変数表示の曲線 `(x(t), y(t), z(t))` と曲面 `(x(u,v), y(u,v), z(u,v))`、立体 `(x(u,v,t), y(u,v,t), z(u,v,t))`。範囲は `2pi` のような式でも書ける
  - 曲面でも、値が飛ぶ所（`floor` の段差、`tan` の極）で面を切る（段と段・極の両側を結ぶ偽の面を描かない）。
    細かくした後の辺のうち、両端の点が離れているものを (u, v) の上で二分し、離れたまま縮まなければ飛んでいるとみなす。
    極の先の点は、表示範囲の対角線の 2 倍の所にそろえる。陽関数と同じく、段差の線が終わる・交わる所だけ細かくする
  - 立体（媒介変数3つ。u, v, t か t₁, t₂, t₃）は、媒介変数の範囲の直方体の6つの面の像を描く。面は外向きになるよう、
    囲まれた体積の符号を見て向きをそろえる。曲面をパラメータの「範囲で重ねる」と、これも立体になる
  - **多変数（媒介変数が4つ以上）**: `(x(t₁, …, t₄), y(t₁, …, t₄), …)` のように、媒介変数 t₁, t₂, … を8個まで使える。
    4つ以上の図形は3次元の画面に中身をそのまま描けないので、媒介変数を2つだけ動かした面（残りは固定）をたくさん描いて表す。

  - 曲線は曲がっている所だけ細かく計算する（適応サンプリング）。値が飛ぶ所では線を切る
  - 曲面（媒介変数2つ）も、急に曲がる所・定義域の縁だけ三角形を二分して細かくする（陽関数と同じ `core/src/adaptive.rs`。
    n 次元の点のずれが表示範囲の対角線の 10⁻³ 倍を超える所。回転・射影してもこの許容量に収まるので、回転の再生では計算し直さない）。

- 曲面の格子線: x, y, z 方向ごとに間隔を変えられる（z 方向は等高線になる）。標準は 1 画素の細い線。
  視点を動かしている間に画素密度を下げても、線の太さは変わって見えない（格子線はシェーダーで細くし、枠・方眼・軸の線は半透明にする）
- 面の濃さ: 0 にすると格子線だけの曲面（ワイヤーフレーム）になる。格子線の密度（x, y 方向・等高線）と太さはスライダーで調整
- スマホでは式の一覧を下から引き出すシートにして、グラフを全画面表示
  - グラフの指の操作（1本指で回転、2本指で移動・拡大縮小）は、three.js の OrbitControls にそのまま任せる。
    パソコン用に入れた調整（操作を始めるたびに注視点を図形・床の面の奥行きに置き直す、回転の感度を半分にする など）は、
    指の操作には使わない（スマホでは調整前の挙動のほうが操作しやすかったため）
  - 入力欄の上から指を動かすとスクロール、タップすると入力が始まる（入力欄に透明な「タップ受け」を重ねている）

- 式の ⧉ ボタンで、その式を複製してすぐ下に置く（式・見た目・格子線・媒介変数の範囲・回転・フォルダなどの設定も写す。色だけは見分けられるよう次の色にする）
- フォルダ: 「＋ フォルダ」や式の ▤ ボタンで、式をまとめて折りたためる（名前の変更・まとめて表示/非表示・解除・削除）。
  ドラッグでも出し入れでき、保存・共有リンクにも残る。式が3つ以上のサンプルはフォルダにまとめて追加する
- 遠近感: 平行投影から強い透視投影までスライダーで調整、背景の明暗の切り替え
- 3D の面は、表示範囲の箱で切れた縁を面の色の線で引く。縦に立った面（`y = 0`・`y = x^2`）を真上から見ても、線として見える
- 2D 表示（グラフ右上の 2D / 3D ボタン）: 横・奥の平面に真上から描く（ドラッグは移動）。描き方は2つから選べる
  - 投影: 3次元の図形を真上から平面に押しつぶした形（影）。z = f(x, y) は値で塗り分ける。
    縦に立った面（`y = x^2 + 0 z`、円柱の側面）は押しつぶすと面積が無くなるので、線として残す
  - 切り口: 縦の座標 = 0 の平面で切って、交わる線を描く。z = f(x, y) なら f = 0 の曲線、媒介変数表示の曲面は
    射影した三角形ごとに平面との交わりの線分を求める。曲線（媒介変数1つ）はどちらでも押しつぶした形
  - 縦の座標を使わない式（x² + y² = 4 など）は、どちらでも同じ形になる
  - `z = f(x, y)`（縦の座標 = 横・奥の関数）: 平面を値で塗り分ける。z の表示範囲が色の範囲で、z 方向の格子線が等高線。
    複素数の色分けをすると、定義域の色分け（偏角の色）になる
  - `y = f(x)`, `x = f(y)`: 曲線（曲がっている所を細かく計算）。陰関数 `F(x, y) = 0`: 曲線（マーチング・スクエア法）。
    符号を変えずに 0 に接するだけの所も描く: 格子の線に沿って |F| が減ってから増える所を三分探索で調べて線にし（`(x² + y² − 4)² = 0` の円）、
    格子点の周りで |F| の極小を探して1点だけ 0 になる所を点にする（`z = x² + y²` の切り口の原点）。
    両端の値から直線で求めた交わる点が実際の F = 0 からずれている辺（値が段になって飛ぶ式など）は、二分法で求め直す
    式に縦の座標 z があれば z = 0 として計算する
  - 範囲で重ねた立体: 塗った領域。媒介変数表示: 縦の成分を 0 にして描く
  - 連立方程式・不等式（切り口、または縦の座標を使わない式）: 縦の座標 = 0 の 2 次元の問題として描く。不等式だけなら塗った領域
    （`y ≤ x^2`。角が立つ。境目に線を引き、`<`・`>` の境目は点線）、等式 1 本と不等式なら曲線の一部、等式 2 本なら交点（`y = x, y = x^2` → 2 点）。等式 3 本はエラー。
    投影で縦の座標を使う式は、3D の図形を平らにする（領域は、境目の面と表示範囲の端のふたを合わせて塗る）
- 切り口: 画面の軸に垂直な平面で切って片側だけを表示し、立体の切り口にふたをする（位置はスライダー、残す側は切り替え）
  - 陰関数・範囲で重ねた立体: 計算担当が切り口の平面の上で F を計算し、中身（F < 0 の側）の部分を三角形にする。
    陰関数は式の両側のどちらが中身か決まっていないので、表示範囲の中で狭いほうを中身とする。
    切り口を動かしたときは、覚えておいた式からふただけを作り直す
  - 範囲で重ねた立体が表示範囲からはみ出すときは、表示範囲の 6 つの面にもふたをする（中が見えないように）。
    切り口があれば、切り落とされる側の端のふたは描かない。ふつうの陰関数は、どちらが中身か決まっていないので端のふたは付けない
  - 媒介変数3つの立体: 描画側でステンシルバッファを使う。切り口の上の点への視線が、立体に入る面と出る面を何回通ったかを
    数え、中にある点だけを塗る
- 4 次元以上: 座標は x, y, z, w（= w₁）, w₂, w₃, …（4 次元目が w、5 次元目が w₂。w₁ と書くと w と同じ）
  - 画面の横・奥・縦に表示する3つの座標を選び、残りの座標はスライダーで値を固定した断面を描く
  - 媒介変数表示 (x, y, z, w, …) は、表示する3つの座標の成分を描く（射影）
- 表示していない座標の見せ方（式ごと。⚙ の「w の見せ方」）: 表示していない座標（w 以降）を使う式は、次から選べる。
  断面以外では、式の下に、その座標の範囲の欄が出る（最初は断面のスライダーの範囲。パラメータも使える）
  - 断面（今まで）: スライダーの値 1 つでの図形。⚙ の「w の値をこの式だけで決める」で、式の下にこの式だけの w のスライダーを出せる（× で次元の設定の値に戻す）
  - 見せ方を切り替えると、面の濃さをその見せ方の既定値にする（等値面 35%・断面の塗り分け 60%・伝達関数 100%・範囲で重ねる 45%。自分で動かした値は変えない）
  - 範囲の欄は、1 つ目の座標だけ断面のスライダーの範囲にし、ほかは今の断面の値に固定して用意する（動かしたい座標だけ範囲を広げる）
  - 等値面を何枚も: 範囲を等分した値ごとの図形を重ね、値で色を付ける（曲線も色分けする）。座標が 2 つ以上なら全部の組み合わせ（64 枚まで。色は 1 つ目の座標）
  - 断面の塗り分け: 表示範囲の中の平面（各軸に等間隔）を、w = f の値で塗る
  - 伝達関数: w = f の値に色と不透明度を割り当て、表示範囲の箱の中で視線を少しずつ（格子の 1 辺の点の数の 1.5 倍の歩数）進めて重ね塗りする（ボリュームレンダリング）。面の濃さが全体の不透明度になる。
    不透明度は「一様・値が大きいほど濃い・小さいほど濃い・何枚かの値の所だけ濃い（等値面風）」から選び、濃さはスライダー。範囲の外の値は描かない。
    視点が箱の中に入ると描かれない
  - 伝達関数の重ね方: 手前から重ね塗り（今まで）・視線上の最大値（最大値投影）・最小値・平均値。最大値などでは視線ごとに 1 つの値の色を出し、
    不透明度はその値での不透明度の形（最大 1 にそろえて 1.5 乗）× 濃さの 2 倍（最大値は大きめの値になりやすく、ゆるく上げると箱全体が塗りつぶされるため）
  - 不透明度の「0 の近くだけ濃い（ぼやけた面）」: 値 0 の面からの距離を |v| / |∇v|（勾配は格子の差分）で見積もり、格子の何マスかの幅でぼかす。
    値の大きさで幅を決めないので、式の大きさによらず同じ厚み。陰影を切っても、視線の向きからの光で陰を付ける（付けないと面の向きが分からず円盤に見える）
  - 勾配で陰影を付ける（⚙ のチェック。重ね塗りのとき。既定で付ける）: 値の勾配（格子の 1 マスの中心差分）を面の法線とみなし、視点の少し右上からの光を当てる
    （拡散 + 鏡面。裏表は区別しない）。暗い側の下限は元の色の 55%、光に向いた所は少し明るく（下限を低くすると、重なった面の多くが横向きなので全体が暗くくすむ）。
    格子の 1 マスで値の位置がほとんど変わらない所（ほぼ平らな所）は法線があてにならないので、光を弱めて元の色に近づける。
    ほとんど透明な点では計算を省く（勾配にテクスチャを 6 回読むため）
- 値が複素数の伝達関数（w = sin(x + iy) + z・複素数の陰関数の F の値）: 実部・虚部の組を 2 チャンネルのテクスチャにし、色は偏角
  （陽関数の複素数の色分けと同じ色。|f| が 2 倍になるごとに明るさの縞）、不透明度の形は |f| で決める。|f| の範囲は 0 〜 表示範囲の中の |f| の 9 割が入る値
  （外は端として描く）。「何枚かの値の所だけ濃い」は |f| = 2ᵏ の所、「0 の近くだけ濃い」は f = 0 の所（3 次元ではふつう線なので、線のまわりの管）。
  補間は実部・虚部で行う（偏角を補間すると ±π をまたぐ所で崩れる）。最大値・最小値は、その値をとった点の偏角の色、平均値は値の平均の偏角
- 不等式の領域の霧（⚙ の「描き方」。標準は今までどおり境目の面とふた）: G = max G_i（全部の不等式を満たす所が G ≤ 0）を格子で計算し、
  境目までの距離の見積もり G / |∇G| にして返す（計算エンジン側で勾配を求めるので、描画側は 1 回読むだけで中身か・境目に近いかが分かる）。
  中身を式の色で薄く塗り、境目（格子の 1.5 マスの幅）を濃くして、境目の近くだけ勾配で陰影を付ける。歩数は格子の 1 辺の点の数の 2.5 倍（256 まで。
  境目が 1 歩より細いと点々のムラになる）。光線は領域（境目から 3 マスまで）を囲む箱の中だけ進める。
  それでも回している間は境目の面より十数倍重い（ソフトウェア描画で 0.9 fps 対 15 fps）ので、標準にはしていない
- 伝達関数の歩幅は、格子の箱のいちばん長い辺 / 歩数でそろえる（箱の真ん中を通る光線は今までどおりの歩数。短い光線・縮めた箱では歩数が減る）
- 陰関数の F の値の伝達関数（⚙ の「描き方」。表示していない座標を使う陰関数では「w の見せ方」の選択肢）: 陰関数 F(x, y, z) = 0 の F（左辺 − 右辺）の値を
  格子で計算し、伝達関数と同じ描き方で塗る。色の範囲は、表示範囲の中の |F| の 9 割が入る値 q での −q 〜 q（外の値は端の色）。
  切り替えると「0 の近くだけ濃い」・式の色の明暗になる。表示していない座標は断面の値（次元の設定の「範囲で重ねる」より優先）
  - 範囲で重ねる: 次元の設定の「範囲で重ねる」と同じ立体を、この式だけの範囲で描く（何等分して調べるかは ⚙ の「範囲で重ねる枚数」）
  - 断面以外を選ぶと、その式が使う座標については、次元の設定の「範囲で重ねる」より式の設定が優先される（重ねたまま等値面を何枚も作ると、同じ立体が重なるだけだったため）
  - 断面の塗り分けと伝達関数は、`w = f(x, y, z)` の形（表示していない座標 = その座標を使わない式）のときだけ。その座標が絡む回転をしているときは使えない
  - 色の対応表は viridis・turbo・式の色の明暗から選ぶ（計算し直さない）。2D 表示では断面のまま
    （式の色の明暗は OKLab で明るさだけを動かす。色相を保ち、鮮やかさは式の色の明るさの所で最大。線形の色を混ぜると途中が灰色に寄ってくすむため）
- 範囲で重ねる: 表示していない座標を「範囲」にするか、パラメータの「範囲で重ねる」を押すと、
  その範囲で動かしたときに図形が通る領域を描く（曲面 → 立体、曲線 → 曲面）
  - 立体は G(p) = max(min F, −max F) ≤ 0 の領域の境界面（F を範囲の各点で計算して最小・最大をとる）
  - 範囲の式にまだ定義していない文字があると、次元の設定の欄に「a のスライダーを追加」ボタンが出る。範囲が計算できない間も、パラメータの定義の行（a = 1）は計算する
  - 座標の範囲は式で書ける。パラメータも使えるので、`0 〜 a` にすると a のスライダーで範囲を動かせる
    （両端が逆なら入れ替え、同じ値ならその値での断面にする）
- 回転: 中心 c と、座標の組 (i, j) ごとの角度（n 次元なら nC2 通り、多いときは折りたたむ）で、点を q = R(p − c) + c に動かす
  - 次元が5未満でも、w, w₂ を使った5次元の回転（5C2 = 10 通り）ができる。陰関数・陽関数はその方向にまっすぐ伸びた形、媒介変数表示はその成分が 0 の形として回す
  - 陰関数は、式に p = c + Rᵀ(q − c) を代入して回す（断面が回転で変わるので、式から計算し直す）
  - 陽関数は、回転が表示中の座標どうし（と、式が使っていない座標どうし）だけなら、曲面 (u, v, f(u, v)) をそのまま回せるので、
    媒介変数表示と同じく点を計算してから回す。
    w など表示していない方向が絡む回転でも、断面は「傾いた直交座標系 (u, v, t) の陽関数 t = g(u, v)」になることが多い。
    f が使う座標の向きが表示中の 3 次元の中で張る空間が 2 次元以下で、それに垂直な向きを高さにとれる（面が高さの向きに近すぎない）なら、
    この傾いた座標系の陽関数として描く（回さない陽関数と同じ作り方なので、段差の切り分け・壁・急な所の細分・定義域の縁・複素数の色分けが残る）。
    回転が変わるたびに、表示範囲がちょうど収まる範囲で計算し直す。
    そうならないとき（4 次元の z = f(x, y, w) を zw で回すなど、f が 3 つの独立な向きを使う場合と、面が高さの向きにほぼ平行な場合）と、
    2D 表示の切り口だけは、陰関数として計算し直す。
    点は回さないときと同じ作り方（段差の切り分け・壁・急な所を細かくする）で、回転の中心から表示範囲の角までの距離の範囲で作るので、
    階段の段差も回した後まで途切れたまま残る。広げた範囲でも表示範囲と同じくらいの格子の間隔になるよう、分割数を増やす（2 倍まで）
  - 2D 表示でも回転を反映する。`y = f(x)` は曲線を、`z = f(x, y)` は曲面を作ってから回し、平面に押しつぶす（値で塗り分け）。
    切り口では、縦の座標を使う陽関数は陰関数として計算し直し、式から直接 縦の座標 = 0 の曲線を求める（接するだけの所も描ける）
  - 媒介変数表示は、n 次元の点を一度計算して Worker に覚えておき、回転・表示する軸が変わったときは射影し直すだけ（式を計算し直さない）
- 4 次元の遠近法: 回転した後、表示していない座標 q_h の奥行きに応じて s = Π D / (D − (q_h − c_h)) 倍に縮めて描く（奥ほど小さい）。
  射影で描く図形（媒介変数表示・回した陽関数）に効く。断面（陰関数）には効かない
- 回転の再生: 回転ごとの ▶ ボタンで、角度を回し続ける。⟲ でその回転を 0° に戻す（「回転をリセット」と同じく、再生も止める）。
  その回転で描いているグラフを全部消す・非表示にすると、再生は自動で止まる
- 断面の値（w, w₂ などの「固定」のスライダー）にも ▶（最小値から最大値まで 4 秒で動かし続ける）と ⟲（0 に戻して再生も止める）がある
- スライダーの横の数値（固定した座標の値・回転角・切り口の位置・細かさ・枚数・遠近感・面の濃さ・線の太さ・格子線の間隔など）は、タップ（クリック）するとその場で数式キーボードから値を入力できる（Desmos と同じく、スライダーの範囲の外の値も入れられる。重すぎる値などは上限で止める）
- リスト: `(t, [-1, 1], [-1, 1], [-1, 1])` のように使うと、組み合わせ（直積）の数だけ図形をまとめて描く。
  陽関数・陰関数でも使える（`z = [1, 2, 3] x`、`x^2 + y^2 + z^2 = [1, 4, 9]`）。パラメータの値には使えない
- サンプルの「正八胞体（4次元の立方体）の回転」で、辺 32 本を4次元の遠近法と xw 回転の再生つきで表示する
- **複素平面の図形**: `=` の無い式が座標（x, y, z, …）を使わず、媒介変数（t / u, v / t₁, t₂, …）だけを変数に使っていれば、
  値 f を複素平面の点として描く。複素平面は x 座標 = 実部・y 座標 = 虚部の平面で、ほかの3次元の図形と同じ空間に置く
  （複素平面の「モード」に切り替えるのではない）。2D 表示にすると、そのまま複素平面の図になる
  - `e^{it}` → 単位円、`2e^{it} + e^{-3it}` → 外サイクロイドのような曲線、`[1, 2, 3] e^{it}` → リストで3つの円
  - `(u + iv)^2` → 媒介変数の長方形の像（曲面）。u, v の格子線が等角写像の像になる
  - 縦（z 座標）には「+α」として、⚙ の「縦の軸」で 0（平面の上）・媒介変数 t・|f|・arg f・Re f・Im f を選べる。
    `e^{it}` で縦を t にするとらせん、`Γ(1 + it)` で縦を |Γ| にすると、虚軸に沿った Γ の値の動きと大きさを一緒に見られる。
    中身は媒介変数表示 (Re f, Im f, 縦の値) なので、回転・4次元の射影・範囲で重ねるも、ふつうの曲線・曲面と同じように使える
  - **点**: 座標も媒介変数も使わない式は、i を書いたか、複素数のパラメータ（スライダーを「複素数」にしたもの）を使ったか、
    値が実数でなければ、複素平面の点（丸）として描く（`1 + 2i`、`c`、`c^2`、`1/c`、`[1, 2, 3] + i`）。
    複素平面でドラッグして c を動かすと、c² や 1/c の点も一緒に動く。式の下には点の値（0.28 + 0.96i など）を書く。
    縦の軸も選べる（|c| にすると、高さ |c| の所に浮かぶ）。i も複素数のパラメータも使わない実数の定数（`2`、実数の `a`）は、
    今までどおり平面 z = 2 になる
  - 長さの無い曲線（組 `(1, 2, 3)` の点など）も、丸で描くようにした（以前は見えなかった）
  - 同じ名前のパラメータ（`t = 1` など）が定義されていれば、t はパラメータになる（`e^{it}` は1つの複素数なので点、`2t` は平面）
  - `e^{ix}` のように座標 x を使う式は、今までどおり陽関数 z = f(x, y)（⚙ の「複素数の色分け」で |f| と偏角の色で描ける）。
    値がどこでも実数にならないときは、t を使えば複素平面に描けることを知らせる
- 媒介変数は t（曲線）、u と v（曲面）、u と v と t（立体）、または番号付きの t₁, t₂, t₃, t₄, …（8個まで。番号は飛んでいてもよい）。
  組 (…) の外では t, u, v はパラメータとして使える
- パラメータ: `a = 1` のように書くとスライダーになり、ほかの式で `a` を使える
  - 未定義の文字を使うと「a のスライダーを追加」ボタンが出る
  - 同じ名前を2つの行で定義すると、下の行はエラーになる（上の行を消す・名前を変えると、下の行がスライダーに戻る）
  - 刻み（Desmos の Step）: 決めると、値を最小値から刻みの整数倍の所にそろえる（式やパラメータも使える。空なら自動）
  - ▶ で値を自動で動かす（最小値から最大値まで 4 秒、最後まで行ったら最初から）
  - スライダーの最小値・最大値は式で書ける。ほかのパラメータも使える（`a ≤ c ≤ b`、`0 ≤ c ≤ 2b` など。a, b を動かすと c の範囲も変わる）。
    式の値は画面側で計算する（`web/src/lib/evalExpr.ts`。数値だけなら JS で読み、式なら計算エンジンの WASM を初めて使うときに読み込む）
  - 媒介変数の範囲にもパラメータを使える（0 ≤ t ≤ b の b を再生すると、曲線が伸びていく）
  - 「複素数」モードでは、複素平面の上で点をドラッグして複素数の値を決められる
- 計算はすべて複素数で行う（例: `z = abs(gamma(x + iy))`）
- 複素数の色分け（陽関数の ⚙）: 値 w = f(x, y) が複素数になる関数を、高さ |w|（または Re w, Im w, arg w）と、偏角 arg w の色相で描く。
  |w| が 2 倍になるごとに明るさの縞が1本入る。頂点ごとに (Re w/|w|, Im w/|w|, log₂|w|) を渡し、色相は画素ごとに計算する
  （偏角そのものを補間すると −π と π の境目で色が崩れるため）
  - 極の近くなど、値が表示範囲から大きく外れる所は、範囲の少し外にそろえて描く（頂点を捨てると穴が空くため）
  - 回転しても色分けできる。表示中の座標どうしの回転なら高さ |f|・Re f・Im f の曲面をそのまま回し、色も付ける。
    w などが絡む回転でも、傾いた座標系の陽関数として描けるなら高さ |f| などの曲面に色も付ける。
    陰関数として計算し直すときだけ（上の条件）、z = |f| などの陰関数になり、形だけで色分けはしない
- 特殊関数（すべて複素数で使える。Wolfram/Mathematica にある主なもの）: ガンマ・ベータ・ポリガンマ・不完全ガンマ／ベータ、ゼータ（フルヴィッツ）・多重対数、誤差関数・フレネル積分・指数積分・三角積分、ベッセル J/Y/I/K・ハンケル・球ベッセル・エアリー、直交多項式（ルジャンドル陪関数・エルミート・ラゲール・チェビシェフ・ゲーゲンバウアー・ヤコビ）・球面調和関数、超幾何関数 ₀F₁ ₁F₁ ₂F₁ U、楕円積分 K E F Π・ヤコビの楕円関数、ランベルトの W 関数。一覧はアプリの「書き方のヒント」。数式キーボードの「特殊」タブに全部あり、◀ ▶ でページ（ガンマ・ゼータ/erf・積分・ベッセル・多項式・超幾何/楕円・その他）をめくる
- 座標系（極座標・球座標・自作）: ⚙ 設定 →「座標系」で座標系を作り、式の ⚙ →「座標系」（または設定のチェック）で式ごとに選ぶ
  - 自動の極座標・円柱座標・球座標: 座標系を選んでいない式で θ・φ・ρ を使うと（`r = θ` など）、座標系を作らなくても自動で座標系を使う
    （`coords.ts` の `autoCoord`）。2D 表示では極座標 (r, θ)、3D では φ か ρ があれば球座標（r または ρ, θ, φ）、無ければ円柱座標 (r, θ, z)。
    自動のときの角度は Desmos と同じく、θ が xy 平面で x 軸からの角、φ が z 軸からの角（上で選ぶ「球座標」とは θ と φ が逆）。
    x・y を使わない r だけの式（`z = sin r`・2D の `r = 2`）も同じ。θ・φ・ρ・r と同じ名前のパラメータ・定義がある式、関数の定義 `f(θ) = …`、組 `(…)` は対象外。
    例: アルキメデスのらせん `r = θ`（2D）・らせんの壁（3D）、バラ曲線 `r = cos 2θ`、リマソン `r = 1 + 2cos θ`、花の形の領域 `r ≤ 2 + cos 5θ`、
    `z = r cos θ`、でこぼこの球 `r = 1 + sin 3θ sin 4φ / 3`、`ρ = 2`
    - 半径は表示範囲の箱が全部入る所まで作る（表示範囲に追従）。等式で r・θ だけの式（極座標の曲線と、それを縦に延ばした面）は負の半径も描く
      （リマソンの内側の輪）。不等式・z を使う式・球座標は r ≥ 0 だけ
    - θ の範囲は式の下の欄で変えられる。初期値は、θ が三角関数の中にしか出てこなければ 0〜2π、外にも出てくれば（らせん）何周も描けるよう 0〜12π。
      φ は 0〜π。式の下に「極座標で描いています」と出る
  - 座標系で移した後に長くなる線分・三角形は、座標の値の空間で等分して細かくしてから移す（`coords.rs` の `refine`）。図形は座標の値の空間の
    一様な格子で作るので、極座標の r が大きい所（らせんの外側）で角ばっていた。線は線分ごとに、移した先の大きさの 1/800 以下になるまで（1 本 64 等分まで）。
    面は継ぎ目にひびができないよう、全部の三角形を同じ k で k² 個に分ける（移した先の大きさの 1/150 以下になる k。8 まで、三角形 16 万個まで）
  - 座標系は、座標の値 q = (x, y, z) を空間の点 T(q) へ移す写像。円柱座標（2D 表示では極座標）は T = (x cos y, x sin y, z)、
    球座標は T = (x sin y cos z, x sin y sin z, x cos y)（y が z 軸からの角 θ、z が xy 平面での角 φ）。自作は 3 つの式を自分で書く（パラメータも使える）
  - ほかに用意してある座標系（設定の「＋ 座標系を足す」）: 楕円柱（μ, ν, z。2D 表示では楕円座標）、放物柱（σ, τ, z）、双極（σ, τ, z。アポロニウスの円）、
    対数極（ρ, θ, z。r = e^ρ）、放物線（σ, τ, φ。放物面）、長球（μ, ν, φ。ラグビーボール形）、扁球（μ, ν, φ。みかん形）、トーラス（σ, τ, φ。入れ子のトーラス）、
    ねじれ（高さに比例して xy 平面が回る）。それぞれの式・範囲は設定で書き換えられる
  - 式は x, y, z か、座標系の座標の名前で書く（円柱は r, θ, z、球は r, θ, φ。設定で変えられる。英字 1 文字か θ・φ・ρ・σ・τ・μ・ν）。
    球座標の `r = 2`（`x = 2` と同じ）は半径 2 の球、`(t, t, t)` はらせん。式の説明も `r = f(θ, φ)` のように座標の名前で出す。
    座標の名前は、同じ名前のパラメータより優先する。θ は `theta` と打つか、数式キーボードの「abc」タブで入れる（φ は `phi`、ρ は `rho`、σ は `sigma`、τ は `tau`）。
    μ・ν は数式キーボードから入れる
    曲線は `(t, t, t)` と書く（`(u, u, u)` は u だけでも曲面と読まれ、つぶれた曲面になる）
  - 「移行」のスライダー s（0〜1）で、(1 − s) q + s T(q) を描く。0 は座標の値をそのまま直交座標とみなした絵、1 は座標系で移した絵。
    ▶ で 1 まで動かして止まる（1 にいるときは 0 まで）。計算エンジンは頂点ごとに T(q) を一緒に返すので、s を動かしても式を計算し直さない（法線は混ぜた形から作り直す）
  - 座標系ごとに「作る範囲」（座標の値の範囲。円柱は 0 ≤ r ≤ 5・0 ≤ θ ≤ 2π・−5 ≤ z ≤ 5、球は 0 ≤ r ≤ 5・0 ≤ θ ≤ π・0 ≤ φ ≤ 2π）を持つ。
    図形はこの範囲で作り、範囲の外にはみ出した所は計算エンジンが切り落とす。画面の箱（表示範囲）は今までどおり。r の範囲を負まで広げると、
    r < 0 の所も描く（極座標のバラ曲線 r = cos 2θ の 4 枚の花びら）
  - 作る範囲の欄の「表示範囲」に印のある座標は、表示範囲（設定の「表示範囲」の x, y, z）と同じ範囲で作り、表示範囲を変えると追従する
    （半径 r は 0 〜 端の大きいほう）。新しく作った座標系では、長さの座標（直交の x, y, z・半径・高さ）に最初から印が付く
    （角度は用意した範囲のまま）。前は ±5 などの決まった範囲だったので、座標系を選ぶと図形の広がりが表示範囲と食い違っていた。
    印を外すと、そのときの値から自由に書ける。範囲を指定した例（負の半径も描くバラ曲線）は、印を付けない
  - 回転は座標の値の空間でかかる（移した後の図形は、視点を回して見る）。座標系を使う式には、切り口のふたを作らない。
    伝達関数・霧の見せ方とは一緒に使えない
  - 格子線は座標の値に沿って引く（球座標なら緯線・経線になる）
  - 座標系の格子（座標曲線）: 作る範囲の箱の面（既定は 3 つ目の座標が最小の面。設定で選べる）の上で、座標を 1 つだけ動かした線を 8 等分ごとに引き、
    図形と同じ移行の値で一緒に曲げる。2D 表示の極座標では、方眼が同心円と放射線に変わる。座標系を使う表示中の式があるときだけ描く
- 式の追加・削除・色変更・表示切り替え、表示範囲と細かさの変更
  - 色は、よく使う色と「カスタム」（彩度・明るさの面、色相の帯、16 進の入力）から選ぶ。カスタムは今の色から始まる
    （ブラウザの色選択は、スマホで「カスタム」を開くと今の色から始まらないことがあるので、アプリの中に作った）
- サンプル: 最初は空の式だけ。「サンプル（タップで追加）」から例をタップすると、一覧の最後に追加される（今ある式は消さない）

  - 「共有リンクをコピー」は、状態（名前も）を圧縮して URL の # の後ろに入れたリンクを作る。リンクを開いた人の一覧には、新しいグラフとして入る
  - グラフを切り替えるときは、計算・再生の状態を確実に入れ替えるため、ページを読み込み直す。前の版の 1 つだけの自動保存は、最初に開いたときに一覧の 1 つ目のグラフになる
  - 一覧はこのブラウザだけのもの（別の端末へは共有リンクで渡す）。保存できない（容量がいっぱいなど）ときは、一覧の画面に出す

## 描画を軽くする工夫

- 画素密度はスマホでも 2 倍までに抑える
- 視点を動かしている間（Desmos と同じく、重いグラフでも視点はなめらかに動かす）:
  - 1コマが遅いときだけ、画素密度と細かさを段階的に下げる（`web/src/lib/motionQuality.ts`）。60 コマ/秒を保てる間は、
    止まっているときと同じ絵のまま。段階は「重い面だけ粗い版にする → 画素密度を 1.5 倍 → 1 倍 → 0.75〜0.3 倍に下げる」の順。
    粗い版にするのは三角形の多い面から順に、細かいままの三角形が 15 万個以下になるまで（軽い式は、重い式と一緒に表示していても細かいまま）。
    下げても 1 コマの時間が 15% 以上縮まなければ（三角形の数で重い場面では、画素密度を下げても速くならない）、元に戻して、その操作の間はもう下げない。
    余裕が 45 コマ続けば1段戻してみて、遅くなったら、その操作の間はもう戻さない。
    ⚙ の「見え方」の「視点を動かしている間の画質」で、自動・くっきり（画素密度は下げず、重い面の粗い版だけ）・常にそのまま（何も下げない）を選べる
    （端末ごとに向きが違うので、共有リンクには入れず、そのブラウザにだけ覚える）。
    操作が終わったときの段階を覚えておき、次の操作はそこから始める。止まったら元の画素密度・そのままの版で描き直す。
    形を差し替えたコマ（回転の再生など。受け渡しと GPU への転送の時間）と、視点が跳んだコマ（2D / 3D の切り替えなど）は数えない
  - 粗い版: 三角形が 6 万個を超える曲面は、計算担当が粗い版（約 3 万個）も作っておく。頂点は同じものを使い、
    三角形の頂点番号だけが違う。格子の曲面は点を間引く。陰関数は、計算済みの F の格子を 2 か 4 個おきに間引いた格子で
    Surface Nets をもう一度走らせて作り直す（自分の頂点を持つ。頂点をまとめる方法と違い、面が重なったり欠けたりしない）。
    段差のある陽関数（階段など）は、まとめると段差と壁が崩れるので、粗い版を作らない
- ホイールの拡大縮小: 1目盛りで約 1.25 倍。目盛りの分をためて、0.1 秒ほどでならして動かす（操作 A・B とも同じ。
  操作 A の中ドラッグも、B の右ドラッグと同じく押した位置に向かって拡大縮小する）
  - スライダー・回転の再生で形が変わっているだけ（視点は止まっている）ときは、粗い版にせず、画素密度も下げない
    （遅いのは計算のほうなので。下げると、動いていない軸・枠・方眼までぼやける）
- 何も変わっていないときは描かない（止まっているときに電池を使わない）
- 曲面の表と裏は 1 つのメッシュで描き、裏面はシェーダーで暗くする
- 目盛りの文字は HTML ではなく WebGL のスプライトで描く（回すたびに HTML を書き換えない）
- 4 次元の回転などで形だけが変わるときは、材質（シェーダー）を使い回して形のデータだけ差し替える
- スライダー・複素平面を動かしている間と回転を再生している間は、式ごとに測った計算時間から、1回の計算が 12 ms に収まる細かさを決める
  - ただし、前の返事が点の使い回し（射影だけし直し）だった式は、細かさを下げずに一度計算する。回転の再生・回転角のドラッグでは、
    あとは射影し直すだけなので、操作が終わるまで粗い形のまま回すことにならない
  （`web/src/lib/budget.ts`。計算時間は細かさの2乗（曲面）・3乗（陰関数）に比例するとみなす）。軽い式は細かいまま。指を離したら、粗く計算した式だけを細かく計算し直す。
  媒介変数表示の図形は軽いので細かいまま回せて、回転の再生では点を計算し直さず射影だけし直す。
  画素密度は、視点を動かしているときと同じ段階で決める（いつも下げるのではない）
- 止まっているときの計算でも、細かい計算が 120 ms を超えそうな式（細かさ 200 の陰関数など）は、先に 40 ms ほどで済む粗い版を出し（「計算中」と出る）、
  続けて細かく計算して1回だけ差し替える
- 非表示の式は計算しない（表示したときに計算する）
- 計算担当の Worker を CPU のコア数に合わせて最大 4 つにし、式ごとに担当を分けて並列に計算する
  - 重い陰関数・範囲で重ねた立体（前回、F の計算に 30 ms 以上かかった式）は、F の計算だけを全部の Worker に分ける。
    担当の Worker が F を計算する点を「かたまり」（密な格子なら 1 層、まばらなら 32,768 点）に分け、かたまりを Worker の数で
    等分して計算し、担当の Worker が値をつなげてメッシュを作る。かたまりの切れ目はいつも同じなので、分けても形は同じ。
    `abs(gamma(x + i y)) = z`（細かさ 80、Worker 3 つ）で約 220 ms → 約 130 ms
- 式の計算（`core/src/eval.rs`）:
  - 同じ計算（2か所に出てくる `sin(u)` など）は1回だけ行う。媒介変数表示では、成分どうしでも共有する
  - 定数だけで決まる部分は、コンパイルのときに計算しておく。媒介変数の一部を固定した面（立体の6つの面・多変数の図形の面）では、
    固定した媒介変数だけで決まる部分もまとめて定数にしてから計算する
  - 値は複素数で計算するのが基本だが、式の定数がすべて実数で、関数が初等関数だけなら、まず実数だけで計算する。
    実数に収まらない所（`sqrt` の中が負など）や、有限でない値が出た所（256 点ごとのまとまり）だけ、複素数で計算し直す。
    結果は複素数で計算したときと（丸め誤差を除いて）同じ。陰関数（細かさ 200）で約 0.97 秒 → 0.60 秒
  - 256 点ごとのまとまりで「有限でない値が出たか」を確かめる足し算を、8 本に分けて足す（1 本だと、足し算が前の結果を待つ鎖になり、
    確かめるほうが計算より遅かった）。2〜4 乗は `powi` を呼ばずに掛け算にする（`powi` と同じ順番に掛けるので、値はビットまで同じ）。
    多項式の式で式の計算が 10 倍ほど速い（細い輪 `(sqrt(x^2+y^2)-3)^2+z^2 = 0.0025` で 93 ms → 6 ms、ネイティブ）
  - 三角関数・指数などの重い関数は、引数のビット → 値を小さな表（64 個）に覚え、同じ引数なら覚えた値を使う。格子の行の上では、
    1 つの座標だけの式（ジャイロイドの `cos(y)`・`sin(z)`、陽関数の `cos(y)`）の引数が同じまま続き、陰関数のブロックの中では
    x の値（9 通り）が行ごとに繰り返し出てくるので、その分を省ける（同じ引数なら同じ値なので、結果は変わらない）。
    ジャイロイドの式の計算で、細かさ 80 は 33 ms → 20 ms、細かさ 200 は 124 ms → 93 ms（ネイティブ）
  - 点の少ない呼び出し（二分法・細分で数点ずつ計算する所）では、作業領域を点の数だけにして、呼び出しをまたいで使い回す
  - 引数が実数のガンマ関数・`nCr`・`nPr`・ベッセル関数 J（級数とシュレーフリの積分）は、同じ計算を実数だけで行う
    （値が有限でない所は、今までどおり複素数で計算する）。ベッセル関数 J₀ の膜のサンプルで約 260 ms → 125 ms（ブラウザ）
- 陽関数の、格子より細い山・谷を区間演算で探す所（`hidden_features`）: 区間演算の回数の上限（3 万回）を、命令が 40 個を超える式では
  命令の数に反比例して減らす（下限 2,000 回）。項がたくさんの総和や積分を和にした式は、命令が数百〜数千あって 1 回が重いうえ、
  区間が広がりすぎてどの箱も疑わしくなり、上限まで使い切っていた。`@sum(n, 1, 200)(sin(n x)/n)` で 0.85 秒 → 0.37 秒、
  2 重の定積分で 1.35 秒 → 0.61 秒（ブラウザ）。ふつうの大きさの式（命令 40 個以下）は今までどおり
- 陽関数を表示範囲の上下の端で切る所（`mesh.rs` の `clip_to_height_range`）: 三角形ごとに配列を作っていたのをやめ、
  点の高さと上下の位置を 1 回だけ求めて使い回す（切るものが無い式でも、陽関数の時間の半分以上がここだった）。
  `z = sin(x) cos(y)`（細かさ 150）で 20 ms → 13 ms、`z = x^2 - y^2` で 21 ms → 10 ms（ブラウザ）
- 陰関数の、小さい図形・細い所の細かい作り直し（`refine_blocks`）: 細かい格子の点の番号から座標を割り算で戻していたのを、
  軸ごとの表にし、Surface Nets の関数も呼び出しを埋め込める形にした（形は同じ）。細い輪（細かさ 80）で 165 ms → 62 ms、
  ローマ曲面 `x^2 y^2 + y^2 z^2 + z^2 x^2 = x y z` で 124 ms → 47 ms（ブラウザ）
- 画面のスレッドが固まらないようにする（実際の画面でサンプルを全部描いて、長いタスク（50 ms を超える処理）を測って直した。
  `?bench=1&set=samples`）:
  - 光線の描き方（3D の陰関数）のシェーダーは裏でコンパイルしているが、three.js は不透明・半透明、描く先（画面 / 描画先のテクスチャ）の
    色空間、シーンの光源の数が違うと別のシェーダーにする。表示した後で不透明度に合わせて半透明にしたり、打ち切りの割合を数えるために
    光源の無いシーンを描画先のテクスチャに描いたりしていたので、重い光線のシェーダーを画面のスレッドを止めてもう一度コンパイルしていた
    （Windows の Chrome で、ヴィヴィアーニの曲線のサンプルが 2.2 秒固まった）。不透明・半透明はコンパイルの前にそろえ（後で変わったら
    裏でコンパイルし直し、その間はメッシュの面を見せる）、打ち切りの割合は、ふつうの画面とシーンのまま左下の小さな範囲に描いて数える
  - 伝達関数の箱のシェーダーも、裏でコンパイルし終えてから見せる（0.77 秒固まっていた）
  - 曲面・切り口・曲線は視錐台の判定をしない（いつも表示範囲の箱の中にある）。three.js は判定のために、新しい形ごとに外接球を
    点を 1 つずつ読んで求めるので、再生中は返事のたびに数十万点の形で数十 ms かかっていた
  - 描く所の大きさは resize のときに覚えて使う（毎コマ `clientHeight` を読むと、DOM が変わった直後には、その場でレイアウトを
    計算し直させてしまう）。GPU の描き方を使うかの URL・端末の判定も 1 回だけにする
  - LaTeX から計算エンジン用の式への変換の結果を覚えておく（計算し直しのたびに全部の行の式を変換していた。範囲の欄が変わったら捨てる）
- 計算エンジンの WASM: 1 つの単位でまとめて最適化し（`codegen-units = 1`）、パニックでは止めるだけにして（`panic = "abort"`）、
  デバッグ情報を消す（`strip = "debuginfo"`）。2.59 MB → 2.13 MB（gzip で 801 KB → 753 KB）、計算も数 % 速い。
  関数の名前の表まで消す `strip = true` ならさらに 0.2 MB 小さくなるが、WASM の機能を書いた区画（`target_features`）も消えて、
  wasm-bindgen が使える機能を判定できなくなる（ビルドで警告が出る）ので、使わない
- 陰関数の、曲面の無い所を飛ばす（`core/src/interval.rs` の区間演算）: 格子を 1 辺 8 マスのブロックに分け、ブロックの箱の上で F が取りうる値の範囲を
  区間演算で求める。0 を含まなければ、そのブロックには曲面が無いので、F も計算せず、セルも見ない。
  F の値は、あるブロックとその周りの1点だけで計算して持つ（細かさ 200 の球で、値を持つ点は全体の 1/5 以下）。
  区間演算が使えるのは、定数がすべて実数で、関数が初等関数（三角関数・指数・対数・累乗・丸めなど）だけの式。
  使えない式（特殊関数・虚数を使う式）や、ブロックの 6 割以上に曲面がありそうな式は、全部のブロックを計算する（同じ仕組みで、飛ばすブロックが無いだけ）。
  細かさ 200 の球で約 230 ms → 33 ms、トーラスで約 250 ms → 19 ms、ジャイロイドで約 640 ms → 420 ms（ネイティブで測定）。
  `sqrt(x^2 + y^2)` のように 0 以上と分かっている値は、丸めの分だけ広げて下の端が負になっても 0 とみなす（軸の上のブロックも飛ばせる）
- 陰関数の格子の走査: ブロックごとに値を小さな配列に写して（密な格子なら写さずに）、セルの8つの角の符号を1バイトにまとめる。
  四角形を作る辺は、頂点を置いたセルの辺だけを見る。計算担当から画面へ配列を渡すときのコピーは1回にする（getter ではなく取り出す）
- 陰関数の「符号が変わらずに接するだけの所」は、辺を囲むセルの角の符号がすべて同じ所だけで探し、その周りのセルだけで調べる。
  格子の平面にたまたま接するふつうの曲面（`x^2 + y^2 + z^2 = 4` の極など）を誤って拾わないので、
  球（範囲 ±5）は細かさ 80 で約 270 ms → 25 ms、細かさ 200 で約 4.2 秒 → 0.43 秒（ネイティブで測定。ブラウザでは 1.5〜2 倍ほど）

## 画素ごとの描き方（GPU）

3D の陰関数と、2D 表示の陰関数の曲線・不等式の領域は、メッシュ（三角形）を作らずに、GPU で画素ごとに描く
（計画 `docs/plan-hard-tasks.md` 12 章）。格子より細い形・極・段差・接するだけの零点・解が体積を持つ式など、メッシュでは崩れる・消える式が
そのまま描ける。メッシュも裏で作って隠しておき、カーソルの下の点・切り口のふた・書き出しに使う。

- 仕組み: 区間演算で「この範囲に曲面（曲線）がありうるか」を調べる。区間には IEEE 1788 の飾り（定義されているか・連続か）を付け、
  極や段差の符号の変化を零点と見誤らない（Tupper の方法）
  - 3D: 画素ごとにカメラから光線を飛ばし、光線の区間の上の箱で区間演算をして、0 を含まなければ捨て、含めば二分して手前から調べる
    （Mitchell・Knoll の方法）。1 画素の幅まで来たら、連続で符号が逆なら二分法で詰め、そうでなければ 1/16 画素まで詰めて決める。
    法線は二重数（自動微分）の勾配。見た目（光の当て方・格子線・表と裏）はメッシュの曲面と同じ計算
    輪郭はアンチエイリアスする: 当たった画素は、画素の中の 4 点へも光線を飛ばし（まず当たった深さの前後 2 画素分だけ探すので軽い）、
    当たった割合を MSAA の標本に割り振る（alphaToCoverage）。外れた画素は、2 × 2 の画素の組の中で当たる画素と隣り合うときだけ調べる。
    止まっているときだけ（輪郭の画素の光線が最大 5 倍。球で 1 コマ 10 → 26 ms）。値が飛ぶ面（floor の和の立方体）の法線は、
    当たった点の前後 1 画素で値がいちばん変わる軸（輪郭・段差の黒い点々を出さない）
  - 2D: 画素の矩形で区間演算をし、分からなければ 2 × 2 → 4 × 4 に分ける。線は |F| / |∇F| で太さをそろえてなめらかに塗る
- 式は計算エンジンが GLSL に直す（`core/src/eval/glsl.rs`。値・二重数・飾り付きの区間の 3 つ）。3D の陰関数は、回転も断面も入れる前の
  元の座標 x, y, z, w, … の式にし、表示中の座標からの 1 次式とスライダーのパラメータを uniform で渡すので、回転（4 次元の回転も）・
  断面・スライダーを動かしても GLSL を作り直さない
- 使える式: 実数だけで計算できる式で、関数が初等関数（三角関数・逆三角関数・双曲線関数・指数・対数・累乗・`abs`・`floor`・`ceil`・
  `round`・`sign`・`mod`・`min`・`max`・`sinc`）だけのもの。特殊関数・複素数・場合分け・座標系・表示していない座標の見せ方（断面以外）を
  使う式と、陽関数・媒介変数表示は、今までどおりメッシュで描く。使えない式は、式の ⚙ に理由が出る
- 式の ⚙ の「描画の方法」で、自動・メッシュ・画素ごと（GPU）を選べる（共有リンクに入る）。自動は、デスクトップ・ノート PC では画素ごと、
  スマートフォン（タッチが主の端末）ではメッシュ
- URL に `?gpu3d=0`・`?gpu2d=0` を付けると、式の設定によらずメッシュで描く（比べるとき）。`?debug=1` で、光線を打ち切った画素を赤で塗る
- 速さ（RTX 2060・Chrome）: 1920 × 1080 で 1 コマ 4〜39 ms（ジャイロイドが最も重い）。式を入れてから GPU の描き方に切り替わるまでの
  シェーダーのコンパイルは 0.2〜1 秒（その間はメッシュの絵）。視点を動かしている間は光線の回数の上限を下げて軽くし、止まったら描き直す
- Windows の Chrome（GLSL を Direct3D に変換する）向けの工夫: 区間演算を呼ぶ所を 1 か所にまとめ、ループの回数を uniform にして展開させない
  （コンパイルが最大 8 秒 → 0.44 秒）。光線のスタックへの書き込みはループの最後の 1 か所だけ（分かれ道の中で配列に書いた値が残らないことがある）。
  `sin`・`cos`・`asin`・`acos` は組み込みを使わず、精度の良い式で書く
- 検査: `cd web && npm run test:gpu`（ブラウザの WebGL2 で、GLSL の値・区間を Rust と比べる・2D の画像を調べる・3D の光線を Rust の基準の実装と
  画素ごとに比べる。CI では回さない。`tools/gpu-g3`・`gpu-g4`・`gpu-g5` の README）

│       ├── special/      特殊関数（ガンマ・ゼータ・ベッセル・超幾何・楕円など）

## 数式の書き方

入力欄は数式入力ライブラリ [MathLive](https://cortexjs.io/mathlive/) を使っていて、分数やべき乗が数式の見た目のまま表示される。

- `/` で分数、`^` でべき乗（右矢印キーで抜ける）、`(` で括弧（閉じ括弧は自動）
- `pi` → π、`sqrt` → √、`sin` などの関数名は自動で変わる
- スマホでは入力欄を押すと数式用のキーボードが出る（123 / 変数 / f(x) / ∑∫∈ / 特殊 / abc のタブ）。
  「行列」のタブには、行列・列ベクトル・行列式の雛形（2×2・3×3）と、det・tr・rank・転置・逆行列・べき・共役転置・ker・成分、
  直前の文字をベクトルの名前にする v⃗（F の後に押すと F⃗）、ベクトル場の定義 F⃗(x, y, z) = (…)、内積・外積・⟨,⟩・‖‖ をまとめた。
  `\operatorname{tr} A`・`\det A`・`\operatorname{rank} A` だけの行は、説明に値が出る（`tr = 5`）。
  長押しで出る別の候補は、長押ししたまま指を候補の上へ動かして離すと入る（候補の外で離すと何も入らない）。
  キーの名前の吹き出しは、候補の欄と重ならないように、その上（場所が無ければ横）に出す。
  「(」の長押しで `{ }`・`[ ]`・`⟨ ⟩`・`{ | }`、「)」の長押しで `}`・`]`、「f」の長押しで F⃗・F⃗(x, y, z)、「x₂」の長押しで v⃗。
  「∑∫∈」のタブには、微積（Σ・Π・定積分・微分・差分・2 重積分・3 重積分・場合分け）、積分（範囲の次元ごとの段: 定積分と線積分、
  2 重積分と面積分、3 重積分。どの段にもスカラー場 f ds・f dS とベクトル場 F · dr・F · dS の形があり、∮・∯ は長押し）、
  範囲（集合 {(x, y) | …}・等式の曲線と曲面・区間の直積・媒介変数表示の曲線・曲面・極座標・立体・円や球面の例）、ベクトル（組・内積・外積・∇・発散の体積分 ∭∇·F）、
  方程式（点での値など）、漸化式（数列の定義・数直線・クモの巣図・軌道・近接網・分岐図）、集合と論理（{ | }・区切りの縦線 ∣・∈（長押しで ∉）・∩・∪・XOR・NAND・NOR・ℝ・区間）の雛形がページにまとまっている（◀ ▶ でめくる。長押しで名前）。
  集合の区切りの縦線を消してしまったら、「∣」のキーか、ふつうの `|` で打ち直せる（括弧の外に 1 本だけある `|` は区切りとして読む）。
  「123」のタブには関数の名前 f・g がある（長押しで f(x)・g(x)・h。階乗 ! は「xⁿ」の長押しと「f(x)」のタブ）。
  入力欄の指数と下付き（積分の範囲・添字）は、MathLive の標準（本文の 70%）より大きく描く。
  積分の範囲は、積分記号の下に名前（D・C・V・S・Ω など 1 文字。自由）だけを書き、範囲そのものは式のすぐ下に出る「D =」の欄に書く
  （`\iint_{D} xy\,dA` と、D = `\{(x,y) \mid 0 \le x \le 1,\ 0 \le y \le x\}`）。同じ名前はどの式でも同じ範囲を指し、片方で直せば全部に効く。
  範囲の欄の右の「表示」を押すと、その範囲がグラフに半透明で描かれる（平面の領域は高さ 0 の面、曲線・曲面はそのまま。
  範囲を書き換えると追従し、その範囲を使う式が無くなると消える。もう一度押すと消える）。積分記号の下に範囲を直接書いた式
  （`\int_{\{(t, t^2) \mid 0 \le t \le 1\}} f\,ds`・`\iint_{[0,1]\times[0,2]}`）には「範囲を表示」のボタンが出て、同じように描ける
  （直接書いた範囲が 2 つ以上あれば「範囲を表示 1」「範囲を表示 2」）。
  積分のある式の下の「∫ 積分を描く」を押すと、被積分関数を積分する範囲の上に描く（面積・体積が積分の値になる図形。もう一度押すと消える。
  式や範囲を書き換えると追従する）。式から描くための式を作って、ふつうの式と同じ道で描く（`web/src/lib/latex.ts` の `integralDisplay`）:
  - 1 変数の定積分 $\int_a^b f\,dx$: 2D 表示では曲線と軸の間（高さ 0 の面。軸より下は負）。3D 表示では、線積分と同じく、横の軸の上に立てた高さ $f$（z の向き）の幕
  - 2 重積分（$\iint_D f\,dA$・累次積分 $\int\int f\,dy\,dx$）: 領域の上の、高さが $f$ の立体 $\{(x,y,z) \mid (x,y) \in D,\ \min(0,f) \le z \le \max(0,f)\}$。
    範囲が変数の式（$1 \le x \le y,\ y \le 3$）でも、条件をそのまま不等式として描くので、そのまま描ける
  - 3 重積分: 領域の中を、$f$ の値の色の霧で塗る（陰関数の F の値の伝達関数。赤は正・青は負で、$|f|$ が大きいほど濃い）。$f$ が定数なら、領域そのものを描く
  - 平面の曲線の上の線積分: 曲線の上に立てた、高さが $f$ の幕（$\mathbf F \cdot d\mathbf r$ は接線の成分 $\mathbf F \cdot \mathbf r' / |\mathbf r'|$）。極座標などで書いた平面の領域は、高さが $f$ の立体
  - 曲面の上の面積分: 曲面を、法線の向きに $f$ だけ厚くした立体（$\mathbf F \cdot d\mathbf S$ は法線の成分 $\mathbf F \cdot \mathbf n$）
  - 空間の曲線の上の線積分: 曲線に沿った帯。幅が $f$（$\mathbf F \cdot d\mathbf r$ は接線の成分）で、曲線に垂直なうち、いちばん上を向いた向き
    $\mathbf N = (\mathbf e_z - (\mathbf e_z \cdot \mathbf T)\mathbf T) / |\cdots|$ に広げる（$\mathbf N \perp \mathbf r'$ なので、帯の面積がちょうど積分の値）
  - 媒介変数 3 つの立体の上の積分（体積分）: 立体そのもの。被積分関数が $\nabla \cdot \mathbf F$ なら、説明にガウスの発散定理（境界の面の外向きの面積分 $\oint \mathbf F \cdot d\mathbf S$ と同じ値）を出す
  - 等式で書いた曲線・曲面（$\{(x,y) \mid x^2+y^2=1\}$）: 曲線の上の幕・法線の向きに厚くした殻・空間の曲線そのもの（下の「線積分・面積分・体積分の範囲の書き方」）
  - 図を出すと、積分する経路・領域そのもの（範囲全体）も一緒に薄く描く。範囲を名前で書いた形（∫_C と C の欄）でも、
    積分記号の下に直接書いた形でも同じ。1 変数の定積分は横の軸の上の線分、
    平面の領域は高さ 0 の面。3 重積分・媒介変数 3 つの立体は、図そのものが立体なので重ねない
  - **進み具合のスライダー（学習用）**: 図を出している間、式の下に、積分の変数 1 つ（媒介変数の積分なら最初の媒介変数、累次積分なら外側の変数）の
    スライダーと ▶ が出る。範囲を「下の端 〜 下の端 + s(上の端 − 下の端)」に縮めた図と、そこまでの積分の値（「途中までの積分 = …」）を出す。
    100% のときは、範囲全体の積分の値（「範囲全体の積分 = …」）を出す。曲線の上の $P\,dx + Q\,dy$ は、続く項も含めた値
    ▶ は 0 から 1 まで 6 秒で動かす。線積分・面積分では、途中の点（ほかの媒介変数は範囲の真ん中）に、今の点・接線 $\mathbf r'$（面積分は法線
    $\mathbf r_u \times \mathbf r_v$）の向き・$\mathbf F$ の向き・$\mathbf F$ の接線（法線）の成分を、矢印の線分で添える（長さは表示範囲の 1/6 にそろえる。
    成分の矢印は $\mathbf F$ の矢印と同じ縮尺）。被積分関数がベクトル場の式（$(-y, x, 0)$・$\nabla \times \mathbf F$）なら、その場の矢印も添える
    （定義した場の名前 F⃗ だけなら、定義の行がもう描いているので重ねない）。値は画面側で、範囲を縮めた積分の式を計算エンジンで計算する
  - まだ描けないもの: 不定積分、積分の変数でない座標が残る積分（$\int_0^x e^{-t^2}\,dt$）。
    式に積分がいくつもあるときは、最初の 1 つだけを描く
  - 積分だけの式（値が 1 つの数）は、高さがその値の平面として描かれていて図を隠すので、図を出すときに平面のほうを非表示にする（● で戻せる。図を消すと、図が非表示にした式だけを表示に戻す。もとから非表示だった式・図を出している間に自分で ● を押した式は、そのまま）
  「∑∫∈」の「積分」のページのキー（∫_C f ds・∫_C F·dr・∬_S f dS・∬_S F·dS・∬_D f dA・∭_V f dV など）はこの形で入る（範囲を積分記号の下に直接書く形も、そのまま使える）。
  欄に収まらない長い式は、指で横になぞると送れる（入力中は、長押ししてからなぞると範囲を選ぶ。PC は横スクロールか Shift + ホイール）。
  送った位置は、ほかの式へ移ってもそのまま残る。PC では、式の一覧の右の端をドラッグすると幅を変えられる（ダブルクリックで元の幅）。
  「=」の長押しで < > ≤ ≥ ≠ ∈、「×」の長押しで外積 ×。PC のキーボードでは `!=`（≠）・`=>`（⇒）・`sum`・`prod`・`nabla`・`xor`・`infty` が自動で記号になる
  （`int` は $e^{int}$ を壊すので変換しない）
- 入力欄の LaTeX は `web/src/lib/latex.ts` で計算エンジン用の式に変換している

計算エンジンが読む式の書き方（入力欄からの変換後）:


- 陽関数: `z = x^2 - y^2`（`z =` は省略可）、`y = sin(x) z` なども可。`z = [1, 2] x` のようにリストも使える
- 陰関数: `x^2 + y^2 + z^2 = 4`、`sin x cos y + sin y cos z + sin z cos x = 0`
- 連立方程式・不等式: 括弧の外の `,` で区切る（`y = x, z = 0`）。連鎖も書ける（`y = x = z`・`x ≤ y ≤ z`・`0 ≤ x = y`）。
  不等号は `<`・`≤`・`>`・`≥`（入力欄では `<=`・`>=` と打つ。数式キーボードの `=` を長押し）。`<` と `≤` は 3D では同じ絵になる。
  等式は 3 本まで、不等式は 8 本まで。パラメータの定義は 1 行に 1 つ（`a = 1, b = 2` はエラー）。範囲で重ねる名前は使えない。
  媒介変数表示も不等式で切り取れる（`(cos t, sin t, t), z ≥ 0`）。不等式は射影した後の表示中の座標の式で、
  不等式の中の `t`・`u`・`v` は媒介変数ではなくパラメータとして読まれる。媒介変数表示と等式は一緒に使えない。
  等式の数で形が決まる: 0 本は領域（`x ≤ y ≤ z`）、1 本は曲面（不等式で切り取り。`x^2 + y^2 + z^2 = 4, z ≥ 0` の半球）、
  2 本は曲線（`y = x, z = 0`・`sin(x) = cos(y) = tan(z)`）、3 本は点（`x = y = z = 1`）
- パラメータ: `a = 1`、`c = 1 + 2i`（x, y, z, t, u, v, e, i 以外の1文字）。ほかの式の中で使える
- 関数の定義: `f(x) = x^2`、`g(x, y) = sin(x) y`（名前は x, y, z, w, t, u, v, e, i 以外の1文字）。ほかの式の中で
  `f(2x)`・`g(f(x), y)`・`f(x) + g(x, 1)` のように使える。関数どうしの演算と合成も書ける: `(f + g)(x)`・`(f ∘ g)(x)`（∘ は `\circ`）・`h = f + g`・`h = sin(f)`。
  `y = f^{-1}(x)` は `f(y) = x` として描く（片側がそれだけのときだけ）。
  定義の行そのものも描く（引数 1 つは `y = f(x)`、2 つは `z = f(x, y)`、値が組なら媒介変数表示。引数 3 つ以上は描かない）。

- 総和・総積: `\sum_{n=1}^{10}`・`\prod_{k=1}^{5}`（数式キーボードの「abc」の「和・積分」）。中身は直後の項（掛け算・割り算のかたまり）で、
  `\sum_{n=1}^{3} n x + 1` は $(1x + 2x + 3x) + 1$。範囲は整数で、パラメータを使える（スライダーで項の数を変えるなら、刻みを 1 にする）。
  添字を並べた `\sum_{x,y,z=0}^{n}` は、$x, y, z$ のそれぞれが $0$〜$n$ の多重の和（`\prod` も同じ）。
  項は 2,000 個まで。入れ子（$\sum_n \sum_{m=1}^{n}$）もよい。式の中で項を全部書き並べた式にしてから計算する（200 項でもコンパイルは 1 ms 以下）

  ① そのまま足す（項が和の 10⁻¹⁷ 倍より小さくなるまで。13 万項まで）、② 交代級数なら Cohen・Villegas・Zagier の加速（遠くの項が小さいことを先に確かめる。
  $1 - 1 + 1 - \cdots$ に「自然な和」1/2 を返さない）、③ オイラー・マクローリンの和公式（$\int_N^\infty f$ と $f'$・$f'''$ の補正。N を 2 通りにして比べる）。

- 極限: `\lim_{x\to0}\frac{\sin x}{x}`（数式キーボードの「abc」の「和・積分」）。`x\to a^{+}` は右から、`x\to a^{-}` は左から近づく。
  向きを省いた有限点では左右の結果を比べる。`x\to\infty`・`x\to-\infty` も使える。
  極限だけを 1 行に書くと、元の関数・数列と数値判定を表示する。有限の極限値は 2D では水平線、3D では積分値と同じくその高さの平面になる。
  元の関数は点線、数列は点で描く。結果パネルのチェックで元のグラフと白丸・黒丸の表示を切り替えられる。
  向きを省いた有限点では、左右の収束・発散・振動を別々に示し、左右の値が異なれば「極限なし」と表示する。
  不連続点では、関数値と一致しない有限の極限値を白丸で、定義された値を黒丸で示す。有限の結果は式に組み込める。近づく先と中身には定義やスライダーを使える。
  極限の中身は直後の項で、和・差全体の極限を取るときは括弧で囲む。
  `\lim_{x\to0}\frac{\int_0^x\cos t\,dt}{x}` や `\lim_{x\to0}f'(x+a)` のように、積分、導関数、合成関数も組み合わせられる。
  積分が極限の変数に依存する場合は、標本ごとに適応積分する。極限の内側に別の極限を書くこともできる。
  **数列の極限**は `a_n=1/n` と `\lim_{n\to\infty}a_n`。一般項、漸化式、部分和、`(-1)^n` のような式を整数の添字で調べる。
  添字は `n` または式の中で添字に使う文字から読み取る。`\lim_{k\to\infty,\,k\in\mathbb{N}}` で自然数に限定することもできる。
  **学習表示**は結果パネルの「ε–δ 論法を試す」「ε–N 論法を試す」。ε、δ または N、極限の候補 L を入力すると、条件を満たす標本と反例が見える。
  たとえば $x\to1$ での $2x$ には $\delta=\varepsilon/2$、$1/n\to0$ には $N>1/\varepsilon$ を試せる。
  グラフの判定は有限個の標本に基づく。証明では条件内のすべての点・項に対して不等式が成り立つ理由を示す。
  有限点で分母が 0 になる分数には、可能ならテイラー係数を使う。その他は 2 系列の標本と Aitken の Δ² 法で数値判定する。
  強い振動、遅い収束、桁落ちがある式では判定できなかったり、近似値がずれたりすることがある。
- 場合分け: `\begin{cases} x^2 & x < 0 \\ x & \text{otherwise} \end{cases}`（数式キーボードの「abc」の「括弧・分数」）。
  行ごとに「値 & 条件」で、条件が全部成り立つ最初の行の値になる。条件は `0 \le x < 1` のような連鎖や、`,` で並べた「かつ」も書ける。
  条件を空にするか `otherwise`・`それ以外` と書いた行は「それ以外」（最後の行に書く）。どの行も成り立たない所は描かない。
  選ばれなかった行の値が計算できなくても（`\sqrt{x}` の $x < 0$ など）、結果に影響しない。微分すると値だけを微分する

  - **行列の大きさを、入れ直さずに変える**: カーソルが行列の中にある間、入力欄の下（スマホでは数式キーボードのすぐ上）に
    「行 ＋・行 −・列 ＋・列 −」と今の大きさ（`2 × 3`）の帯が出る。大きさを押すと 6×6 のマス目が出て、押したマスの大きさに一度で変わる。
    キーでは、行列の中で Enter = 下に行、Shift + Enter = 上に行、`,` = 右に列、Tab・Shift + Tab = 次・前の成分

    （大きさを変えている間もエラーにならず、絵が続けて変わる）。Ctrl + Z で戻せる。
    大きさを小さくして外れた成分は覚えておき、大きさを戻す（マス目・最後に行・列を足す）と元の成分が戻る（入力欄ごと。途中の行・列を消したら、それは戻らない）

    | 書いたもの | 描くもの |
    |---|---|
    | ベクトルの等式 $A\mathbf x = \mathbf b$・1 次式の連立方程式 | 成分ごとの等式の連立。全部が座標の 1 次式なら、先に掃き出して独立な等式だけにする（重なった平面 `x + y + z = 1, 2x + 2y + 2z = 2` は平面 1 枚、4 本でも階数が 3 なら点）。矛盾していれば「解がありません」 |
    | `\ker A` | $A\mathbf x = \mathbf 0$ の解（原点を通る点・直線・平面。表示範囲の箱の中だけ。全体なら箱）。成分は数とスライダーの文字 |
    | `\operatorname{Im} A`（`\operatorname{im}`・`Image`・`range` も） | 行全体が `Im` で、引数が成分の全部実数の行列（列が 2 つ以上）なら、列ベクトルが張る空間（像）。キーボードの「行列」タブの Im。それ以外（スカラー・ベクトル・複素数の成分がある行列・式の中の `Im`）は虚部（ベクトル・行列は成分ごと） |

    （`ker A = span{(2, −1)}、(x, y) = t(2, −1)、x + 2y = 0（1 次元。直線）`）。ker は掃き出した $A$ の独立な行が方程式、
    自由変数ごとの解が張るベクトル。Im はピボットの列が張るベクトル、$\ker A^{\mathsf T}$ のベクトル $\mathbf n$ ごとの $\mathbf n \cdot \mathbf y = 0$ が方程式。
    成分が小さい整数の比なら整数で出す。描けない次元（4 次元の中の ker）でも、式は誤りの文に出す
    | 行列式だけの行 `\det A`・`\begin{vmatrix}…\end{vmatrix}`（成分が数の 2×2・3×3） | 列ベクトルが張る平行六面体（2×2 は平行四辺形）。値を式の下に出す（`det = 6`）。体積（面積）が $\lvert\det A\rvert$。成分に座標があれば、今までどおり「縦 = 式」 |
    | 行列の定義の行 `A = (…)`（行が 2 か 3。2×3 のような正方でない行列も）・ベクトルの定義 `\vec{b} = (1, 2, 3)` | 列ベクトル（ベクトル）を原点からの線分で描く |
    | 行列 × 組 `A (\cos t, \sin t, 0)` | ふつうの媒介変数表示 |

    | `\operatorname{eig} A`（`Eig` も。キーボードの「行列」タブの eig） | 固有値と固有空間。説明に、固有値ごとの重複度と固有空間 $E(\lambda) = \ker(A - \lambda I)$ の式（張るベクトル・媒介変数表示・方程式）を出す。固有空間の次元が重複度より小さければ「対角化できない」、実数でない固有値は $\lambda = a \pm bi$ と出すだけ。図には実数の固有値の固有ベクトル（固有空間の基底。長さは表示範囲の 1/3）を矢印で描く。固有値は固有多項式（ファデーエフ・ルヴェリエ）の根（デュラン・ケルナー法）で、近い根をまとめて重複度にし、分母 12 までの分数に近ければその分数にする |
    | `\ker(A - \lambda I)`・`\ker(\lambda E - A)` | 決まった固有値 $\lambda$ の固有空間（直線・平面として描く）。行列との足し算・引き算の中の `I`・`E`（とその倍 `3I`・`\lambda E`）は単位行列 |

    `\dim\ker A`・`\dim\operatorname{Im} A`・`\operatorname{rank} A` は数になる（式の中で使える）

    $T(\mathbf q) = A\mathbf q$ の座標系ができる。ほかの式の ⚙「座標系」で選ぶと、その式が変換され、格子も一緒に変形する。

- **数列**: `a_n=1/n^2`（一般項）、`a_{n+1}=a_n^2+a_1` や `a_{n+1}=\log{a_n}+a_1`（漸化式）。
  初項は別の行に `a_1=1` のように書くとスライダーになる。左辺にも `a_{n+1}^2`、`\log{a_{n+1}}`、`\ln{a_{n+1}}` を使える。
  左辺の正の整数乗は根の主値、`\log` は底 10、`\ln` は底 $e$ の逆演算で項を求める。
  `\frac{a_{n+1}}{2}=\sin a_n+1` のように、求める項を分数の分子に書ける。分母が 0 になる添字では、その規則から項の値は決まらない。
  左辺の添字には `2n` や `2n+1` のような整数係数の一次式が使え、偶数項と奇数項を別々の行で定義できる。
  `(a_{n+1})(a_n)=6` も漸化式になる。同じ数列の各添字で `n` の係数が等しければ、右辺を他の因子で割って最大の添字の項を求める。割る因子が 0 の場合、その規則から項の値は決まらない。
  積そのものを点で描くには、`b_n=(a_{n+1})(a_n)` のように別の数列として定義する。
  右辺には `a_1`、`a_{2n}`、`a_{\lfloor n/2\rfloor}` など整数になる添字を書ける。計算に必要な項をたどり、循環する参照はエラーになる。
  一般項に座標を書けば関数の列になる（`a_n=x^n/n!`、`z=a_3`）。定義の行は、横の表示範囲内で求められる点 $(n,a_n)$ を最大 2,000 点描く。
  値が実数でない項があれば、
  複素平面の点 $(\operatorname{Re} a_n, \operatorname{Im} a_n)$ を順に結んだ軌道。数列の名前は座標と同じ文字でもよい
  （`z_{n+1}=z_n^2+x+iy`、`z_0=0` のもとで `\left|z_{20}\right|=2` がマンデルブロ集合の縁）。
  部分和は Σ と組み合わせる（`s_{n}=\sum_{k=1}^{n}a_{k}`）。
  数列の行の「項の表」で、表示範囲の添字・値・規則に代入した添字を確認できる。
  場合分けの条件が項ごとに決まる漸化式では、当てはまる式だけを使う。たとえば $a_0=1$ と $a_n=a_{n-1}+2$ を一つの場合分けに書ける。
  `\operatorname{cobweb}(a_1,12)` で、$a_1$ から12回分の階段図を描く。$(a_n,a_n)$ から $(a_n,a_{n+1})$ を経て $(a_{n+1},a_{n+1})$ へ進む。
  $a_{n+1}=f(a_n)$ なら、`y=f(x)` と `y=x` を重ねると固定点への近づき方を追える。「数列」のサンプルで初項と係数を動かせる。
  **連立漸化式の軌道**は、`a_0=3`、`b_0=0`、`a_{n+1}=0.88a_n-0.42b_n`、`b_{n+1}=0.42a_n+0.88b_n`、`N=24` を別の行に入力し、`\operatorname{orbit}(a_0,b_0,N)` で描く。
  $N$ は反復回数（0〜512 の整数）。$N=0$ では開始点だけを描く。整数刻みのスライダーで反復を追える。
  3 次元では開始項を 3 個並べる。同じ数列の連続した項を使う `\operatorname{orbit}(a_0,a_1,N)` も描ける。
  - **数直線上の移動**は `\operatorname{orbit}(a_0,N)`。右への移動は数直線の上、左への移動は下に弧を描く。最後の項は点で示す。
  - **複素数列の軌道**も `\operatorname{orbit}(a_0,N)`。複素数の項があれば実部を横、虚部を縦に取る。`\operatorname{orbitpoints}(a_0,N)` なら点だけを描く。初項は `a_0=2+i` のように書ける。複数の開始項で座標を指定するときは、それぞれ実数列にする（例 `u_n=\operatorname{Re}(a_n)` と `v_n=\operatorname{Im}(a_n)`）。
  - **行列での反復**は `\operatorname{orbit}(A,(1,2),N)`。定義した正方行列 $A$ を初期点に繰り返し掛ける。3 次元は 3×3 行列と 3 成分の初期点を指定する。`\operatorname{eig}(A)` を重ねると実固有ベクトルの向きと比較できる。
  - **軌道の点群**は `\operatorname{orbitpoints}(a_0,b_0,N)`。開始項を 1〜3 個指定し、0〜8,192 回反復できる。
  - **リカレンスネットワーク**は `\operatorname{recurrence}(a_0,32,0.1)`。横軸は添字、縦軸は項の値。開始項から最大 128 個の連続した項を表示し、値の差の絶対値が指定距離以下の点を弧で結ぶ。
    複素数列の頂点は 3D の $(n,\operatorname{Re}a_n,\operatorname{Im}a_n)$ に置き、辺は複素平面での距離 $\lvert a_i-a_j\rvert$ で決める。
  - **分岐図**は `\operatorname{bifurcation}(f,0.2,2.5,4)`。`f(x,r)=rx(1-x)` のような二変数関数を別の行で定義する。横軸のパラメータ $r$ を 401 通りに取り、各 $r$ で同じ初期値から反復し、最初の 400 回の後に得た 48 項を縦軸に置く。
  数式キーボードの「∑∫∈ → 漸化式」に各入力キーがあり、「数列」にロジスティック写像・グモースキー・ミラ写像・ホパロンなどのサンプルがある。
- **常微分方程式**（解法は刻み幅を自動で決めるドルマン・プリンス法。同じ入力なら同じ絵）
  - 連立: 行ごとに「座標′ = 式」を `,` で並べる（`x'=10\left(y-x\right),\ y'=x\left(28-z\right)-y,\ z'=xy-\frac{8z}{3}`）。
    独立変数は $t$ で、範囲は媒介変数の範囲の欄（既定 $0 \le t \le 2\pi$）。`\dot{x}`・`\ddot{x}`・`\frac{dx}{dt}` も同じ。

  - 1 本: `y'=x-y`・`y''+y=0`・`2y'+4y=8`（最も高い階の導関数について 1 次式なら、計算エンジンが解いた形にする。
    `\frac{d^{2}y}{dx^{2}}` も同じ）。独立変数は横の座標で、表示範囲の横の幅を解く。1 階なら、傾きの場（同じ長さの短い線分）も描く
  - 初期値は、式の下の欄（`x(0) =`・`y'(0) =`）。空欄なら、座標は 1、導関数は 0。初期時刻は、範囲に 0 があれば 0、無ければ範囲の始まり。

  - 状態が表示範囲の 8 倍の箱を出たら、そこで止める（$y' = y^2$ の発散など。エラーにはしない）。1 本 20 万歩・合計 100 万歩で打ち切る（説明に出す）

  （印刷物の太字・手書きの矢印・黒板の二重線のどれで書いてもよい。v⃗ の長押しで 𝐅・𝔽）。定義の行の説明・ボタンなどの画面の文字では、ベクトルの名前を「ベクトル F」と出す（矢印を重ねる文字や太字の数学用文字は、スマホの字体によって □ になるため。キーの表示は MathLive の数式の字体で描く）。値が組の関数は、名前だけで書くと座標 x, y, z に当てはめた場になる（`\vec{F}` だけの行は矢印の場、
  `\vec{F}\cdot\left(1,0,0\right)` は場の成分）。値がスカラーの関数は、今までどおり f(x) のように引数を書く
- **スライダーの値の条件**: パラメータ（スライダー）だけの不等式の行（`ab>1`・`0<a<1,\ ab>1+\frac{3\pi}{2}`・`a<b\land b<2`。
  連鎖・`,`・`\land` で並べてよい）は、図形を描かずに**条件**になる。スライダーを動かして、いま成り立っている条件が成り立たなくなる値にしようとすると、
  境目の手前で止まる（前の値と新しい値の間を二分法で詰めるので、どんな式の不等式でもよい。止めた値は、書いても条件が成り立つ桁数で書く）。
  スライダーの下の帯に、動かせる所（色）と動かせない所（灰色）を出す。いま成り立っていない条件は、動かすのを止めない（説明にそう出す）。
  条件の行を非表示にすると、条件を使わない。座標（x, y, z）を使う不等式は、今までどおり領域
- **∞ までの総和（座標を含む式）**: `\sum_{n=0}^{\infty}a^n\cos\left(b^n\pi x\right)`（ワイエルシュトラウス関数）のように中身に座標があるときは、
  表示範囲の決まった 257 点で項の大きさを調べ、項の最大がそれまでの和の $10^{-9}$ 倍より小さい項が 4 つ続いた所で打ち切った和を描く
  （説明に「Σ の ∞ は n = 32 までの和」と出す）。400 項までに小さくならない級数（$\sum \frac{\sin nx}{n}$ など）は 400 項で打ち切り、そう書く。
  値が数になる ∞ の和は、今までどおり級数の加速で計算する。サンプル「ワイエルシュトラウス関数」は、条件 $0 < a < 1$、$ab > 1 + \frac{3\pi}{2}$ でスライダーを制限する
- **点を押すと値が出る**（⚙ 設定 →「操作」の「グラフを押したら値を出す」。標準はオフで、このブラウザに覚える。タッチで操作すると印が出て見づらいため）: オンのとき、グラフの曲線・曲面をクリック（タップ）すると、押した所に印を付けて座標の札を出す（ドラッグ・2 本指の操作は押したことにしない。
  何も無い所を押すと消える）。陽関数の行（`y = f(x)`・`z = f(x, y)`）は、押した横・奥の座標で式の値を計算し直して、縦の座標を正確な値にする。
  陽関数では、計算エンジンが表示範囲の中の**注目する点**（1 変数: 極大・極小・零点・縦軸との交点、2 変数: 極大・極小・鞍点）を求めておき
  （`core/src/critical.rs` の `points_of_interest`。オフのときと、動かしている間は求めない）、押した式の注目する点を灰色の小さな球で出す。
  球の近く（12 画素以内。ほかの式の点は 6 画素以内）を押すと、「極大 (−2, 4)」「零点・y 切片 (0, 0)」のように種類と正確な座標を出す。
  零点は符号が変わる所を二分法で詰め、詰めても値が小さくならない所（$\tan x$ の極）は除く。重解（符号が変わらない零点）は、極値としてだけ出る
- **定積分の近似（リーマン和・台形則・シンプソン則）**: 1 変数の定積分 `\int_a^b f\,dx` の「∫ 積分を描く」を押すと、「近似」の欄が出る。
  左端・右端・中点のリーマン和、台形則、シンプソン則から選び、分割数 $n$（スライダーは 1〜64、欄には 400 まで）を変えると、
  近似の図形（長方形・台形・放物線の下の領域。青）と、近似の値・正確な値・誤差が出る。▶ で $n$ を 1 から 64 まで増やしていく。
  誤差の減り方（$O(1/n)$・$O(1/n^2)$・$O(1/n^4)$）も添える。シンプソン則の $n$ は偶数に切り上げる。
  図形は 1 つの集合で、$\Delta x = \frac{b-a}{n}$、$K = \min(\lfloor (x-a)/\Delta x \rfloor, n-1)$ として高さ $f(a + (K + c)\Delta x)$ の段差の関数の下の領域
  （`web/src/lib/latex.ts` の `riemannDisplay`）。近似の値は $\Delta x \sum_{k} f(x_k)$ の式を計算エンジンで計算する
- **テイラー多項式**: `\operatorname{Taylor}\left(f, x, a, n\right)`（計算エンジンでは `@taylor(f, x, a, n)`。数式キーボードの「∑∫∈」→「微積」の Tₙ）は
  $T_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k$。多変数は `\operatorname{Taylor}\left(f, \left(x, y\right), \left(a, b\right), n\right)` で
  $T_n(\mathbf x) = \sum_{|\alpha| \le n} \frac{\partial^\alpha f(\mathbf a)}{\alpha!}(\mathbf x - \mathbf a)^\alpha$（変数は 3 つまで。$n = 1$ が接線・接平面）。
  $f$ は式か、定義した関数の名前だけ（引数の数を変数の数にそろえる）。1 変数で中心が数なら、係数を式の木の上の打ち切ったべき級数の計算（自動微分の Taylor モード。`core/src/series.rs`）で直接求める（$\tan x$ の 20 次も数 ms）。多変数・特殊関数を含む式は、偏導関数を記号微分で作る。次数は 1 変数で 20、2 変数で 10、3 変数で 6 まで。
  次数をスライダー（刻み 1）にすると、動かして近似が良くなる様子を見られる。係数が数（とパラメータ）だけなら、説明に多項式を出す
  （`T₅(x) = x − x³/6 + x⁵/120`。係数は分母が $10^7$ 以下の分数で書けるなら分数、そうでなければ有効 6 桁）。
  $\sin(xy)$ を $x$ だけで展開したときのように係数に別の変数が残れば、説明は出さずに式として描く。
  導関数の表が無い関数（ζ など）は差分の式で微分するので、高い次数では誤差が大きくなる
- **停留点の分類**: `\operatorname{crit} f`（`@crit f`。1 行にそれだけ。キーボードの「微積」の crit）は、$f$ が使う表示中の座標（1〜3 個）について
  $\nabla f = \mathbf 0$ の点を表示範囲の中で探し、極大・極小・鞍点に分けて説明に出す（`(1, 0): 極小 f = −2（det H = 12 > 0, ∂²f/∂x² = 6 > 0）`）。
  図には点を描く: 1 変数は $(x, f(x))$、2 変数は曲面 $z = f(x, y)$ の上の点、3 変数はその点。
  - 探し方: 表示範囲を格子（1 変数 600、2 変数 48 × 48、3 変数 16³）に分けたマスの中心から、ヘッセ行列 $\mathrm H$ を使ったニュートン法
    （$\mathrm H$ が特異でも進むよう、$(\mathrm H^\top \mathrm H + \mu I)\mathbf d = \mathrm H^\top \nabla f$）で $\nabla f = \mathbf 0$ を解き、近い点をまとめる。
    種のマスより狭く固まった停留点は見落とすことがある（近似。説明に書く）。100 個を超えたら打ち切る（線・面に沿って続いている可能性もあると出す）。判定できない点が 5 個以上なら、停留点が線・面に沿って続いている（孤立していない）可能性を説明に出す（$(x-y)^2$ など）
  - 分け方: 2 変数は $\det \mathrm H$ と $f_{xx}$ の符号、3 変数は主小行列式（シルベスターの判定法）。$\det \mathrm H = 0$ なら「判定できない」（$x^4 + y^4$ の原点など）。
    1 変数は $f''$ の符号で、$f'' = 0$ なら 0 でない最初の高階導関数（8 階まで）が偶数階なら極値、奇数階なら「極値でない」（$x^3$ の原点）
  - 関数の名前だけ（`\operatorname{crit} f`。定義した `f(x, y)`）でもよい。回転・座標系を使っているときは求めない
- 点での値: `\left.f\right|_{x=1,y=2}`（計算エンジンでは `@at(f, x, 1, y, 2)`）。式を展開してから変数に値を入れるので、
  `\left.\nabla\times\vec{F}\right|_{x=1,y=2,z=3}` のように、展開してはじめて座標が出てくる式にも使える
- ベクトル場の演算子（座標は x, y, z）: 勾配 `\nabla f`、発散 `\nabla\cdot F`、回転 `\nabla\times F`（2 成分なら $\partial_x Q - \partial_y P$）、
  ラプラシアン `\nabla^{2} f`・`\Delta f`。`\operatorname{grad}`・`div`・`rot`・`curl` でもよい。直後の項に掛かる（$\sum$ と同じ）ので、
  $\nabla f$ と別のベクトルの内積は `\left(\nabla f\right)\cdot v` と括弧で囲む。定義した関数 `F(x, y, z) = (…)` の名前にも使える
- 積分の全体像（数学としての組み立て）: 定積分・2 重積分・3 重積分・線積分・面積分は、どれも
  「$k$ 次元の範囲 $M$（$\mathbb R^n$ の中の区間・曲線・曲面・領域）の上で、$k$ 次元の大きさ（長さ・面積・体積）について足し合わせる」
  $\int_M f\,d\mu$ の場合分けにすぎない。$M$ を媒介変数 $\mathbf r: D \subset \mathbb R^k \to \mathbb R^n$ で書くと、大きさの要素は
  $d\mu = \sqrt{\det(J^\top J)}\,du$（$J$ は $\mathbf r$ のヤコビ行列。グラム行列式）で、
  $k = 1$ なら $|\mathbf r'(t)|\,dt$（弧長 $ds$）、$k = 2,\ n = 3$ なら $|\mathbf r_u \times \mathbf r_v|\,du\,dv$（面積 $dS$）、
  $k = n$ なら $|\det J|$（変数変換）になる。

  | 範囲の次元 | まっすぐな範囲（$\mathbf r$ が恒等写像） | 曲がった範囲 | ベクトル場の形（向きに依る） |
  |---|---|---|---|
  | 1 | 定積分 $\int_a^b f\,dx$（区間） | スカラー場の線積分 $\int_C f\,ds$（曲線） | $\int_C \mathbf F \cdot d\mathbf r = \int_a^b \mathbf F(\mathbf r(t)) \cdot \mathbf r'(t)\,dt$（接線成分） |
  | 2 | 2 重積分 $\iint_D f\,dA$（平面の領域） | スカラー場の面積分 $\iint_S f\,dS$（曲面） | $\iint_S \mathbf F \cdot d\mathbf S = \iint \mathbf F(\mathbf r) \cdot (\mathbf r_u \times \mathbf r_v)\,du\,dv$（法線成分） |
  | 3 | 3 重積分（体積分）$\iiint_V f\,dV$（空間の領域） | — | （$\iiint_V \nabla \cdot \mathbf F\,dV$ はガウスの発散定理で $\oint_{\partial V} \mathbf F \cdot d\mathbf S$） |

  スカラー場の積分は向きに依らず（$f = 1$ なら長さ・面積・体積）、ベクトル場の積分は単位接線 $\mathbf T$・単位法線 $\mathbf n$ の成分
  $\mathbf F \cdot \mathbf T$・$\mathbf F \cdot \mathbf n$ をスカラー場として積分したもの（$d\mathbf r = \mathbf T\,ds$・$d\mathbf S = \mathbf n\,dS$）で、向きを逆にすると符号が変わる。
  積分記号（∫・∬・∭・∮・∯）は自由に書け、何の積分かは範囲（書き方・次元）と被積分関数の形から決める（∮・∯ は閉じていることを表す記号で、計算は ∫・∬ と同じ）。
  積分のある式の下に、判定した分類（「スカラー場の線積分（弧長についての線積分）」）・範囲の書き方と形（「等式で書いた平面の曲線」）・
  媒介変数で書いたときの式を出す（`web/src/lib/latex.ts` の `integralKinds`）。数式キーボードの「積分」のページは、この表の行（範囲の次元）で
  キーを並べ、どの行にもスカラー場とベクトル場の形がある。「範囲」のページには、集合（等式・不等式）と媒介変数表示の雛形がある
- 線積分・面積分・体積分の範囲の書き方: どの積分でも、範囲は**集合の書き方**（等式・不等式）でも、**媒介変数表示**でも書ける。
  `\int_{\{(\cos t, \sin t, t) \mid 0 \le t \le 2\pi\}} f\,ds`（弧長）、`\iint_{\{(\sin u\cos v, \sin u\sin v, \cos u) \mid 0 \le u \le \pi,\ 0 \le v \le 2\pi\}} f\,dS`（面積）、
  媒介変数 3 つなら体積（体積要素 $|\det J|$）、平面の媒介変数 2 つなら変数変換の面積。集合の書き方なら
  `\oint_{\{(x,y) \mid x^2+y^2=1\}} F\cdot d\mathbf{r}`・`\iint_{\{(x,y,z) \mid x^2+y^2+z^2=1,\ z \ge 0\}} f\,dS`。
  ベクトル場は `\oint_{C} F\cdot d\mathbf{r}`・`\iint_{S} F\cdot d\mathbf{S}`。被積分関数の x, y, z に点の成分を入れる。
  媒介変数は、条件で範囲を書いた名前のうち点の式に出てくるもの（面の向き $\mathbf r_u \times \mathbf r_v$ は、点の式に出てくる順）。
  被積分関数は、名前で定義したベクトル場 `\vec{F}\left(x,y,z\right)=\left(\dots\right)` の名前だけ（`\vec{F}\cdot d\mathbf{r}`）でも、
  `\nabla\times\vec{F}`・`\nabla\cdot\vec{F}` でもよい（体積分 `\iiint_{V}\nabla\cdot\vec{F}\,dV` はガウスの定理の左辺）。
  `\oint`・`\oiint` は `\int`・`\iint` と同じ（閉じているかは調べない）。
  媒介変数の名前は t・u・v でなくてもよい（`\{(x, x^2) \mid 0 \le x \le 1\}`・`\{(s, \sin s) \mid \dots\}`）。
  曲線・曲面は、座標の組と等式でも書ける: `\{(x,y) \mid y = x^2,\ 0 \le x \le 1\}`・`\{(x,y,z) \mid x = y = z,\ 0 \le x \le 1\}`・
  `\{(x,y,z) \mid z = x^2 + y^2,\ x^2 + y^2 \le 1\}`（曲面）。等式は、どれかの座標の 1 次式になっていれば、その座標について解いて
  点の式に入れる（後ろの座標から。残った座標が媒介変数）。$x^2 + y^2 = 1$・$x^2 + y^2 + z^2 = 1$・$(x^2+y^2+z^2+3)^2 = 16(x^2+y^2)$
  のように 1 次式にならない等式は、媒介変数を作らずに、点と重みを数値で求める（`core/src/implicit.rs`）: 曲線は単位接線 $\mathbf T$、
  曲面は単位法線 $\boldsymbol\nu = \nabla F / |\nabla F|$ の成分 $g_S$（座標平面・座標軸への射影の拡大率。$\sum_S g_S^2 = 1$）で
  1 の分割 $\varphi_S = g_S^{12} / \sum g^{12}$ を作り、射影ごとに、射影した座標をガウス・クロンロッドの適応型の求積の点に固定して
  残りの座標について等式を解く（$dS = dA_S / g_S$）。折り返す所では $\varphi_S / g_S \to 0$ なので、射影した座標の関数としてなめらか。
  不等式で切った端は、切り口の点の数が変わる所を二分法で探して求積の区間の端にする。誤差はふつう $10^{-8}$ 以下
  （不等式で斜めに切ると $10^{-6}$ ほど、円錐の頂点のような特異点があると $10^{-5}$ ほど）。等式 2 つ（空間の曲線）・1 次式に解ける等式と混ぜた形
  （$\{(x,y,z) \mid x^2+y^2=1,\ z=1\}$）も同じ。範囲が限りなく続く（$x^2 - y^2 = 1$ だけ）なら、不等式で区切るように言う。
  向きは、$F$ = 左辺 − 右辺 として、平面の曲線は $\{F < 0\}$ を左に見る向き（$x^2 + y^2 = 1$ なら反時計回り。グリーンの定理の向き）、
  曲面は $\nabla F$ の向き（$\{F < 0\}$ の外向き。球面なら外向きで、ガウスの発散定理の向き）、空間の曲線は $\nabla F_1 \times \nabla F_2$ の向き。
  「∫ 積分を描く」では、平面の曲線は曲線の上の幕 $\{(x, y, z) \mid F = 0,\ \min(0, f) \le z \le \max(0, f)\}$、曲面は法線の向きに厚くした殻
  $\min(0, f) \le F / |\nabla F| \le \max(0, f)$（$F / |\nabla F|$ は曲面からの距離の近似なので、体積はほぼ積分の値）、空間の曲線は曲線そのものを描く
  （媒介変数が無いので、進み具合のスライダーは出ない）。
  積分の $d$ の後の文字は、範囲の次元と合っているかを確かめる: `ds` は曲線、`dS`・`dA`・`d\sigma` は曲面・平面の領域、`dV` は立体、
  `d\mathbf{r}` は曲線、`d\mathbf{S}` は 3 次元の曲面（合わなければ「ds は曲線の上の積分に使う記号ですが、この範囲は曲面です」のような誤り）。
  媒介変数そのものの $d$（`r\,dr\,d\theta`・`dt`）なら、何も掛けない（$\int f\,dt$ そのもの）。曲線の上の座標の $d$ は向きの付いた線積分で、
  `\oint_{C} -y\,dx + x\,dy` は $\int (-y\,x'(t) + x\,y'(t))\,dt$（`P\,dx + Q\,dy + R\,dz` と続けて書ける）。曲面の上の `R\,dx\,dy` は法線の
  $z$ 成分を掛ける（向きの付いた面積）。`(P\,dx + Q\,dy)` と括弧で囲んでもよい。`\mathbf{F}\cdot\mathbf{T}\,ds`（単位接線）は $\mathbf F \cdot d\mathbf r$、
  `\mathbf{F}\cdot\mathbf{n}\,dS`（単位法線。`\hat{\mathbf{n}}` も）は $\mathbf F \cdot d\mathbf S$、`\mathrm{d}\mathbf{r}` も読む。
  積分記号の下には、条件だけ（`\iint_{x^2+y^2 \le 1} f\,dx\,dy`。点は d の文字か、積分記号の数で決める）・`\mathbb{R}^2`・
  添字の付いた名前（`C_1`・`D_{12}`）・集合どうしの $\cap$・$\cup$・$\setminus$（点が同じ変数の組なら 1 つの領域、媒介変数で書いた曲線・曲面どうしの
  $\cup$ はそれぞれの積分の和。三角形の経路 $\oint_{C_1 \cup C_2 \cup C_3}$ など）も書ける。式を全部書き並べてから計算するので、3 重の積分の
  式が大きくなりすぎるとエラーになる（球座標の球の体積は計算できるが、範囲が外側の変数の式（$\sqrt{1-x^2-y^2}$）の 3 重積分は大きすぎる）
- 集合と論理: 内包的表記 `\left\{(x,y,z) \mid x^2+y^2<1,\ 0 \le z \le 2\right\}`（点の名前は自由。表示中の座標に順に読み替える）、
  条件の `-1 \le x, y \le 1`・`-1 \le x, y, z \le 1` は、並べた文字のどれもが $-1$ 以上 $1$ 以下（`-1 \le x \le 1, -1 \le y \le 1` と同じ。
  集合の中でも、積分の範囲でも、連立の不等式の行でも同じ。不等号の向きがそろっていて、両端に並べた文字や座標が無いときだけ。
  `x \le y, z \le 1` は $x \le y$ と $z \le 1$ のまま）。片側だけの `x, y, z \ge 0`・`0 \le x, y` も、並べた文字のどれもがその条件
  （「$-1 \le x$ かつ $y \le 1$」は `-1 \le x \land y \le 1` と書く）。区間・実数全体の累乗 `[0,1]^2`・`\mathbb{R}^3` は直積（$\in$ の右・積分記号の下）、
  集合の補集合 `\{\dots\}^{c}`。要素が式の集合でも `t \in [0, 1]`・`t \ne \pi`・`0 \le t \le s` をほかの条件と組み合わせられる。
  片側だけの不等式も書ける。有限な端がない入力変数の方向は表示範囲に応じて計算する。
  通常の座標・媒介変数以外の文字も、`s \in \mathbb{R}`・`0 \le s \le 1` のように条件で指定すれば入力変数になる。
  `\{(ax,y)\mid x^2+y^2\leq b\}` の $a$・$b$ はスライダーにできる。
  論理 `\land`・`\lor`・`\neg`・`\Rightarrow`・`\Leftarrow`・`\Leftrightarrow`、排他的論理和（XOR）`\oplus`・`\veebar`・`\nleftrightarrow`、
  否定論理積（NAND）`\barwedge`・`\uparrow`、否定論理和（NOR）`\downarrow`・`\nor`、集合 `\cap`・`\cup`・`\setminus`・対称差 `\triangle`・`\ominus`・
  補集合 `A^{c}`・`A^{\complement}`・`\complement A`、`\in`・`\notin`・`\ni`、区間 `[0,1)`・`(0,1]`・`[0,\infty)` とその直積 `[0,1]\times[0,2]`、
  `\mathbb{R}`・`\mathbb{Z}`（$\sin(\pi p) = 0$）・`\mathbb{N}`（1 以上の整数）・`\top`・`\bot`・`\emptyset`・`\ne`。
  名前を付けた集合 `A = \left\{(x,y,z) \mid \dots\right\}` は、ほかの行で `A \setminus B`・`(x,y,z) \in A` のように使える。
  二成分の集合 `\{(x,y)\mid x^2+y^2\leq1\}` は、3D 表示でも $z=0$ の円板になる。
  同じ条件で縦方向にも広がる集合を描くには、要素を `(x,y,z)` と書く。
  要素に式を書くと、条件を満たす入力をその式に写す。`\{(2x,y)\mid x^2+y^2\leq1\}` は横に伸ばした楕円の領域、
  `\{\sqrt{1-x^2-y^2}\mid x^2+y^2\leq1\}` は数直線上の値域。入力が最大3変数の一般の像は描画用のメッシュで近似する。
  有限な上下限を条件で指定すると、表示範囲の外にある入力も使える。像に対する所属・共通部分・差集合には、逆変換できる同じ次元のアフィン変換を使える。
  集合の区切りは `\mid`、`\middle\vert`、`\bigm|`、コロン、`\text{such that}` などで書ける。`\{x\in A\mid P(x)\}` の所属も条件として読める。
  条件は「かつ」のかたまりを「または」でつないだ形（16 個まで）に直して描く。領域どうしの「または」は 1 本の不等式
  $\min_k \max_j g_{kj} \le 0$ にまとめる（和集合の角は格子の細かさの分だけ丸まる）。等式のあるかたまりは、それぞれ描いて重ねる。
  `\ne` は「かつ」の中では形を変えず、除いた所を示す: 曲線（`y = x,\ y \ne 0`・`x^2+y^2=1,\ x \ne 0`）は除いた点に白丸、
  面・領域は除いた線を点線で描く。$\mathbb{Q}$ は描けない。
  点を媒介変数の式で書いた集合 `\left\{(\cos t, \sin t, 0) \mid 0 \le t \le \pi\right\}` は媒介変数表示で、条件が媒介変数の範囲になる
  （媒介変数は、条件で範囲を書いた名前のうち点の式に出てくるもの。`\{(x, x^2) \mid 0 \le x \le 1\}`・`\{(s, \sin s) \mid 0 \le s \le 6\}` のように
  t・u・v 以外の名前でもよい）。キーボードで `{` と `|` を打った形（`\left\lbrace … \middle\vert … \right\rbrace`）も同じ
- 集合の上の総和・総積: `\sum_{n \in \{1, 4, 9\}}`・`\sum_{1 \le n \le 10,\ \operatorname{mod}(n, 2) = 1}`（上を書かない）・
  `\sum_{d \mid 12}`（約数）・`\prod_{(m,n) \in [1,3]\times[1,3]}`・`\sum_{1 \le m < n \le 3}`（2 つの添字）・名前を付けた有限集合 `\sum_{k \in S}`。
  添字は整数で、条件の不等式から範囲を出し（別の添字で書いた端も区間演算で絞る）、候補を 1 つずつ数で調べる（候補は 2 万まで、項は 2,000 まで）。
  条件は数とパラメータだけで書く（座標は使えない）。範囲が無限の集合（$\mathbb{Z}$ 全体）は書けない
- 添字で並べた和集合・共通部分: `\bigcup_{k=1}^{3} \{(x,y) \mid \dots\}`・`\bigcap_{k \in S}`（`\bigvee`・`\bigwedge` も）。
  有限集合 `x \in \{1, 2, 3\}`（$\in$ のすぐ後の `\{…\}`）も書ける。条件のカンマはいちばん弱い区切り
  （`x < 0 \lor y < 0, z > 0` は $(x < 0 \lor y < 0) \land z > 0$）
- 等差のリスト: `[1, 3, \ldots, 9]` は `[1, 3, 5, 7, 9]`、`[1, \ldots, 5]` は公差 1（256 個まで）
- 両方の符号: `y = \pm\sqrt{x}` は `y = \sqrt{x}` と `y = -\sqrt{x}` の 2 つを描く（1 つの式の中の ± はそろって動く。∓ は逆の符号）
- 度: `30^{\circ}` は $30 \cdot \pi / 180$
- 微分: `\frac{d}{dx}`・`\frac{\partial}{\partial x}`・`\frac{d^{2}}{dx^{2}}`・`\frac{\partial^{2}}{\partial x\partial y}`（直後の項を微分する）、
  定義した関数の導関数 `f'(x)`・`f''(x)`・`\frac{df}{dx}`。式を記号のまま微分する（数値の差分ではない）。
  導関数の表が無い関数（ζ・楕円関数・超幾何関数など）だけは、中心差分 $\frac{g(u+h) - g(u-h)}{2h}$（$h = 10^{-5}\max(1, |u|)$）で計算する。
  `abs` の折れ目・`floor` の段差のような微分できない点では、片側の値（段差の上では 0）になる。パラメータで微分してもよい（`\frac{d}{da}`）
- 曲線: `(cos t, sin t, t/4)`（t を使う。範囲は式の下の欄で指定）
- 複素平面の曲線・曲面: `e^(i t)`、`(u + i v)^2`（組にせず、座標を使わずに t や u, v だけを使う。横 = 実部、奥 = 虚部）
- 曲面: `((3 + cos v) cos u, (3 + cos v) sin u, sin v)`（u と v を使う）
- 多変数: `(t_1, t_2, t_3, t_4)`（媒介変数 t₁, t₂, … を4つ以上。次元を成分の数に合わせる）
- 掛け算の `*` は省略可: `2xy`, `x sin(y)`, `(x+1)(x-1)`
- 括弧なしの関数: `sin x`, `sin^2 x`（= `(sin x)^2`）
- 定数: `pi`（`π`）, `e`, `i`（虚数単位）
- `theta`・`θ`, `phi`・`φ`, `rho`・`ρ`, `sigma`・`σ`, `tau`・`τ`, `mu`・`μ`, `nu`・`ν` は 1 つの名前として読む（座標系の座標の名前に使う。前は `theta` を t·h·e·t·a と読んでいた）
- 関数: `sin cos tan sec csc cot arcsin arccos arctan sinh cosh tanh arcsinh arccosh arctanh exp ln log sqrt abs floor ceil round sign Re Im conj arg`
- 特殊関数: `gamma`（Γ）, `beta`, `psi`（ψ）, `zeta`（ζ）, `polylog`, `erf`, `erfi`, `Ei`, `Si`, `besselJ`/`besselY`/`besselI`/`besselK`, `airyAi`, `legendreP`, `hermiteH`, `hyp2F1`, `ellipticK`, `jacobiSN`, `lambertW` など（Wolfram の名前の先頭を小文字にした形。一覧はアプリの「書き方のヒント」）
- 2 つの引数の関数: `mod(a, b)`（余り）, `min(a, b)`, `max(a, b)`, `nCr(n, r)`（二項係数）, `nPr(n, r)`（順列）
- 階乗: `n!`（= Γ(n + 1) なので整数でなくてもよい）
- 結果が実数にならない点（例: `x < 0` での `sqrt(x)`）は描かれない
