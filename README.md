# graphploter

公開ページ: https://miasf.github.io/graphploter/

ブラウザで動く 3D グラフソフト。目標は「Desmos くらい使いやすく、多次元の媒介変数表示・陰関数・特殊関数・複素数を 3 次元空間に自由に描ける」こと。

現在できること:

- 陽関数の曲面 `z = f(x, y)`（`y = f(x, z)`、`x = f(y, z)` も可）
- 陰関数の曲面 `F(x, y, z) = G(x, y, z)`（例: `x^2 + y^2 + z^2 = 4`）
- 媒介変数表示の曲線 `(x(t), y(t), z(t))` と曲面 `(x(u,v), y(u,v), z(u,v))`、立体 `(x(u,v,t), y(u,v,t), z(u,v,t))`。範囲は `2pi` のような式でも書ける
  - 立体（媒介変数3つ。u, v, t か t₁, t₂, t₃）は、媒介変数の範囲の直方体の6つの面の像を描く。面は外向きになるよう、
    囲まれた体積の符号を見て向きをそろえる。曲面をパラメータの「範囲で重ねる」と、これも立体になる
  - 曲線は曲がっている所だけ細かく計算する（適応サンプリング）。値が飛ぶ所では線を切る
  - 曲面の格子線は u, v に沿って引ける（範囲を何等分するかをスライダーで選ぶ）
  - 入力欄では成分を x =, y =, z = の縦に並べて編集できる（「1行で編集」で元に戻せる）
- 数式の見た目のまま入力できる欄と、スマホ用の数式キーボード（括弧の自動補完、pi → π などの自動変換つき）
- 曲面の格子線: x, y, z 方向ごとに間隔を変えられる（z 方向は等高線になる）。標準は 1 画素の細い線
- 面の濃さ: 0 にすると格子線だけの曲面（ワイヤーフレーム）になる。格子線の密度（x, y 方向・等高線）と太さはスライダーで調整
- スマホでは式の一覧を下から引き出すシートにして、グラフを全画面表示
  - 入力欄の上から指を動かすとスクロール、タップすると入力が始まる（入力欄に透明な「タップ受け」を重ねている）
- 式の欄でエンター（⏎）を押すと、すぐ下に新しい式を足す。左端の番号をつまんで上下にドラッグすると並べ替えられる
- 遠近感: 平行投影から強い透視投影までスライダーで調整、背景の明暗の切り替え
- 切り口: 画面の軸に垂直な平面で切って片側だけを表示し、立体の切り口にふたをする（位置はスライダー、残す側は切り替え）
  - 陰関数・範囲で重ねた立体: 計算担当が切り口の平面の上で F を計算し、中身（F < 0 の側）の部分を三角形にする。
    陰関数は式の両側のどちらが中身か決まっていないので、表示範囲の中で狭いほうを中身とする。
    切り口を動かしたときは、覚えておいた式からふただけを作り直す
  - 媒介変数3つの立体: 描画側でステンシルバッファを使う。切り口の上の点への視線が、立体に入る面と出る面を何回通ったかを
    数え、中にある点だけを塗る
- 4 次元以上: 座標は x, y, z, w（= w₁）, w₂, w₃, …（4 次元目が w、5 次元目が w₂）
  - 画面の横・奥・縦に表示する3つの座標を選び、残りの座標はスライダーで値を固定した断面を描く
  - 媒介変数表示 (x, y, z, w, …) は、表示する3つの座標の成分を描く（射影）
- 範囲で重ねる: 表示していない座標を「範囲」にするか、パラメータの「範囲で重ねる」を押すと、
  その範囲で動かしたときに図形が通る領域を描く（曲面 → 立体、曲線 → 曲面）
  - 立体は G(p) = max(min F, −max F) ≤ 0 の領域の境界面（F を範囲の各点で計算して最小・最大をとる）
- 回転: 中心 c と、座標の組 (i, j) ごとの角度（n 次元なら nC2 通り、多いときは折りたたむ）で、点を q = R(p − c) + c に動かす
  - 次元が5未満でも、w, w₂ を使った5次元の回転（5C2 = 10 通り）ができる。陰関数・陽関数はその方向にまっすぐ伸びた形、媒介変数表示はその成分が 0 の形として回す
  - 陰関数は、式に p = c + Rᵀ(q − c) を代入して回す（断面が回転で変わるので、式から計算し直す）
  - 陽関数は、回転が表示中の座標どうし（と、式が使っていない座標どうし）だけなら、曲面 (u, v, f(u, v)) をそのまま回せるので、
    媒介変数表示と同じく点を計算してから回す。w など表示していない方向が絡む回転のときは、陰関数として計算し直す
  - 媒介変数表示は、n 次元の点を一度計算して Worker に覚えておき、回転・表示する軸が変わったときは射影し直すだけ（式を計算し直さない）
- 4 次元の遠近法: 回転した後、表示していない座標 q_h の奥行きに応じて s = Π D / (D − (q_h − c_h)) 倍に縮めて描く（奥ほど小さい）。
  射影で描く図形（媒介変数表示・回した陽関数）に効く。断面（陰関数）には効かない
- 回転の再生: 回転ごとの ▶ ボタンで、角度を回し続ける
- リスト: `(t, [-1, 1], [-1, 1], [-1, 1])` のように媒介変数表示の中で使うと、組み合わせ（直積）の数だけ図形をまとめて描く
- サンプルの「正八胞体（4次元の立方体）の回転」で、辺 32 本を4次元の遠近法と xw 回転の再生つきで表示する
- 媒介変数は t（曲線）、u と v（曲面）、u と v と t（立体）、または番号付きの t₁, t₂, t₃。組 (…) の外では t, u, v はパラメータとして使える
- パラメータ: `a = 1` のように書くとスライダーになり、ほかの式で `a` を使える
  - 未定義の文字を使うと「a のスライダーを追加」ボタンが出る
  - ▶ で値を自動で動かす（最小値から最大値まで 4 秒、最後まで行ったら最初から）
  - 媒介変数の範囲にもパラメータを使える（0 ≤ t ≤ b の b を再生すると、曲線が伸びていく）
  - 「複素数」モードでは、複素平面の上で点をドラッグして複素数の値を決められる
- 計算はすべて複素数で行う（例: `z = abs(gamma(x + iy))`）
- 特殊関数（すべて複素数で使える。Wolfram/Mathematica にある主なもの）: ガンマ・ベータ・ポリガンマ・不完全ガンマ／ベータ、ゼータ（フルヴィッツ）・多重対数、誤差関数・フレネル積分・指数積分・三角積分、ベッセル J/Y/I/K・ハンケル・球ベッセル・エアリー、直交多項式（ルジャンドル陪関数・エルミート・ラゲール・チェビシェフ・ゲーゲンバウアー・ヤコビ）・球面調和関数、超幾何関数 ₀F₁ ₁F₁ ₂F₁ U、楕円積分 K E F Π・ヤコビの楕円関数、ランベルトの W 関数。一覧はアプリの「書き方のヒント」
- 式の追加・削除・色変更・表示切り替え、表示範囲と細かさの変更
- サンプル: 最初は空の式だけ。「サンプル（タップで追加）」から例をタップすると、一覧の最後に追加される（今ある式は消さない）
- 保存・共有: 式と設定はブラウザに自動で保存され、次に開いたときに戻る。「共有リンクをコピー」で、状態を圧縮して URL の # の後ろに入れたリンクを作る

## 描画を軽くする工夫

- 画素密度はスマホでも 2 倍までに抑え、グラフを動かしている間は 1 倍に下げる（止まったら元に戻す）
- 何も変わっていないときは描かない（止まっているときに電池を使わない）
- 曲面の表と裏は 1 つのメッシュで描き、裏面はシェーダーで暗くする
- 目盛りの文字は HTML ではなく WebGL のスプライトで描く（回すたびに HTML を書き換えない）
- 4 次元の回転などで形だけが変わるときは、材質（シェーダー）を使い回して形のデータだけ差し替える
- スライダー・複素平面を動かしている間と回転を再生している間は、細かさを半分にして計算し（陰関数は 1/8）、画素密度も下げる。指を離したら細かく計算し直す
- 非表示の式は計算しない（表示したときに計算する）
- 計算担当の Worker を CPU のコア数に合わせて最大 4 つにし、式ごとに担当を分けて並列に計算する

## 構成

```
graphploter/
├── core/   … Rust で書いた計算エンジン（WebAssembly に変換してブラウザで動かす）
│   └── src/
│       ├── parser.rs     数式の文字列 → 構文木
│       ├── eval.rs       構文木 → 命令列、たくさんの点でまとめて計算（複素数）
│       ├── functions.rs  組み込み関数の一覧
│       ├── special/      特殊関数（ガンマ・ゼータ・ベッセル・超幾何・楕円など）
│       ├── equation.rs   式の種類（陽関数・陰関数）の判定
│       ├── mesh.rs       曲面のメッシュを作る（陽関数: 格子 / 陰関数: Surface Nets 法）
│       └── lib.rs        JavaScript から呼ぶ入口
└── web/    … 画面（Svelte + TypeScript + Three.js）
    └── src/
        ├── App.svelte               画面全体
        └── lib/
            ├── ExpressionItem.svelte  式の一覧の1行
            ├── ParamControl.svelte    パラメータのスライダー
            ├── SpacePanel.svelte      次元の設定（表示する座標と断面・範囲）
            ├── RotationPanel.svelte   回転の設定（中心と nC2 通りの角度）
            ├── ComplexPad.svelte      複素数のパラメータを決める複素平面
            ├── MathInput.svelte       数式の入力欄（MathLive）
            ├── mathSetup.ts           数式入力欄の設定・数式キーボードの配置
            ├── latex.ts               入力欄の LaTeX → 計算エンジン用の式への変換
            ├── persist.ts             保存・共有（ブラウザへの保存と共有リンク）
            ├── samples.ts             サンプルの一覧
            ├── Viewer.ts              3D 表示（Three.js）
            ├── surfaceMaterial.ts     曲面の材質（格子線を描くシェーダー）
            ├── plot.worker.ts         計算担当（別スレッドで WASM を呼ぶ）
            ├── plotClient.ts          計算担当への依頼窓口
            └── types.ts               データの型
```

処理の流れ:

```
式を入力 → (Web Worker) Rust/WASM が解析・計算・メッシュ生成 → Three.js が描画
```

## 自分のパソコンで動かす

### 1. 必要なものを入れる（最初の1回だけ）

| ツール | 用途 | 入れ方 |
|---|---|---|
| Node.js (v20 以上) | 画面側の開発 | https://nodejs.org から LTS 版 |
| Rust | 計算エンジン | https://rustup.rs の手順どおり |
| WASM 用の部品 | Rust → WebAssembly | 下のコマンド |

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-pack
```

### 2. 起動する

```sh
cd web
npm install      # 最初の1回だけ（部品のダウンロード）
npm run dev      # Rust のビルド → 開発用サーバーの起動
```

表示された URL（たいてい http://localhost:5173 ）をブラウザで開く。

- **画面側（`web/src`）を書き換えたとき**: 保存するだけでブラウザに自動で反映される
- **Rust 側（`core/src`）を書き換えたとき**: `npm run dev` を止めて（Ctrl + C）もう一度実行する

### よく使うコマンド

| 場所 | コマンド | 内容 |
|---|---|---|
| `core/` | `cargo test` | Rust 側のテストを実行 |
| `web/` | `npm run dev` | 開発用サーバーを起動 |
| `web/` | `npm run check` | 画面側の型チェック |
| `web/` | `npm test` | 数式の変換（latex.ts）のテスト |
| `web/` | `npm run build` | 公開用のファイルを `web/dist/` に作る |

## 数式の書き方

入力欄は数式入力ライブラリ [MathLive](https://cortexjs.io/mathlive/) を使っていて、分数やべき乗が数式の見た目のまま表示される。

- `/` で分数、`^` でべき乗（右矢印キーで抜ける）、`(` で括弧（閉じ括弧は自動）
- `pi` → π、`sqrt` → √、`sin` などの関数名は自動で変わる
- スマホでは入力欄を押すと数式用のキーボードが出る（123 / f(x) / abc のタブ）
- 入力欄の LaTeX は `web/src/lib/latex.ts` で計算エンジン用の式に変換している

計算エンジンが読む式の書き方（入力欄からの変換後）:


- 陽関数: `z = x^2 - y^2`（`z =` は省略可）、`y = sin(x) z` なども可
- 陰関数: `x^2 + y^2 + z^2 = 4`、`sin x cos y + sin y cos z + sin z cos x = 0`
- パラメータ: `a = 1`、`c = 1 + 2i`（x, y, z, t, u, v, e, i 以外の1文字）。ほかの式の中で使える
- 曲線: `(cos t, sin t, t/4)`（t を使う。範囲は式の下の欄で指定）
- 曲面: `((3 + cos v) cos u, (3 + cos v) sin u, sin v)`（u と v を使う）
- 掛け算の `*` は省略可: `2xy`, `x sin(y)`, `(x+1)(x-1)`
- 括弧なしの関数: `sin x`, `sin^2 x`（= `(sin x)^2`）
- 定数: `pi`（`π`）, `e`, `i`（虚数単位）
- 関数: `sin cos tan sec csc cot arcsin arccos arctan sinh cosh tanh arcsinh arccosh arctanh exp ln log sqrt abs floor ceil round sign Re Im conj arg`
- 特殊関数: `gamma`（Γ）, `beta`, `psi`（ψ）, `zeta`（ζ）, `polylog`, `erf`, `erfi`, `Ei`, `Si`, `besselJ`/`besselY`/`besselI`/`besselK`, `airyAi`, `legendreP`, `hermiteH`, `hyp2F1`, `ellipticK`, `jacobiSN`, `lambertW` など（Wolfram の名前の先頭を小文字にした形。一覧はアプリの「書き方のヒント」）
- 2 つの引数の関数: `mod(a, b)`（余り）, `min(a, b)`, `max(a, b)`, `nCr(n, r)`（二項係数）, `nPr(n, r)`（順列）
- 階乗: `n!`（= Γ(n + 1) なので整数でなくてもよい）
- 結果が実数にならない点（例: `x < 0` での `sqrt(x)`）は描かれない
