# 計画: 数学の記法に、描き方の意味を持たせる

`docs/plan-hard-tasks.md` の 10 章（キーボードに入れた記号に、描き方の意味を持たせる）を、ステップに分けた指示書。
実装担当（Opus）には、5 章の指示書を 1 ステップずつ（1 ステップ = 1 PR）渡す。ステップの名前は M0〜M14（`plan-hard-tasks.md` の S・G・H と重ならないように M にした）。

扱うもの:

- 関数の定義と四則演算・合成（`f(2x)`・`g(f(x))`・`(f+g)(x)`・`f \circ g`）
- 微分・積分・総和・総積
- ベクトルと行列（連立一次方程式、$\ker A$ の解空間、$\operatorname{Im} A$ の像、行列式、線形変換）
- ベクトル場、常微分方程式、数列
- 集合の書き方でのプロット（内包的表記・論理演算・集合演算）
- そのほかの「まだ使えません」の記号の意味づけと、意味を持たせられない記号の除外
- ほかの MD に残っている計画の状態と順番（7 章）

### 1.2 10 章の見立てと違った所

- 10 章は $\sum$・$\prod$・$\int$ を「中」としていたが、束縛する変数を構文木に持てないことと、名前の衝突（上の `int`）があるので、先に土台（M0）が要る。土台ができれば、$\sum$・$\prod$ は小さい
- 10 章は行列を「未定」としていた。調べると、行列の計算は全部、**成分が式の小さな行列を、展開の段で式のまま計算する**ことで済む（`det` は余因子展開の式になる）。VM に行列の値を持たせる必要は無い。描き方は 3.4 に決めた
- 10 章は $\exists$ を「大（数値で影を作る仕組みが別に要る）」としていたが、範囲が有界で等式が 1 本なら、今の「範囲で重ねる」と同じ（1.1）。一般の $\exists$ だけが難しい
- `docs/plan-prompt-ambitious.md` の候補 A（自動微分）は「VM の命令ごとに双対数の版を作る」案だった。**記号微分に変える**（3.2）。結果がふつうの式になるので、区間演算・段差・GLSL（12 章）がそのまま使え、VM を触らない

## 2. 全体の決めごと

### 2.1 新しい記法は、展開の段で今ある式に落とす

新しいモジュール `core/src/expand.rs` を作り、解析の直後（`equation.rs` の `rename_coords` を呼んでいる 3 か所: `compile_with`・`hidden_field`・`compile_coord_map` と、`eval_constant_with`）で、`rename_coords` より**前**に呼ぶ。

$$\text{文字列} \xrightarrow{\ \texttt{parse}\ } \text{構文木（新しい節あり）} \xrightarrow{\ \texttt{expand}\ } \text{構文木（今ある 8 つの節だけ）} \xrightarrow{\ \text{今までの道}\ } \text{図形}$$

- 展開の段は、式の**形**（スカラー・ベクトル・行列・関数・集合）を調べながら、関数の呼び出しを中身に置き換え、$\sum$ を項の和に、微分を導関数の式に、行列の積を成分の式にする
- 展開の後に新しい節が残っていたら、内部エラー（`Program::compile_with` の `emit` で `unreachable` ではなく `Err`）
- 例外は 2 つだけ: 場合分けの `Func::Piece`（M2。VM の関数として足す）と、図形の種類が増えるもの（ベクトル場・常微分方程式・数列の点。`Plot` に枝を足す）

### 2.2 計算エンジンの文字列の文法（`latex.ts` が出し、`parser.rs` が読む）

今の式を 1 つも壊さないために、新しい演算子は**英字の並びの外**に置く。

| 書き方 | 意味 | 字句 |
|---|---|---|
| `@名前`（`@sum`・`@prod`・`@int`・`@diff`・`@det`・`@ker` など） | 新しい演算子。`@` の後の英字の並び全部が名前（1 文字ずつに分けない） | `Tok::Op(String)` |
| `{名前}`（`{alpha}`・`{vec_v}`・`{bb_R}`） | 2 文字以上の名前の変数 1 つ（ギリシャ文字・飾り付きの文字） | `Tok::Var` |
| `名前'`・`名前''` | プライム（導関数・常微分方程式） | `Tok::Prime` |
| `名前_(式)` | 数字でない添字（数列の項 $a_{n+1}$）。数字だけの添字 `a_1` は今までどおり変数 `a1` | `Tok::Sub` |
| `;` | 行列の行の区切り | `Tok::Semi` |
| `⟦ … ⟧` | 行列（`⟦1, 2; 3, 4⟧`） | `Tok::LMat`・`Tok::RMat` |
| `×` | 外積・直積（スカラーどうしは今までどおり掛け算） | `Tok::Cross` |
| `∧`・`∨`・`¬`・`⇒`・`⇐`・`⇔`・`∩`・`∪`・`∖`・`∈`・`∉`・`∋`・`≠`・`⊤`・`⊥`・`∅`・`ℝ`・`ℤ`・`ℕ`・`ℂ`・`ℚ` | 論理・集合（M11） | それぞれの字句 |
| `⦃ 点 ∣ 条件 ⦄` | 内包的表記（M11。`{名前}`・絶対値の `|` とぶつからないように、別の文字にする） | `Tok::LSet`・`Tok::SetBar`・`Tok::RSet` |
| `∘`・`±`・`∓`・`…` | 合成（M1）、両方の符号・等差のリスト（M4） | それぞれの字句 |

束縛する変数を持つ演算子は、頭を括弧で書き、中身はその後の**項**（`term`: 掛け算・割り算のかたまり）にする。「$\sum$ は次の項に掛かる」というふつうの読み方で、`latex.ts` は中身の終わりを探さなくてよい。

```text
@sum(n, 1, 10) 項        Σ_{n=1}^{10} 項
@prod(n, 1, 10) 項       Π
@diff(x) 項              d/dx 項        @diff(x, 2) 項 は 2 階
@int(t, 0, x)(式)        ∫_0^x 式 dt    （積分だけは latex.ts が dt を見つけて括弧で囲む）
```

### 2.3 定義の行と、その受け渡し

- **定義の行**: `f(x) = x^2`（関数）、`{vec_b} = (1, 2, 3)`（ベクトル）、`A = ⟦1, 2; 3, 4⟧`（行列）、`a_(n+1) = 2 a_(n)`（数列）、`S = {(x, y, z) | …}`（集合）。パラメータの定義 `a = 1` は今までどおり `Params`
- 計算エンジンへは、`plot` の引数を増やさず、`coord_system(map, names)` と同じ置き方で渡す: `definitions(src: &str)`（行を `\n` でつないだ文字列）を呼んでおくと、次の `plot`・`check_expression`・`eval_range` が 1 回だけ使う（`thread_local`。`lib.rs` の `COORD_MAP` と同じ）
- 定義の表 `Defs`（`expand.rs`）: 名前 → `Function { args, body }`・`Value(Expr)`（ベクトル・行列・引数の無い式）・`Sequence { index, rules }`・`Set(…)`
- 定義は**使う所で**展開する（定義の中で別の定義を使ってよい）。自分自身を呼ぶ循環は、名前を挙げてエラーにする（数列の漸化式だけは別。M10）
- 画面は、パラメータと同じ流れにする: `MeshResult` に `used_defs()`（使った定義の名前）と `def_name()`（この行が定義なら、その名前）を足し、定義の行が変わったら、それを使う式だけ描き直す（`App.svelte` の `paramsChanged` と同じ形の `defsChanged`）

### 2.4 名前の決まり

- 定義にできる名前: 英字 1 文字（数字の添字つきも可）と `{名前}`。座標（$x, y, z, w, w_2, \dots$）・$e$・$i$ は不可。**$t, u, v$ も不可**（組の中では媒介変数なので、読み方が 2 通りになる）。ベクトルに $\mathbf v$ を使いたいときは `\vec{v}`（= `{vec_v}`。別の名前）
- 同じ名前をパラメータと定義の両方にしたら、両方の行にエラーを出す
- `a(x) = 1` の読み方: **$a$ がパラメータとして定義されていれば、今までどおり積 $a \cdot x = 1$**（陰関数）。そうでなく、左辺が「名前(変数, …)」の形（引数が全部、違う名前の変数 1 つずつ）なら関数の定義。今の保存データの式は変わらない
- 関数の仮引数は、どの名前でもよい（座標の名前でもよい）。中身に出てくるそれ以外の名前は、外の名前（座標・パラメータ・ほかの定義）

### 2.5 大きさの上限（展開が爆発しないように）

- 展開した後の構文木の節の数は **20 万まで**。超えたら「式が大きくなりすぎます（$\sum$ の項の数・入れ子を減らしてください）」
- $\sum$・$\prod$ の項は 2,000 まで。積分の入れ子は 2 重まで。関数の入れ子の深さは 64 まで
- **判断の分かれ目**: M4・M5 の後、`core/tests/bench.rs` に `@sum`（200 項）と `@int`（32 点）の式を足して、コンパイルの時間（`Builder` の命令の共有の表引き）と計算の時間を測る。コンパイルが 50 ms を超えるなら、展開をやめて VM に「中の命令列を繰り返す命令」を足す案に切り替える（そのときは区間演算と速い道の対応も要るので、別のステップにする）

### 2.6 LaTeX の変換（`latex.ts`）は、構造を写すだけにする

- `\sum_{n=1}^{10}` → `@sum(n,1,10) `、`\frac{d}{dx}` → `@diff(x) `、`\begin{pmatrix}a&b\\c&d\end{pmatrix}` → `⟦a,b;c,d⟧` のように、**形の決まった置き換え**だけをする
- 意味の判断（`Im` が虚部か像か、`\times` が掛け算か外積か、`|A|` が絶対値か行列式か）は、展開の段が式の形を見て決める
- 新しく読めるようにした命令は、`latex.test.ts` に 1 つずつ例を足す

### 2.7 全ステップに共通の決まり

`plan-hard-tasks.md` の 5 章の最初の箇条書きと同じ（日本語のコメントと README、`cargo test`・`npm run check`・`npm test`・`npm run build`、保存データに足す項目は省略できるようにして古いデータが読めることをテストする、指示に無い整理をしない）。加えて:

- **新しい記法を使っていない式の結果を、1 ビットも変えない**。各ステップで、`core/tests/shape.rs`・`systems.rs`・`coords.rs` などの今あるテストが、変更なしで通ること
- エラーの文は日本語で、直し方が分かるように書く（「$n$ の範囲は整数にしてください」）
- 計算エンジンのテストは `@sum(n,1,3) n^2` のような文字列で書く（LaTeX を通さない）。LaTeX からの変換は `latex.test.ts`

## 3. 選んだ方針

### 3.1 関数

- 定義 `f(x) = …`・`g(x, y) = …`。呼び出しは、解析器が「定義されている名前の直後に `(`」を見て `Expr::Apply` にする（定義の名前の一覧を `parse` に渡す）。こうしないと `f(x)^2` が $f \cdot x^2$ になる
- 展開の段で、引数を中身に代入する。`f(2x)`・`g(f(x))`・`f(x) + g(x)`・`f(x) g(x)`・`f(x)/g(x)` は、これだけで全部動く
- 関数そのものの四則演算と合成: 名前を引数なしで書いた `f` は「関数の形」。関数の形どうしの `+ − × ÷` は点ごとの演算、`∘`（`\circ`）は合成、**関数の形 × 括弧の式は適用**（`(f+g)(x)`・`(f∘g)(x)`。解析器は積として読み、展開の段が形を見て適用にする）。引数なしの定義 `h = f + g`・`h = f∘g` も書ける
- 定義の行そのものも描く（Desmos と同じ）: 引数を表示中の座標に順に当てはめ、1 引数は「奥 = f(横)」（`y = f(x)` と同じ絵）、2 引数は「縦 = f(横, 奥)」。3 引数以上と、値が組の関数は描かない。目のボタンで消せる
- 選ばなかった案: 引数を命令の番号に結び付けて展開せずにコンパイルする案（構文木が大きくならない）。式の種類の判定（`find_explicit`・`first_list`・`complex_plane`）が構文木を見るので、展開のほうが下流を触らずに済む。大きさは 2.5 の上限で守る

### 3.2 微分は記号微分

- `@diff(x) 式` を、展開の段で導関数の式にする（`core/src/diff.rs`）。変数は実数として扱う（複素数の値に、実の変数での微分を付ける）
- 導関数の表に無い関数（特殊関数の大半）は、**中心差分の式**に置き換える: $\dfrac{g(x + h) - g(x - h)}{2h}$、$h = 10^{-5}\max(1, |x|)$。これも式なので、同じ道を通る。2 階までにし、それ以上は「この関数は 2 回までしか微分できません」
- 微分できない点（`abs` の折れ目・`floor` の段差）は、片側の値のまま（段差の上では 0）。段差の上での微分を $\delta$ 関数にはしない
- 結果は必ず簡約する（$0 \cdot u$・$1 \cdot u$・$u + 0$・定数どうし）。簡約しないと、3 階の微分で節の数が上限に届く

### 3.3 総和・総積・積分

- $\sum$・$\prod$: 範囲は、パラメータだけで決まる整数（スライダーの値は四捨五入しない。整数でなければエラーにして、スライダーの刻みを 1 にするよう促す）。項ごとに束縛する変数へ数を代入して、足す・掛ける
- 定積分: ガウス・ルジャンドルの 32 点（区間を 2 つに分けて 16 点ずつ）の重み付きの和に展開する。**端は式でよい**（$\int_0^x$）。$\infty$ の端は変数変換 $t = a + \dfrac{s}{1 - s}$（$s \in [0, 1)$）で有限にする
- 適応的な積分ではないので、鋭い山・端の特異点（$\int_0^1 \frac{dt}{\sqrt t}$）では精度が落ちる。README にそう書く。直すのは 2.5 の「判断の分かれ目」で VM の命令に変えるとき

### 3.4 行列の描き方

10 章で「未定」だった所。次のように決める。

| 書いたもの | 描くもの |
|---|---|
| ベクトルの等式 $A\mathbf x = \mathbf b$（例: `⟦1,2,3; 4,5,6⟧ (x, y, z) = (1, 2)`） | 成分ごとの等式の連立（今の `Plot::System`）。全部が座標の 1 次式なら、先に掃き出して階数 $r$ を出し、独立な $r$ 本だけを渡す（平面・直線・点）。矛盾していれば「解がありません」 |
| `@ker(A)`（$\ker A$） | $A\mathbf x = \mathbf 0$ の解空間。零空間の基底を数値で求め、原点を通る点・直線・平面（媒介変数表示として作り、表示範囲で切る）。全空間なら表示範囲の箱 |
| `Im(A)`（$\operatorname{Im} A$。引数が行列のとき） | 列ベクトルが張る空間（像）。同じく点・直線・平面・箱 |
| `@det(A)`・`\begin{vmatrix}…\end{vmatrix}`・`|A|` | 式の中ではスカラーの値（成分に座標があってもよい: `z = @det(⟦x, y; y, x⟧)`）。**1 行に行列式だけ**を書いたときは、列ベクトルが張る平行六面体（2×2 なら平行四辺形）を描き、値を行の下に出す。体積が $|\det A|$ |
| 行列だけの行（`A = ⟦…⟧`。正方で 2×2 か 3×3） | 列ベクトルを原点からの矢印で描く（基底の行き先）。行の ⚙ の「座標系として使う」で、$T(\mathbf q) = A\mathbf q$ の自作の座標系を作る（格子が変形し、移行のスライダーで単位行列から連続に移る。9 章の仕組み） |
| 行列 × 組（`A (cos t, sin t, 0)`） | ふつうの媒介変数表示（展開の段で成分の式になる） |

行列の計算は、成分が式の小さな行列（6×6 まで）を、展開の段で式のまま計算する。`@ker`・`Im`・階数だけは、成分をパラメータの値で数にしてから数値で求める（成分に座標があればエラー）。

### 3.5 ベクトル場・常微分方程式・数列

- **ベクトル場**: 成分に表示中の座標を使う組（`(-y, x, 0)`）。格子の点に矢印を描き、大きさで色を付ける。$\nabla f$（勾配）・$\nabla \times \mathbf F$（回転）も組になるので、同じく描ける。$\nabla \cdot \mathbf F$（発散）・$\nabla^2 f$ はスカラー
- **常微分方程式**: 2 つの書き方
  - 連立: `x' = 10(y - x), y' = x(28 - z) - y, z' = x y - 8z/3`（独立変数は $t$。`\dot{x}`・`\frac{dx}{dt}` も同じ）→ 解曲線
  - 1 本: `y' = x - y`・`y'' + y = 0`（独立変数は横の座標、未知関数は奥か縦の座標）→ 解曲線と、1 階なら傾きの場
  - 初期値は行の ⚙ の欄（定数の式。パラメータを使えるので、スライダーで動かせる）。リストを書けば何本も描く
  - 解法は刻み幅を自動で決めるドルマン・プリンス法（RK45）。硬い方程式は扱わない（歩数の上限で打ち切り、そう表示する）
- **数列**: `a_n = 1/n^2`（一般項）、`a_{n+1} = a_n + 2`（漸化式。初項はパラメータ `a_1 = 1`）。行そのものは点 $(n, a_n)$ を描く。値が複素数なら、複素平面の点を順に結んだ軌道。式の中では $a_{10}$・$a_{N}$ として使える

### 3.6 集合の書き方

- 内包的表記 $\{(x, y, z) \mid \text{条件}\}$ は、条件だけを取り出して、今の連立方程式・不等式に渡す
- 論理式は**選言標準形**（「かつ」のかたまりを「または」でつないだ形）に直し、かたまり 1 つずつを今の `Plot::System` として描いて、まとめる。領域どうしの和集合は、互いの中に入った面を切り取る
- 否定は内側へ押し込む（ド・モルガン）。不等式の否定は向きを逆にする。**等式の否定 $F \ne 0$ は「かつ」の中では無視する**（曲面を除いても絵は変わらない）。説明の欄に「（≠ は描けないので無視）」と出す
- 集合の演算は論理の演算と同じ: $\cap = \land$、$\cup = \lor$、$A \setminus B = A \land \lnot B$、$A^c = \lnot A$
- $\in$: 名前を付けた集合（`S = {…}`）、区間（$x \in [0, 1)$）、区間の直積（$(x, y, z) \in [0,1] \times [0,2] \times [0,1]$）、$\mathbb R$（常に真）、$\mathbb Z$・$\mathbb N$（表示範囲の中の整数を並べた等式）

1. 定義の行の判定（`Defs::parse` と `compile_with` の両方が使う 1 つの関数にする）: 左辺が「名前 × (変数)」か「名前 × (変数, 変数, …)」（今の解析器は積・組として読む）で、名前が 2.4 の決まりを満たし、**パラメータとして定義されていなければ**、関数の定義。右辺は式でも組でもよい
2. 展開: `Expr::Apply` を、定義の中身の仮引数に実引数を代入した式にする（代入の前に、実引数を先に展開する。中身の中の呼び出しも続けて展開する）。引数の数が合わなければ「$f$ の引数は 2 個です」。循環は「$f$ の定義が $f$ 自身を使っています」
3. 関数の形: 展開の段の値を `enum Shape { Scalar(Expr), Fn { args: Vec<String>, body: Box<Shape> }, … }` で持つ。名前だけの `f` は `Fn`。`Fn ± Fn`・`Fn × Fn`・`Fn ÷ Fn`・スカラー × `Fn` は点ごと（仮引数の名前を 1 つ目の関数のものにそろえる）。`f ∘ g`（字句 `∘`。`latex.ts` は `\circ` を、上付きでない所では `∘` にする）は合成。**`Fn` × 括弧の式（または組）は適用**。引数なしの定義 `h = f + g` は `Defs` に `Fn` として入る
4. 定義の行を描く（3.1）: `compile_with` が、定義の行を「奥 = 中身」（1 引数）・「縦 = 中身」（2 引数）として、仮引数を表示中の座標に置き換えてコンパイルする。`kind` は `f(x) の定義`。描けない形（3 引数以上・値が組・`Fn` の定義）は、図形なしで `kind` だけ返す（`Plot::Param` と同じ扱いの `Plot::Def`）
5. 逆関数: 等式の片側が `f^(-1)(式)` だけ（$f$ は 1 引数の関数）のとき、`f(反対側) = 式` に書き換える。それ以外の所の `f^(-1)(x)` は、今までどおり $\dfrac{1}{f(x)}$ ではなく、エラー「逆関数は y = f^{-1}(x) の形でだけ使えます」
6. `latex.ts`: `\circ` → `∘`、`f\colon x\mapsto 式`・`f:x\mapsto 式` → `f(x)=式`。`\mathrm{f}` などは今までどおり
7. 画面: 定義の行は `item.def` に名前を入れ、変わったら `defsChanged`。未定義の関数を呼んだ式には、`missingParam` と同じ形で「$f$ の定義を追加」ボタンを出す（`f(x)=x` の行を足す）

**やらないこと**: 再帰（`f(x) = f(x-1) + 1`）。引数の数が違う同じ名前の関数。`f^2(x)`（2 乗か 2 回の合成か決まらないので、今までどおり $f$ が関数ならエラー）。プライム `f'`（M3）。

**完了の条件**

- 新しいテスト（`core/tests/notation.rs` を作る）: 定義 `f(x) = x^2`・`g(x) = sin(x)` のもとで、
  `z = f(2x)` と `z = (2x)^2`、`z = g(f(x))` と `z = sin(x^2)`、`z = (f+g)(x)` と `z = x^2 + sin(x)`、`z = (f∘g)(y)` と `z = sin(y)^2`、`z = f(x) g(y)` と `z = x^2 sin(y)` が、それぞれ**同じメッシュ**（頂点と三角形が一致）
- `a = 2` があるときの `a(x) = 1` が、今と同じ陰関数。無いときは関数 $a$ の定義
- 2 変数: `h(x, y) = x y` のもとで `z = h(y, x + 1)` と `z = y (x + 1)` が同じメッシュ
- `y = f^(-1)(x)` と `f(y) = x`（= `y^2 = x`）が同じメッシュ
- 循環・引数の数の違い・未定義の名前で、名前の入ったエラーが出る
- 画面: `f(x) = x^2` の行の中身を変えると、`f` を使う式だけが描き直される（`usedDefs` を見て確かめる。使っていない式の `requestId` が増えない）

**壊してはいけないもの**: パラメータ $a$ があるときの `a(x+1)`（積）。`(x+1)(x-1)`（積）。`t, u, v` を使う媒介変数表示。

### M2: 場合分け（`cases`）

**目的**: $f(x) = \begin{cases} x^2 & x < 0 \\ x & x \ge 0 \end{cases}$ が書ける。

**触るファイルと関数**: `core/src/functions.rs`（`Func::Piece`）、`core/src/eval.rs`（`CallN` の計算・区間演算）、`core/src/parser.rs`（`@cases`）、`core/src/expand.rs`、`web/src/lib/latex.ts`、README

**やること**

1. 文法: `@cases(値1, 条件1; 値2, 条件2; 値3)`（最後の行の条件は省ける = それ以外）。条件は、関係の連鎖（`0 ≤ x < 1`）を `,`（かつ）でつないだもの。括弧の中で関係を読むのはここだけなので、`@cases` の引数専用の読み方にする（今の「=・≤ などは、括弧の外に書いてください」のエラーは、ほかの括弧では残す）
2. 条件を**余裕の値**（0 以上なら成り立つ実数）にする: $L < R$・$L \le R$ は $R - L$、$L = R$ は $-|L - R|$、「かつ」は `min`、「または」（M11 の後）は `max`
3. `Func::Piece`（引数は `余裕1, 値1, 余裕2, 値2, …, [それ以外の値]`）: 点ごとに、余裕が 0 以上（厳密な不等号は 0 より大きい。厳密かどうかは、余裕に `-0.0` を足す工夫ではなく、関数を `Piece` と `PieceStrict` の並びで持つなど、実装で決めてよい）の最初の値を返す。どれも成り立たなければ NaN（描かない）。**選ばれなかった値が NaN・無限大でも、結果に影響しない**
4. 区間演算: 余裕の区間が 0 以上になり得る枝の、値の区間の包（どの枝も成り立たない可能性があれば、定義されない所があるという印）。最初は「区間演算が使えない」（`supports_interval` が偽）にして、後から足してもよい
5. 段差: 陽関数は `find_jumps` が数値で見つけるので、追加は要らない。確かめるだけ
6. `latex.ts`: `\begin{cases}a & c \\ b & d\end{cases}` → `@cases(a, c; b, d)`。`&` の後が空・`\text{otherwise}`・`\text{それ以外}` なら条件なし

**やらないこと**: 陰関数の「部品に分ける」道（`eval/pieces.rs`）で、場合分けを枝として扱うこと（最初は、分けられない式として今までの格子の道に流す。`floor` と同じ扱いにするのは、需要を見てから）。

**完了の条件**

- 新しいテスト: `z = @cases(x^2, x < 0; x)` の頂点が、$x < 0$ で $z = x^2$、$x \ge 0$ で $z = x$（誤差 $10^{-9}$）。`@cases(sqrt(x), x > 0; 0)` が $x < 0$ で 0（NaN にならない）。`@cases(1, x > 1)` が $x \le 1$ で描かれない
- `z = @cases(1, x > 0; -1)` に、`sign(x)` と同じ位置の段差の切り分けが入る（壁の位置が $|x| < $ 格子の $\frac{1}{1000}$）
- `latex.test.ts`: 上の LaTeX の例
- `bench.rs` の今ある式の時間が変わらない

**壊してはいけないもの**: 実数だけの速い道（`Piece` を含まない式は今までどおり速い道を通る）。

**README**: 「数式の書き方」に場合分けを足す。

### M3: 記号微分

**目的**: `z = \frac{\partial}{\partial x} \sin(x y)`、`y = f'(x)`、`y = \frac{d^2}{dx^2} e^{-x^2}` が描ける。以後のステップ（$\nabla$・常微分方程式・1 次式の判定）の土台。

**触るファイルと関数**: 新しい `core/src/diff.rs`、`core/src/expand.rs`、`core/src/functions.rs`（導関数の表）、`web/src/lib/latex.ts`、README

**やること**

1. `pub fn diff(e: &Expr, var: &str) -> Result<Expr, String>`（今ある 8 つの節だけの式を受け取る。展開の後に呼ぶ）:
   - 和・差・積・商・合成の規則。べき乗は、指数が `var` を含まなければ $(u^c)' = c\,u^{c-1} u'$、底が含まなければ $(c^v)' = c^v \ln c \cdot v'$、両方含めば $u^v \left(v' \ln u + \dfrac{v\,u'}{u}\right)$
   - 初等関数（`functions.rs` の「初等関数」の全部）と、$\Gamma' = \Gamma\,\psi$、`erf`・`erfc`・`erfi`、`ln`・`log`、ベッセル関数の $z$ での微分（$J_\nu' = \tfrac12 (J_{\nu-1} - J_{\nu+1})$ など、漸化式で書けるもの）
   - 複素数用: $\dfrac{d}{dx}|u| = \dfrac{\operatorname{Re}(\bar u\,u')}{|u|}$、$(\operatorname{Re} u)' = \operatorname{Re} u'$、$(\operatorname{Im} u)' = \operatorname{Im} u'$、$(\bar u)' = \overline{u'}$、$(\arg u)' = \operatorname{Im}\dfrac{u'}{u}$
   - 段差: `floor`・`ceil`・`round`・`sign` は 0。$\operatorname{mod}(a, b)' = a' - b' \lfloor a/b \rfloor$。`min`・`max` は $\max(a, b) = \tfrac12 (a + b + |a - b|)$ に直してから。`Piece` は、値だけを微分する（条件はそのまま）
   - 表に無い関数は中心差分の式（3.2）。差分にした関数を、さらに 2 回を超えて微分しようとしたらエラー
   - 組・行列は成分ごと。リストは要素ごと
2. `pub fn simplify(e: Expr) -> Expr`: $0 + u$、$0 \cdot u$、$1 \cdot u$、$u^1$、$u^0$、$-(-u)$、定数どうしの演算、$0 / u$。`diff` は節を作るたびに呼ぶ
3. 展開: `@diff(x) 項`・`@diff(x, k) 項`（$k$ は 0 以上の整数の定数。8 まで）。変数は、座標・媒介変数・関数の仮引数・パラメータのどれでもよい（パラメータで微分するときは、展開の段ではまだ値を入れていないので、そのまま微分できる。`Params` を畳み込むのはコンパイルのとき）
4. プライム: `f'(式)`（$f$ は 1 引数の関数）は、中身を仮引数で微分してから代入する。`f''`・`f'''` も。2 引数以上の関数にプライムはエラー（「$\partial$ で書いてください」）
5. `latex.ts`: `\frac{d}{dx}`・`\frac{\partial}{\partial x}`・`\frac{\mathrm{d}}{\mathrm{d}x}` → `@diff(x) `、`\frac{d^{2}}{dx^{2}}`・`\frac{\partial^{2}}{\partial x^{2}}` → `@diff(x,2) `、`\frac{\partial^{2}}{\partial x\partial y}` → `@diff(x) @diff(y) `。分子に式がある形 `\frac{d f}{d x}`・`\frac{\partial z}{\partial x}` は、分子が定義された名前 1 つのときだけ `@diff(x) f`（中身は展開の段で決まる）。`f'` → `f'`（`\prime`・`^{\prime}` も）
6. `equation.rs` に `pub fn gradient(e: &Expr, names: &[String]) -> Result<Vec<Expr>, String>` を足す（M7・M8・7 章の N1 が使う）

**やらないこと**: VM に双対数の命令を足すこと。式の整理（共通因数でくくる、三角関数の公式）。`\dot{x}`（M9）。陰関数の微分 $\frac{dy}{dx}$（$F(x, y) = 0$ から $-F_x / F_y$ を作る）。

**完了の条件**

- 新しいテスト（`diff.rs`）: 導関数の表の関数を全部、乱数の点 200 個（実数。関数ごとの定義域の中）で、中心差分（$h = 10^{-6}$）と比べて相対誤差 $10^{-6}$ 以下。複素数の引数（$u = x + 2i$ など）でも同じ
- `z = @diff(x) sin(x y)` と `z = y cos(x y)` のメッシュの頂点の差が $10^{-12}$ 以下。`@diff(x, 2) exp(-x^2)` と `(4x^2 - 2) exp(-x^2)` も
- 節の数: `@diff(x, 4) sin(x^2) cos(x)` の展開の後が 3,000 節以下（簡約が効いていることの確認）
- 差分に落ちる関数: `@diff(x) zeta(x)` が、$x = 2$ で $\zeta'(2) = -0.9375482543\ldots$ と $10^{-6}$ 以内
- `bench.rs` に `z = @diff(x) @diff(y) sin(x y) exp(-x^2)` を足し、時間が手で書いた導関数の式の 1.5 倍以内

**壊してはいけないもの**: 展開の段を通らない式の速さ。

**README**: 「数式の書き方」に微分を足す。差分に落ちる関数があること、微分できない点の扱い（3.2）を書く。

### M4: 総和・総積、等差のリスト、$\pm$

**目的**: $\displaystyle z = \sum_{n=1}^{N} \frac{\sin((2n-1)x)}{2n-1}$（$N$ はスライダー）、$\displaystyle \prod_{k=1}^{5} (x - k)$、`[1, 2, …, 10]`、$y = \pm\sqrt{x}$ が描ける。

**触るファイルと関数**: `core/src/expand.rs`、`core/src/equation.rs`（`expand_lists` の前）、`web/src/lib/latex.ts`・`mathSetup.ts`、README

**やること**

1. `@sum(n, a, b) 項`・`@prod(n, a, b) 項`: $a$・$b$ は展開してから `eval_constant_with` と同じ方法で数にする（座標・媒介変数を含めばエラー「$\sum$ の範囲に $x$ は使えません」）。整数から $10^{-9}$ より離れていればエラー。$b < a$ は 0（積は 1）。項の数の上限は 2.5
2. 項ごとに、束縛する変数へ `Expr::Num(k)` を代入して展開し、平衡のとれた木（左に偏らせない。深さ $\log_2$）で足す・掛ける
3. 入れ子（$\sum_n \sum_m$）は、内側の範囲に外側の束縛する変数を使ってよい（外側の項ごとに内側を展開するので、数になっている）
4. リスト: `[a, b, …, c]`（字句 `…`。`latex.ts` は `\ldots`・`\cdots`・`\dots` を `…` にする）は、$a, b$ から公差 $b - a$ で $c$ を超えない所までの等差の並び。`[a, …, c]` は公差 1。要素は 256 個まで（`expand_lists` の上限と同じ）
5. $\pm$: 字句 `±`・`∓`。式の中に 1 つでもあれば、$\pm \to +$・$\mp \to -$ にした式と、逆にした式の 2 つを作り、`Plot::Multi` にする（1 つの式の中の $\pm$ は全部そろって動く）。単項（`±x`）と 2 項（`a ± b`）の両方
6. `latex.ts`: `\sum_{n=1}^{10}` → `@sum(n,1,10) `（下の添字が `変数=式` の形でなければ「$\sum$ の下に n=1 の形で書いてください」）。`\prod` も。`\pm` → `±`、`\mp` → `∓`

**やらないこと**: 範囲に $\infty$（エラー「上の端をスライダーにしてください」）。範囲が座標で決まる和（$\sum_{n=1}^{\lfloor x \rfloor}$）。添字の集合での和（$\sum_{n \in S}$）。

**完了の条件**

- 新しいテスト: `z = @sum(n,1,3) n x` と `z = 6x` が同じメッシュ。`@prod(k,1,3) (x-k)` と `(x-1)(x-2)(x-3)`。`@sum(n,1,2) @sum(m,1,n) m` の値が 4。$N = 2.5$ のエラー。$b < a$ が 0
- `[1, 3, …, 9]` と `[1, 3, 5, 7, 9]`、`y = ±sqrt(x)` と `y = [1, -1] sqrt(x)` が同じ結果
- `bench.rs`: `z = @sum(n,1,200) sin(n x)/n` のコンパイルが 50 ms 以下、細かさ 150 の計算が、同じ式を手で 200 項書いたものと同じ時間（±5%）。2.5 の判断の分かれ目の数字を PR に貼る
- スライダー $N$ を動かすと、項の数が変わる（画面で確かめる。$N$ の刻みを 1 にするよう、エラーの文に書いてあること）

**壊してはいけないもの**: 今のリスト（`[1, 2, 3]`）。`…` を使わない式。

### M5: 定積分

**目的**: $\displaystyle y = \int_0^x e^{-t^2}\,dt$、$\displaystyle z = \int_0^{2\pi} \cos(x \sin t - y t)\,dt$ が描ける。

**触るファイルと関数**: `core/src/expand.rs`（新しい `quad` の節でもよい）、`web/src/lib/latex.ts`、README

**やること**

1. `@int(t, a, b)(式)`: 区間 $[a, b]$ を半分に分け、それぞれ 16 点のガウス・ルジャンドルで

   $$\int_a^b g(t)\,dt \approx \sum_{j=1}^{2} \frac{h}{2} \sum_{k=1}^{16} w_k\, g\!\left(m_j + \frac{h}{2}\,\xi_k\right), \qquad h = \frac{b - a}{2},\quad m_j = a + \left(j - \tfrac12\right) h$$

   の式に展開する（$\xi_k, w_k$ は表で持つ。$a, b$ は式のまま）。束縛する変数 $t$ へ $m_j + \frac{h}{2}\xi_k$ の式を代入する
2. 端が $\infty$: $\int_a^\infty g(t)\,dt = \int_0^1 g\!\left(a + \frac{s}{1-s}\right) \frac{ds}{(1-s)^2}$、$\int_{-\infty}^{b}$ は反転、$\int_{-\infty}^{\infty}$ は $t = \dfrac{s}{1 - s^2}$（$s \in (-1, 1)$）。ガウスの点は端を含まないので、そのまま使える
3. 入れ子は 2 重まで。内側の積分は 8 点 × 2 にする（節の数を抑える）
4. `latex.ts`: `\int_{a}^{b}` の後、同じ深さで最初に出てくる「`d` + 英字 1 つ」（`\mathrm{d}t`・`\differentialD t`・`\,dt` も）を積分の変数とし、その手前までを括弧で囲んで `@int(t,a,b)(中身)` にする。見つからなければ「積分の変数を dt のように書いてください」。**積分の中では、パラメータ $d$ は使えない**（README に書く）。上下の端が無ければ「積分の範囲を書いてください」

**やらないこと**: 不定積分。適応的な積分。$\iint$・$\oint$（3.7 で除外）。端の特異点の特別扱い。

**完了の条件**

- 新しいテスト: `@int(t,0,1)(t^2)` $= \tfrac13$、`@int(t,0,pi)(sin(t))` $= 2$、`@int(t,0,x)(exp(-t^2))` が $x \in [-3, 3]$ で $\tfrac{\sqrt\pi}{2}\operatorname{erf}(x)$ と $10^{-10}$ 以内、`@int(t,0,∞)(exp(-t))` $= 1$ と $10^{-6}$ 以内、`@int(t,-∞,∞)(exp(-t^2))` $= \sqrt\pi$ と $10^{-6}$ 以内
- 入れ子: `@int(s,0,1)(@int(t,0,s)(1))` $= \tfrac12$
- `z = @int(t,0,2pi)(cos(x sin(t) - y t))` が `2 pi besselJ(y, x)`（$y$ が整数の所）と $10^{-8}$ 以内
- `latex.test.ts`: `\int_{0}^{x}e^{-t^{2}}\,dt` → `@int(t,0,x)(e^(-t^(2)))`、`\int_0^1 t\,dt+1` の `+1` が積分の外
- `bench.rs`: `y = @int(t,0,x)(exp(-t^2))` の時間が、`y = erf(x)` の 40 倍以内

**壊してはいけないもの**: 式の中の文字 $d$（積分の外ではふつうのパラメータ）。

**README**: 「数式の書き方」に積分と、精度の注意（3.3）を足す。

**やること**

2. 演算（展開の段で、成分の式を作る）:
   - `+`・`−`（同じ大きさ）、スカラー倍、スカラーでの割り算、単項の `−`
   - 積: 行列 × 行列、行列 × ベクトル、**ベクトル × ベクトル（`*`・`·`・並べて書く）は内積**、`×` は 3 次元の外積（2 次元なら $u_1 v_2 - u_2 v_1$ のスカラー）
   - べき: 正方行列の $A^n$（$n$ は 0 以上の整数の定数。20 まで）、$A^{-1}$（余因子で。$\det A$ で割る式）、`^T`・`ᵀ`（転置）、`^†`（共役転置）
   - `@det`（余因子展開。小行列式を、使う列の組でメモする）、`@tr`、`@inv`、`@transpose`、`@norm`（$\sqrt{\sum |v_k|^2}$）、`@dot`、`@cross`、`@angle(u, v)` $= \arccos\dfrac{\mathbf u \cdot \mathbf v}{\lVert\mathbf u\rVert \lVert\mathbf v\rVert}$
   - 今ある関数に行列・ベクトルが来たとき: `abs(行列)` は行列式、`abs(ベクトル)` はノルム、`Re`・`Im`・`conj` は成分ごと（`Im(行列)` が像になるのは、**1 行にそれだけを書いたとき**だけ。M7）。それ以外の関数にベクトルを渡したらエラー
   - 成分の取り出し: `v_1`（ベクトル $v$ が定義されていれば、変数 `v1` より優先して 1 つ目の成分）、`A_(1,2)`
3. 定義: `{vec_b} = (1, 2, 3)`・`A = ⟦…⟧`（左辺が定義にできる名前で、右辺がベクトル・行列の形）。成分にパラメータ・座標・媒介変数を使ってよい（使う所で展開する）
4. 式の種類の判定を、展開の**後**の形でする: 1 行がベクトルで、成分が媒介変数だけ → 今までの媒介変数表示（`parametric`）。成分に表示中の座標 → M8（それまではエラー「ベクトル場はまだ使えません」）。ベクトル = ベクトル → 成分ごとの等式の連立（`Chain` を成分の数だけ作って `system` へ）
5. `latex.ts`: `\begin{pmatrix}`・`\begin{bmatrix}`・`\begin{Bmatrix}`・`\begin{matrix}` → `⟦…⟧`（`&` → `,`、`\\` → `;`）、`\begin{vmatrix}` → `@det(⟦…⟧)`、`\det` → `@det`、`\operatorname{tr}` → `@tr`、`^{T}`・`^{\top}`・`^{\intercal}` → `ᵀ`（**底が行列・ベクトルの名前のときだけ**。底の形は `latex.ts` では分からないので、`^(T)` のまま出し、展開の段が「底が行列で、指数が変数 $T$ 1 つ」なら転置にする。$T$ がパラメータでも転置を優先する）、`^{\dagger}` → `^†`、`\left\langle a,b\right\rangle` → `@dot(a,b)`、`\left\Vert a\right\Vert`・`\lVert a\rVert` → `@norm(a)`、`\vec{v}`・`\overrightarrow{v}` → `{vec_v}`、`\times` → `×`（M0 で済み）
6. **行列の大きさを、その場で変えられるようにする**（入れ直さずに、行・列を足す・消す。中身は残す）。3 つの入口を用意し、どれも同じ処理を呼ぶ
   - **行列の中にカーソルがある間だけ出る小さな帯**（入力欄のすぐ下。`ExpressionItem.svelte`）: 「行 ＋」「行 −」「列 ＋」「列 −」の 4 つのボタンと、今の大きさ（`2 × 3`）。大きさの表示を押すと、行と列の数を選ぶ 6 × 6 のマス目が出て、押したマスの大きさに一度で変わる（表計算ソフトの表の挿入と同じ形）。スマホでは、数式キーボードの上に同じ帯を出す（キーボードに隠れない所）
   - **キー**: 行列の中で、Enter = 下に行を足す、Shift + Enter = 上に行を足す、`,`（カンマ）= 右に列を足す、Tab・Shift + Tab = 次・前の成分へ（最後の成分で Tab を押したら、次の行を足す）。空の行・空の列の中で Backspace = その行・列を消す（中身のある行・列は、Backspace では消えない）
   - **数式キーボード**: M14 で足す「行列」の段に、同じ 4 つのキー
   - 足す・消すのは、**カーソルのある行・列を基準**にする（足すのは下・右、消すのはその行・列）。最後の 1 行・1 列は消せない（ボタンを薄くする）。6 × 6 を超える分は足せない
   - 増えた成分は空欄（`\placeholder{}`）で、**空欄は 0 として読む**（`latex.ts`）。足したとたんにエラーにならず、大きさを変えながら絵が続けて変わる

   - 括弧の形（`pmatrix`・`bmatrix`・`vmatrix`）は、大きさを変えても変わらない。組 `(a, b, c)` で書いた列ベクトルには、この帯は出さない（成分を足すのは `,` を打つだけ）
   - 作り方: MathLive（`^0.111.4`）には、行・列を足す・消す命令（`addRowAfter`・`addRowBefore`・`addColumnAfter`・`addColumnBefore`・`removeRow`・`removeColumn`）があるはず（**この環境には `node_modules` が無く、確かめていない。最初に `mathlive` の型定義で名前を確かめること**）。あれば、ボタン・キーは `el.executeCommand(...)` を呼ぶだけ。無い・足りない場合と、マス目からの「一度に変える」は、LaTeX を直接書き換える小さな関数 `resizeMatrix(latex, at, rows, cols)`（新しい `web/src/lib/matrixEdit.ts`。カーソルのある `\begin{…matrix}` … `\end{…matrix}` を `&`・`\\` で分け、足りない所を `\placeholder{}` で埋め、余った所を捨てる。入れ子の行列・成分の中の `\frac` などの `{}` の深さを数える）で行い、`el.setValue` の後にカーソルを元の成分へ戻す
   - カーソルが行列の中かどうか・何行何列目かは、`el.position` より前の LaTeX（`el.getValue(0, el.position, 'latex')`）の、閉じていない `\begin{…matrix}` と、その後の `&`・`\\` の数で求める（`MathInput.svelte` の、添字の中かどうかを調べている所と同じやり方）

### M7: 行列の描き方

**目的**: 3.4 の表のとおりに描く。

**触るファイルと関数**: 新しい `core/src/linalg.rs`（数値の掃き出し）、`core/src/equation.rs`（`system` の手前・1 行の式の判定）、`core/src/expand.rs`、`core/src/lib.rs`、`web/src/lib/ExpressionItem.svelte`・`CoordPanel.svelte`・`App.svelte`・`latex.ts`、README

**やること**

1. `linalg.rs`: 数の行列の、部分ピボット付きの掃き出し（階数・行の簡約形・零空間の基底・列空間の基底）。しきい値は、成分の最大の絶対値 × $10^{-9}$。零空間・列空間の基底は、グラム・シュミットで正規直交にする
2. **連立一次方程式**: `system` に渡す等式が 2 本以上あり、全部が全座標（次元の数）の 1 次式のとき（`diff::gradient` の成分が全部、座標を含まない）、係数を数にして掃き出す。表示していない座標は断面の値を入れて定数の側へ移す。階数 $r$ の独立な等式（行の簡約形）に置き換えてから、今の道へ。矛盾していれば `Err("解がありません（連立一次方程式が矛盾しています）")`。$r = 0$（全部 $0 = 0$）なら、不等式だけの式として扱う。等式が 4 本以上でも、$r \le 3$ なら描ける
3. **$\ker$・$\operatorname{Im}$**: 1 行が `@ker(A)`、または `Im(A)`・`@im(A)`（$A$ が行列の形）のとき。成分を数にして（座標・媒介変数があればエラー）、基底 $\mathbf b_1, \dots, \mathbf b_k$ を求める。列の数（$\operatorname{Im}$ は行の数）が次元と違えば「$\ker A$ は 3 次元の空間の中の集合です。$A$ の列を 3 つにするか、次元を 4 にしてください」。$k = 0$ は原点の点、$k = 1$ は `(t b_1)` の曲線、$k = 2$ は `(u b_1 + v b_2)` の曲面、$k \ge 3$（表示中の 3 つの座標を全部含む）は表示範囲の箱。媒介変数の範囲は、表示範囲の対角線の長さ $\pm$ にし、`coords::trim_to_domain` で箱の中だけ残す。`kind` は「$\ker A$（2 次元。平面）」のように、次元を出す
4. `@dim(…)`・`@rank(A)`: 数になる（式の中で使える）。`\dim\ker A` → `@dim(@ker(A))`
5. **行列式の行**: 1 行が `@det(A)`（成分が全部、座標・媒介変数を含まない。3×3 か 2×2）のとき、`(u a_1 + v a_2 + t a_3)`（$u, v, t \in [0, 1]$。$\mathbf a_k$ は列）の媒介変数表示の立体（2×2 は曲面）として描き、`MeshResult` の `kind` に値（`det = -2`）を入れる。成分に座標があれば、今までどおり「縦 = 式」
6. **行列の行**: `A = ⟦…⟧`（定義）と、行列だけの行。2×2・3×3 で成分が数になるなら、列ベクトルを原点からの線分（先に点）で描く（M8 の矢印ができたら矢印に変える）。それ以外の大きさは図形なし
7. **線形変換**: 行列の定義の行の ⚙ に「座標系として使う」ボタン。押すと、`CoordSystem` を 1 つ足す（`preset: 'custom'`、`map` は `A (x, y, z)` の LaTeX、名前は行列の名前）。座標系の式（`compile_coord_map`）が、定義（`definitions`）を使えるようにする（M0 で展開の段を通してあるので、`Defs` を渡すだけ）。行列の成分のパラメータを動かすと、座標系も動く
8. 2D 表示: 2×2 の行列・2 つの座標の連立方程式・$\ker$・$\operatorname{Im}$ が、平面の中の点・直線・領域になることを確かめる

**やらないこと**: 固有ベクトルの表示。最小二乗解（矛盾した連立方程式の近似の解）。成分に座標のある行列の $\ker$。

**完了の条件**

- 新しいテスト（`linalg.rs`）: 乱数の行列で、零空間の基底 $\mathbf b$ が $\lVert A\mathbf b \rVert < 10^{-9}$、階数 + 零空間の次元 = 列の数
- `x + y + z = 1, 2x + 2y + 2z = 2`（重なった平面）が、平面 1 枚（今は「連立方程式の曲線」と判定される）。`x + y = 1, x + y = 2` が「解がありません」。`x + y + z = 1, x - y = 0, z = 0, 2x + z = 1`（4 本・階数 3）が点 $(\tfrac12, \tfrac12, 0)$
- `@ker(⟦1, 1, 1⟧)` が平面 $x + y + z = 0$ の上（全部の頂点で $|x + y + z| < 10^{-9}$）で、表示範囲の箱の中だけ。`@ker(⟦1,0,0; 0,1,0⟧)` が $z$ 軸。`Im(⟦1,0; 0,1; 0,0⟧)` が平面 $z = 0$
- `@det(⟦2,0,0; 0,1,0; 0,0,3⟧)` の行が、$[0,2] \times [0,1] \times [0,3]$ の箱の面で、`kind` に `6`

**壊してはいけないもの**: 今の連立方程式（1 次式でないもの・1 次式でも独立なもの）のメッシュ。`Im(x + i y)`（引数がスカラーなら虚部）。

### M8: ベクトル場（矢印、$\nabla$）

**目的**: `(-y, x, 0)`、`\nabla (x^2 + y^2 - z)`、`\nabla \times (-y, x, 0)` が、矢印の場として描ける。

**触るファイルと関数**: `core/src/equation.rs`（`Plot::Field`）、新しい `core/src/field.rs`（矢印のメッシュ）、`core/src/lib.rs`（`build`）、`core/src/expand.rs`（`@grad` など）、`web/src/lib/types.ts`・`ExpressionItem.svelte`・`plot.worker.ts`・`latex.ts`、README

**やること**

1. 式の種類: 1 行がベクトルで、成分が表示中の座標を使い、媒介変数（$t, u, v$）を使わない → `Plot::Field { progs: Vec<Program>, … }`（変数は表示中の 3 つの座標）。成分は 3 つ（2D 表示・成分が 2 つのときは、縦の成分を 0 にして横・奥の平面に描く）。表示していない座標は断面の値。関数の定義 `F(x, y, z) = (…)` の行も同じく描く
2. `field.rs`: 表示範囲を各軸 $n$ 個（既定は 3D で 9、2D で 18。⚙ で 4〜24）に分けた格子の中心で、`eval_batch` で値を求める。矢印 1 本は「軸の線分（`outline` の線へ）+ 矢じりの四角錐（三角形 4 枚 + 底。メッシュへ）」。長さは、最大の大きさの矢印が格子の間隔の 0.9 倍になるように全体を同じ倍率で縮める。⚙ の「長さをそろえる」なら全部 0.7 倍の長さ。色は大きさ $\lVert\mathbf F\rVert$ を、頂点ごとの値の 1 つ目に入れて、11 章の色の対応表で塗る（`value_range` も返す）。大きさが 0・有限でない点は描かない
3. 回転: 表示中の座標どうしの回転だけなら、点と向きを $R$ で回す。表示していない座標が絡む回転は「この回転ではベクトル場を描けません」
4. 演算子（展開の段。`diff::gradient` を使う。変数は、次元の数の座標）:
   - `@grad(f)`: $\nabla f = (\partial_x f, \partial_y f, \partial_z f)$
   - `@div(F)`: $\nabla \cdot \mathbf F = \sum_k \partial_k F_k$（スカラー）
   - `@curl(F)`: $\nabla \times \mathbf F$（3 成分。2 成分なら $\partial_x F_2 - \partial_y F_1$ のスカラー）
   - `@lap(f)`: $\nabla^2 f = \sum_k \partial_k^2 f$
5. `latex.ts`: `\nabla\cdot` → `@div `、`\nabla\times` → `@curl `、`\nabla^{2}` → `@lap `、それ以外の `\nabla` → `@grad `（どれも、次の項に掛かる単項の演算子として読む。M0 の演算子の表に「項を取る」印を付ける）。`\operatorname{grad}`・`\operatorname{div}`・`\operatorname{rot}`・`\operatorname{curl}` も
6. `PlotItem` に `field?: { count?: number; unit?: boolean }`（省略できる。保存・共有リンクのテストを足す）

**やらないこと**: 流線（M9）。座標系（9 章）を選んだ式のベクトル場（成分をどの基底で読むかが決まらないので、エラー）。4 次元以上のベクトル場の射影。矢印の太さ・形の設定。

**完了の条件**

- 新しいテスト: `(-y, x, 0)` の矢印の軸の線分が、始点 $\mathbf p$・向き $(-p_y, p_x, 0)$ に平行（外積の大きさ $< 10^{-6}$）。本数が $9^3$。原点（大きさ 0）に矢印が無い
- `@grad(x^2 + y^2 - z)` と `(2x, 2y, -1)` が同じ結果。`@curl((-y, x, 0))` と `(0, 0, 2)`。`z = @div((x^2, y^2, 0))` と `z = 2x + 2y` が同じメッシュ。`z = @lap(x^2 y)` と `z = 2y`
- `bench.rs`: `(-y, x, 0)`（$9^3$ 本）が 5 ms 以下、$24^3$ 本で三角形が 10 万個以下
- 画面: 矢印の色が、大きさで変わる。色の対応表を切り替えても計算し直さない

**壊してはいけないもの**: 媒介変数表示（成分が $t, u, v$ だけ）。組の成分に座標と媒介変数が混ざった式は、今と同じエラーのまま。

**目的**: ローレンツ・アトラクター、$y' = x - y$ の解曲線と傾きの場、$y'' + y = 0$、ベクトル場の流線が描ける。

**やること**

1. `ode.rs`: ドルマン・プリンス法（5 次・4 次の組。刻み幅は自動）

   $$\frac{d\mathbf y}{dt} = \mathbf f(t, \mathbf y), \qquad \text{誤差の見積もり} \le 10^{-9} + 10^{-6}\,\lVert\mathbf y\rVert_\infty$$

   - 右辺は `Program` の並び（変数は状態の成分と $t$）。`eval_batch` を 1 点で呼ぶ
   - 歩数の上限は 1 本 20 万歩、合計 100 万歩。超えたら、そこまでを描いて `kind` に「（途中で打ち切り）」
   - 状態が表示範囲の 8 倍の箱を出たら止める。値が有限でなくなったら止める
   - 出力は、受け入れた歩ごとの点。歩の弦が表示範囲の対角線の $\frac{1}{400}$ より長ければ、エルミートの 3 次補間で間を埋める
   - **同じ入力なら同じ出力**（時間で打ち切らない。歩数だけで決める）
   - $t$ の範囲 $[t_0, t_1]$ の中の初期時刻（既定は 0。範囲に 0 が無ければ $t_0$）から、前と後ろの両方へ解く
2. 式の種類の判定（`compile_with` の最初、連立の判定より前）:
   - **連立**: 全部の行が「座標$'$ = 式」（`x'`・`y''` など。左辺は `Expr::Prime` で、名前が座標）。同じ座標が 2 回出たらエラー。右辺には座標・$t$・パラメータと、**階数より低いプライム**（`x'' = -x - x'/5`）を使える。プライムの付いていない表示中の座標があれば、その成分は一定（$' = 0$）。状態は、座標ごとに階数の分だけ（合計 12 まで）
   - **1 本**: 行が 1 つで、プライムの付いた座標がちょうど 1 つ（未知関数 $y$。横の座標ではないこと）。独立変数は横の座標。最も高い階数 $y^{(k)}$（4 まで）について、式を $F = 0$ の形にし、$y^{(k)}$ を仮の変数 $s$ と見て、$F$ が $s$ の 1 次式なら（`diff::diff(F, s)` が $s$ を含まない）

     $$y^{(k)} = -\frac{F|_{s = 0}}{\partial F / \partial s}$$

     で解いた形にする。1 次式でなければ「最も高い階の導関数について解いた形で書いてください」
3. 初期値: `PlotItem` に `ode?: { init: string[]; t0?: string }`（定数の式の LaTeX。パラメータを使える。省略すると、状態は全部 1、導関数は 0）。⚙ に、状態の成分ごとの入力欄（`y(0) =`・`y'(0) =`）を出す。入力欄にリスト（`[0, 1, 2]`）を書くと、組み合わせの数だけ解曲線を描く（64 本まで）。$t$ の範囲は、媒介変数の範囲と同じ欄（`item.ranges.t`。既定は $-10 \le t \le 10$。1 本の形では、横の座標の表示範囲）
4. 描くもの:
   - 連立: 状態の座標の成分を点にした曲線（`Plot::Curve` と同じく、全部の座標の成分を持ち、`Space::view` で回転・射影する。4 次元以上もそのまま）
   - 1 本: 曲線 $(x, y(x))$（未知関数が奥の座標なら横・奥の平面、縦なら横・縦の平面）。1 階のときは、傾きの場も描く（格子の点に、向き $(1, f(x, y))$ の同じ長さの短い線分。M8 の矢印の軸だけを使う。⚙ で消せる）
   - 自励系（右辺に $t$ が無い）の連立で、状態が表示中の座標だけのときは、⚙ の「ベクトル場も描く」で M8 の矢印を重ねる
5. **流線**: ベクトル場の行（M8）の ⚙ に「流線」。格子の点（各軸 $m$ 個。既定 4）を始点に、$\mathbf x' = \mathbf F(\mathbf x)$ を同じ解法で解いて描く（長さは、弧長が表示範囲の対角線の 2 倍まで）
6. `latex.ts`: `x'` → `x'`、`\dot{x}` → `x'`、`\ddot{x}` → `x''`、`\frac{dx}{dt}`・`\frac{\mathrm{d}x}{\mathrm{d}t}` → `x'`（分子が「d + 座標 1 つ」、分母が「d + 変数 1 つ」の形）、`\frac{d^{2}y}{dx^{2}}` → `y''`

**やらないこと**: 硬い方程式用の陰的な解法。境界値問題。偏微分方程式。初期値をグラフの上でドラッグすること（パラメータにしておけば、スライダーや複素数のスライダーの平面で動かせる。グラフの上でのドラッグは 7 章の N4 と一緒に考える）。遅延微分方程式。

**完了の条件**

- 新しいテスト（`ode.rs`）: $y' = y$、$y(0) = 1$ の $t = 5$ での値が $e^5$ と相対誤差 $10^{-5}$ 以内。$x' = -y,\ y' = x$、$(1, 0)$ から $t \in [0, 20\pi]$ で、全部の点が $|x^2 + y^2 - 1| < 10^{-4}$。同じ入力で 2 回解いた結果が、ビットまで同じ
- `y'' + y = 0`（$y(0) = 0$、$y'(0) = 1$）の曲線が $y = \sin x$ と $10^{-4}$ 以内。`2 y' + 4 y = 8`（1 次式から解く形）が $y = 2 + C e^{-2x}$
- `y' y' = 1` が「解いた形で書いてください」のエラー

- $y' = y^2$、$y(0) = 1$（$x = 1$ で発散）が、箱を出た所で止まり、エラーにならない
- 画面: 初期値に使ったパラメータのスライダーを動かすと、解曲線がその場で変わる（1 本の解で 16 ms 以下を目安に、PR に時間を貼る）

**壊してはいけないもの**: `f'(x)`（M3 の導関数）。座標でない名前のプライムは、常微分方程式にしない。

**README**: 機能の一覧に「常微分方程式」。「数式の書き方」に書き方と、初期値の欄・硬い方程式を扱わないこと。サンプルにローレンツ・減衰振動・傾きの場。

### M11: 集合と論理

**目的**: $\{(x, y, z) \mid x^2 + y^2 < 1,\ 0 \le z \le 2\}$、$(x^2 + y^2 + z^2 \le 4) \land \lnot(z > 1)$、$A \cup B$、$A \setminus B$、$(x, y, z) \in [0,1] \times [0,2] \times [0,1]$ が描ける。

**触るファイルと関数**: `core/src/parser.rs`（論理式の文法）、新しい `core/src/logic.rs`（標準形）、`core/src/equation.rs`（`system`・`Plot::Multi`）、`core/src/system.rs`（和集合の切り取り）、`core/src/expand.rs`（集合の定義・$\in$）、`web/src/lib/latex.ts`、README

**やること**

1. 文法（`parse_system` を広げる。優先順位は弱い順）:

   ```text
   formula := iff
   iff     := imp ('⇔' imp)*
   imp     := or ('⇒' imp)?                     右結合
   or      := and (('∨' | '∪') and)*
   and     := not ((',' | '∧' | '∩' | '∖') not)*   ∖ は「かつ ¬」
   not     := '¬' not | atom | atom 'ᶜ'
   atom    := chain | '(' formula ')' | 集合の名前 | '{' 点 '|' formula '}' | 式 '∈' 集合 | '⊤' | '⊥' | '∅'
   ```

   - 今の式（`,` で区切った関係の連鎖）は、そのまま `and` の並びとして読める。結果の `Vec<Chain>` も、論理式が「かつ」だけなら今と同じものを返す
   - `(` の後が論理式か、ふつうの式かは、対応する `)` までに関係の字句・論理の字句が（深さ 0 で）あるかで決める
   - 集合の括弧は `{` `|` `}`（`latex.ts` が `\left\{ … \mid … \right\}`・`\{ … : … \}` から出す。2.2 の `{名前}` と区別するため、`latex.ts` は集合の括弧を `⦃ … ∣ … ⦄` の字句で出す）
2. 内包的表記 `⦃ 点 ∣ 条件 ⦄`: 点が、表示中の座標の組（`(x, y, z)`・`(x, y)`）か、座標 1 つなら、条件だけを取り出す。点が式（`⦃ (cos t, sin t) ∣ 0 ≤ t ≤ pi ⦄`）なら、媒介変数表示にして、媒介変数だけの不等式は媒介変数の範囲にする。それ以外の条件が付いていればエラー
3. `logic.rs`:
   - 論理式の木を、否定を内側へ押し込んだ形（否定は原子の直前だけ）にし、選言標準形（かたまりの「または」）に直す。かたまりは 16 個まで（超えたら「条件が複雑すぎます」）
   - 原子の否定: $L < R \to L \ge R$、$L \le R \to L > R$、$L = R \to L \ne R$。連鎖 $a < b < c$ は先に「かつ」に分ける
   - $\ne$ は、かたまりの中では取り除き、`kind` に「（≠ は描けないので無視）」。かたまりが $\ne$ だけなら全空間（箱）
   - $A \Rightarrow B$ は $\lnot A \lor B$、$A \Leftrightarrow B$ は $(A \land B) \lor (\lnot A \land \lnot B)$
   - $\top$ は条件なし、$\bot$・$\emptyset$ はかたまりなし（何も描かない。エラーにしない）
4. 描く: かたまりが 1 つなら、今の `system` へそのまま。2 つ以上なら、かたまりごとに `system` でコンパイルして `Plot::Multi` にする。**領域（等式 0 本）のかたまりが 2 つ以上あるとき**は、メッシュを作った後、ほかの領域の内側（厳密に内側）に入った面を `system::trim_mesh` で切り取る（値の関数は、ほかの領域の不等式の $\max_j G_j$ の符号を逆にしたもの。2 つの領域の境目が重なる所は残す）
5. $\in$（展開の段。`式 ∈ 集合` を論理式にする）:
   - 名前を付けた集合（`S = ⦃…⦄` の定義）: 左が表示中の座標の組ならそのまま、ほかの点 $(a, b, c)$ なら、集合の条件の座標へ代入する
   - 区間: `x ∈ [a, b]` は $a \le x \le b$。`(a, b)`・`[a, b)`・`(a, b]` は端の不等号を厳密にする（**$\in$ の右の `(a, b)` は、組ではなく開区間**）。端の `∞`・`-∞` は条件なし
   - 直積: `(x, y, z) ∈ I × J × K` は、成分ごとの $\in$ の「かつ」。`S × I`（集合 $S$ が 2 つの座標の条件）も
   - `ℝ`・`ℂ` は $\top$。`ℤ`・`ℕ`（1 以上）は、その式が表示中の座標 1 つなら、表示範囲の中の整数 $k$ ごとの等式 $x = k$ の「または」（64 個まで）。座標 1 つでない式（`x + y ∈ ℤ`）は等式 `sin(pi (x + y)) = 0`。`ℚ` はエラー「有理数の集合は描けません」
   - `∉` は `¬(… ∈ …)`、`∋` は左右を入れ替えた `∈`
6. 集合の定義 `S = ⦃ … ⦄`・`S = A ∪ B`: `Defs` に論理式として入れる。定義の行も描く。名前だけの行（`S`）・集合の式（`A ∖ B`）も描く
7. `latex.ts`: `\land`・`\wedge` → `∧`、`\lor`・`\vee` → `∨`、`\neg`・`\lnot` → `¬`、`\implies`・`\Rightarrow`・`\Longrightarrow` → `⇒`、`\impliedby`・`\Leftarrow` → 左右を入れ替えた `⇒`（`⇐` の字句を出し、解析器で入れ替える）、`\iff`・`\Leftrightarrow`・`\biconditional` → `⇔`、`\cap` → `∩`、`\cup` → `∪`、`\setminus`・`\smallsetminus`・`\backslash` → `∖`、`\in` → `∈`、`\notin` → `∉`、`\ni`・`\owns` → `∋`、`\ne`・`\neq` → `≠`、`\emptyset`・`\varnothing` → `∅`、`\top` → `⊤`、`\bot` → `⊥`、`\mathbb{R}` → `ℝ`（Z・N・C・Q も）、`^{c}`・`^{\complement}`・`\complement` → `ᶜ`（底が集合のときだけ補集合。`latex.ts` は `^(c)` のまま出し、展開の段が決める。M6 の `^T` と同じ）、`\left(a,b\right]`・`\left[a,b\right)` → 半開区間、`\And` → `∧`

**やらないこと**: $\exists$・$\forall$（M12）。集合どうしの関係（$\subset$）。集合の濃度・測度。3 つ以上の領域の和集合で、境目が重なる所の面の重複を完全に除くこと（半透明のときに少し濃く見えるのは許す。README に書く）。

**完了の条件**

- 新しいテスト（`logic.rs`）: 標準形の単体テスト（ド・モルガン、分配、$\Rightarrow$、連鎖の否定、かたまりの上限）
- `⦃(x,y,z) ∣ x^2+y^2<1, 0≤z≤2⦄` と `x^2+y^2<1, 0≤z≤2` が同じメッシュ。`x^2+y^2+z^2≤4 ∧ ¬(z>1)` と `x^2+y^2+z^2≤4, z≤1`
- `x^2+y^2+z^2 ≤ 1 ∨ (x-1)^2+y^2+z^2 ≤ 1`（2 つの球の和集合）: 全部の頂点が、もう一方の球の内側（中心からの距離 $< 1 - 2h$、$h$ は格子の間隔）に無い。`core/tests/shape.rs` の物差しで、正解（`min` で 1 本にした不等式を細かさ 2 倍で描いたもの）との欠け・余計が 1% 以下
- `A = ⦃(x,y,z) ∣ x^2+y^2+z^2 ≤ 4⦄`、`B = ⦃(x,y,z) ∣ z > 0⦄` のもとで、`A ∖ B` と `x^2+y^2+z^2 ≤ 4, z ≤ 0` が同じメッシュ
- `(x,y,z) ∈ [0,1]×[0,2]×[0,1]` が箱。`x ∈ ℤ` が、表示範囲の中の整数の平面
- `x^2 + y^2 = 1 ∨ z = 0`（等式どうしの「または」）が、円柱と平面の両方
- `x ≠ 0, x^2+y^2+z^2 ≤ 1` が球で、`kind` に注意が出る
- 2D 表示で、`x^2+y^2<1 ∨ (x-1)^2+y^2<1` の領域と境目の線（点線）が描ける
- 今の `core/tests/systems.rs` が変更なしで通る

**壊してはいけないもの**: 今の連立方程式・不等式の文法（`,`・連鎖）と、そのメッシュ。絶対値の `|`（集合の区切りは `latex.ts` が `∣` で出すので、`|x|` とぶつからない。`\{x \mid |x| < 1\}` のテストを足す）。リストの `[a, b]`（$\in$ の右でだけ区間）。

## 6. 危ない所

1. **展開した式が大きくなる**（2.5）。$\sum$ の中に積分、行列式の中に $\sum$、のように重ねると、すぐ上限に届く。上限のエラーが分かりやすいことと、M4・M5 の後の測定（判断の分かれ目）を省かないこと
2. **`f(x)` の読み方が、定義があるかどうかで変わる**。定義の行を消すと、`f(2x)` は積に戻り、「変数 'f' は…」のエラーになる。これは正しい動きだが、エラーから「$f$ の定義を追加」ボタンを出して、迷わないようにする（M1 の 7）
3. **記号微分の式は、数値の桁落ちを起こしやすい形になることがある**（$\frac{d}{dx}\frac{\sin x}{x}$ の $x \to 0$）。元の式が持っていた特別扱い（`sinc`）は、導関数の表に個別に入れる。見つけたものから `diff.rs` のテストに足す
4. **固定の点数の積分**（3.3）は、振動の激しい被積分関数（$\int_0^{100} \sin(t^2)\,dt$）で、黙って間違った値を返す。誤差を見積もっていないので、警告も出せない。README に書き、需要があれば、16 点と 32 点の差が大きいときに `kind` へ「（積分の精度が足りない可能性）」を出す（展開の式を 2 つ作るので時間が 1.5 倍になる。入れるなら M5 の後に別の PR）
5. **行列の `^T`・集合の `^c`・`Im`・`|A|`** は、底の形で意味が変わる。パラメータ $T$・$c$ を定義している人が、行列の $T$ 乗（意味が無いのでエラーになる）を書くことは無いはずだが、**スカラーの底のときは必ず今までどおり**になることを、M6・M11 のテストに入れる
6. **常微分方程式の解は、カオス的な系では機械・ビルドによって見た目が変わる**（浮動小数点の演算の順番）。ネイティブと WASM で同じ結果になるとは限らない。テストは、保存量・解析解のある式で書き、ローレンツは点の数と時間だけを見る
7. **和集合の切り取り**（M11 の 4）は、2 つの領域の面がちょうど重なる所（$x \le 0 \lor x \ge 0$ の $x = 0$）で、切るか残すかが丸めで揺れる。残す側に倒す（厳密に内側だけを切る）。重なった面が 2 枚描かれるのは許す
8. **行列の大きさを変える操作が、キーの今の意味とぶつかる**（M6 の 6）。Enter は「新しい式の行を足す」、`,` は組・連立の区切りに使っている。行列の中かどうかの判定を間違えると、ふつうの式で Enter が効かなくなる。判定は 1 つの関数にまとめ、行列の外・行列の成分の中の括弧の中（`\begin{pmatrix}\left(1,2\right)…` の `,` は組の区切りのまま）のテストを書く。画面が大きくなるなら、計算（M6 の 1〜5）と、この操作（M6 の 6）を 2 つの PR に分けてよい
9. **`latex.ts` が育ちすぎる**。今は 400 行の、前から置き換えるだけの作り。このままでは M11 の辺りで読めなくなる。M6 に入る前に、命令ごとの小さな関数の表（命令の名前 → 変換の関数）に分けてよい（振る舞いを変えない整理。それだけの PR にする）
10. **12 章（画素ごとに描く）との関係**: `Func::Piece`（M2）は GLSL へ移す関数の表に足す必要がある。展開の段の後の式はふつうの式なので、$\sum$・微分・積分・行列を使った陰関数は、12 章の道でもそのまま描ける（命令の数の上限だけ注意。GLSL の長さ）

### 7.4 全体のおすすめの順番

1. **M0 → M1 → M4 → M3 → M2 → M5**（関数・$\sum$・微分・場合分け・積分）。使う人から見える効果が大きく、ほかの全部の土台になる
2. **G0**（12 章の試作と測定）を、上と並行で。結果で 12 章を続けるかが決まる
3. **N1**（勾配を式から）。小さく、陰影とニュートン法の精度が上がる。12 章の G3 も軽くなる
4. **M6 → M7 → M8 → M9**（ベクトル・行列・ベクトル場・常微分方程式）
5. **M10 → M11 → M13 → M14**（数列・集合・小さな記号・キーボードの整理）。M12 は余裕があれば
6. 12 章を続けるなら **G1 → G2 → G3 → G4 → G5 → G7 → G6 → G8**
7. **N2 → N3 → N4**（曲率・測地線・点を押す）。M3・M9 の後なら、どれも中くらいの大きさ
8. 残り（N5〜N10、`implicit-pieces.md` の「まだのもの」）は、需要を見て。N10（精度の検証）は、いつやっても損が無い

やらないと決めたもの: $\lim$・$\iint$・$\oint$・集合どうしの関係・固有ベクトルの表示・偏微分方程式・硬い常微分方程式（理由は 3.7 と各ステップの「やらないこと」）。
