## やりたいこと（依頼者の言葉をもとに）

### 1. 連立方程式

- **3 次元の中の直線**: `y = x, z = 0`（$xy$ 平面の上の直線 $y = x$）
  - ただし、3 次元で `y = x` だけを書いたときは、**今と同じく平面**のまま（既存の式・共有リンクの見え方を変えない）
- **等号の連鎖**: `y = x = z`（直線 $x = y = z$）
- **愉快な形**: `sin(x) = cos(y) = tan(z)`（2 つの曲面 $\sin x = \cos y$ と $\cos y = \tan z$ の交わる線。$\tan z$ の極がある）

### 2. 不等式

- **1 本の不等式**: `x ≤ y`（半空間）、`x^2 + y^2 + z^2 < 4`（球の中身）
- **不等号の連鎖**: `x ≤ y ≤ z`（$x \le y$ かつ $y \le z$ のくさび形の領域）
- `<`・`≤`・`>`・`≥` の 4 つ（入力は `<=`・`>=` と、数式入力の `\le`・`\ge`・`\lt`・`\gt` も）

数式で書くと、扱いたいのは次の集合です（$\mathbf p$ は表示中の座標。表示していない座標は今と同じく断面の値か範囲）:

$$
S = \{\, \mathbf p \mid F_1(\mathbf p) = 0,\ \dots,\ F_m(\mathbf p) = 0,\ G_1(\mathbf p) \le 0,\ \dots,\ G_k(\mathbf p) \le 0 \,\}
$$

3 次元では、$m = 0$ なら立体（領域）、$m = 1$ なら曲面、$m = 2$ なら曲線、$m = 3$ なら点の集まり（一般の位置では）。

## 何が難しいか（依頼者の見立て）

- **交わる線の精度**: 2 つの曲面がほぼ接する所（交わる角度が小さい所）で、線がちぎれる・ジグザグになる。
  $\tan z$ のような極の両側で、偽の線ができる
- **連立不等式の角**: $\max(G_1, G_2) \le 0$ を 1 つの陰関数として Surface Nets にかけると、面と面の交わる**角が丸まる**
  （7 章で Dual Contouring を見送った理由と同じ）。角を立てるには、面ごとにメッシュを作って、ほかの条件で切り取る必要がありそう
  （7 章の S22 `trim_undefined`・S26 `trim_to_branch` と同じ種類の「二分で境目を求めて切る」処理）
- **領域の見せ方**: `x ≤ y` は表示範囲いっぱいに広がる。境目の面だけを描くのか、半透明の立体にするのか、端のふたを付けるのか。
  2D 表示では Desmos のように塗りつぶし（`<` は境目を点線）が自然だが、3D でどう見せるか
- **ほかの機能との組み合わせ**: 回転（表示していない座標が絡む回転）、4 次元以上の断面、範囲で重ねる、リスト `[1, 2]`、パラメータ、
  2D 表示（投影・切り口）、切り口とふた、複素数の色分け、粗い版、共有リンクの互換性
- **等式と不等式の混在**: `x^2 + y^2 + z^2 = 4, z ≥ 0`（半球）、`y = x, 0 ≤ x ≤ 1`（線分）。
  不等式で「切り取る」処理があれば自然に付いてくるはず

## 調べてほしいこと

1. **文法**
   - 括弧の外の `,` で式を区切る形（`y = x, z = 0`）と、連鎖（`y = x = z`、`x ≤ y ≤ z`、`0 ≤ x ≤ 1`）を、今の `parse_at`・`compile_with` にどう入れるか。
     今の「`=` が 1 つでパラメータの定義になる」判定（`a = 1`）とぶつからないか
   - 連鎖の意味: `a = b = c` は $\{a = b,\ b = c\}$、`a ≤ b ≤ c` は $\{a \le b,\ b \le c\}$。`a ≤ b = c` のような混ぜ方を許すか
   - 媒介変数表示と組み合わせるか（`(cos t, sin t, t), z ≥ 0` のような切り取り）。やるなら同じ仕組みで済むか
2. **交わる線（$m = 2$）の作り方**。少なくとも次の 2 つを試作して比べる
   - (a) $F_1 = 0$ のメッシュの頂点で $F_2$ を計算し、$F_2 = 0$ の線を取り出す（`slice_mesh` を一般の関数に広げる形）。最後に $F_1 = F_2 = 0$ の上へニュートン法
     $\mathbf p \leftarrow \mathbf p - J^{+}(\mathbf p)\,\mathbf F(\mathbf p)$（$J$ は $2 \times 3$ のヤコビ行列、$J^{+}$ は擬似逆行列）で寄せる
   - (b) 格子のセルで直接求める（セルの面の上で $F_1 = 0$ の線と $F_2$ の符号の変化を調べ、線分をつなぐ）
   - どちらを $F_1$ にするか（式の順番で結果が変わらないか）、極（$\tan z$）・定義されない所・接する所での振る舞い、時間
   - 曲線の正しさの物差し（7 章の `shape_report` のような数字）。例: 正解の線（媒介変数で書ける式で作る）との距離の最大・平均、途切れの数、偽の線の長さ
   - 確認に使う式の例: `y = x, z = 0`、`y = x = z`、`x^2 + y^2 = 4, z = x`（楕円）、`x^2 + y^2 + z^2 = 4, x^2 + y^2 = 2x`（ヴィヴィアーニの曲線。$(2, 0, 0)$ で自分と交わる）、
     `x^2 + y^2 = 1, x^2 + z^2 = 1`（2 本の楕円が交わる）、`sin(x) = cos(y) = tan(z)`、`z = 0, x^2 + y^2 = 4`（円）、`x^2 + y^2 + z^2 = 4, z = 2`（1 点で接する）
3. **点（$m = 3$）**: `x = y = z = 1`、`x^2 + y^2 + z^2 = 4, x = y, z = 0` など。やるか、やるならどう求めるか（セルごとのニュートン法など）。
   4 次元以上で `m` が表示中の次元を超える場合の扱い（エラーにするか、空にするか）
4. **不等式（$m = 0$）の作り方**
   - 1 本: 今の `Field`（範囲で重ねた立体）と同じ道で $G \le 0$ の立体として描けるか。切り口のふた・端のふた（S16）がそのまま使えるか
   - 連鎖・連立: (a) $\max_i G_i \le 0$ を 1 本の陰関数にする（角が丸まる。どのくらい丸まるかを測る）、
     (b) 面 $G_i = 0$ ごとにメッシュを作り、ほかの $G_j \le 0$ で切り取る（角が立つ。切り取りの継ぎ目の頂点を共有できるか）。
     `x ≤ y ≤ z`、`abs(x) ≤ 2, abs(y) ≤ 2, abs(z) ≤ 2`（立方体）、`x^2 + y^2 ≤ 9, x^2 + z^2 ≤ 9`（シュタインメッツの立体）、`0 ≤ z ≤ sin(x) cos(y)` で比べる
   - 等式と混ざる場合（$m = 1$ か $2$ で、$k \ge 1$）: 曲面・曲線を不等式で切り取る。上の (b) と共通にできるか
   - `<` と `≤` の違いを見た目に出すか（2D の点線など）
5. **見せ方**（3D の領域）: 境目の面だけ／半透明の立体／ふた付きの立体、のどれを既定にするか。今の半透明（`depthWrite` を切るだけ）で破綻しないか。
   無限に広がる領域（`x ≤ y`）が表示範囲の箱で切られて見えることを、どう分かりやすくするか
6. **2D 表示**: 不等式の塗りつぶし（`y ≤ x^2` など）、連立不等式の重なり、2D での連立方程式（`y = x, y = x^2` → 交点）。
   今の 2D の「投影」「切り口」の 2 つの描き方との関係
7. **回転・n 次元**: 陰関数と同じく「式に $\mathbf p = \mathbf c + R^\top(\mathbf q - \mathbf c)$ を代入する」で全部済むか。
   回転の再生中の時間（S6 の予算）に収まるか。陽関数の行（`z = f(x, y)` の形）が混ざるときに、S19 のような陽関数の道を使うべきか
8. **画面側**: 式の種類の表示（`kind_label`）、数式入力（MathLive）で `≤` を打つ方法、エラーの文言、サンプル（`samples.ts`）に足す例
