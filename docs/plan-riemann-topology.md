# 計画: リーマン面（N8）と位相幾何

文書 1（`docs/plan-roadmap.md`）。多価関数のリーマン面（`plan-math-notation.md` 7.3 の N8）と、位相幾何の「測る・作る・変形・結び目」を、
1 ステップずつ（1 ステップ = 1 PR）の指示書にする。ステップの名前は、位相幾何が **U0〜U4**、リーマン面が **R0〜R5**。
各ステップの「担当」は `docs/agent-tiers.md` の段階。

**順番の要点**: 位相幾何の「測る」（U0）を先に入れ、リーマン面（R）が正しくつながっているかを、オイラー標数 $\chi$ と
リーマン・フルヴィッツの公式で**数で**確かめる物差しにする。

## 2. 全体の決めごと

### 2.1 位相は「射影する前の形」で測る

クラインの壺は 3 次元に入れると自分と交わるが、位相（つながり方）は交わりとは関係ない。
**頂点の位置が 3 次元で重なったからといって、つなげてはいけない**。だから:

- 媒介変数の曲面: 媒介変数の格子のつながり（`NdShape` の格子・`tris`）で測る。溶接するのは**媒介変数の範囲の端どうし**
  （$u = u_0$ の列と $u = u_1$ の列、$v$ も同じ）と、**格子の 1 行が 1 点になる所**（球の極）だけ。端どうしの点が n 次元で（3 次元ではない）
  一致すれば溶接する
- 陰関数: メッシュはもともと頂点を共有している（Surface Nets）。そのまま測る。表示範囲の箱で切れた所は「縁」になるので、
  「表示範囲の端で切れています」と知らせる
- 陽関数: 定義域の四角で必ず縁があり、$\chi$ はほぼいつも 1（円板）なので、測らない

### 2.2 リーマン面は「点ごとの値の集合」と「となりどうしの対応」で作る

主値の式を少しずつ直すのではなく、次の 2 段で作る（N8 の「となりの点に一番近い枝を選ぶ」を、全体の一貫した作りにしたもの）:

1. **値の集合**: 格子の各点 $z$ で、多価関数の値を**全部**（有限個）求める。$\sqrt z$ なら $\{\pm\sqrt z\}$、$\log z$ なら
   $\{\operatorname{Log} z + 2\pi i k\}$（$k$ は決めた範囲）
2. **対応**: 格子の三角形ごとに、3 つの頂点の値の集合を「一番近いものどうし」で対応させる。対応した組が 1 枚の三角形になる

こうすると、どの点にも「何枚目のシート」という番号を付けなくてよい。分岐点の周りを 1 周すると別の値に移る（モノドロミー）ことは、
三角形ごとの対応をつないだ結果として、自然にメッシュのつながりに現れる。**枝の切れ目という考えが要らない**。

### 2.3 分岐点は格子の頂点にする

分岐点（値が重なる所）を含む三角形では「一番近いもの」が決まらない。分岐点の位置を先に求め、そこを格子の頂点として入れ、
周りを扇形の三角形にする。分岐点の頂点では、重なった値を 1 つにまとめる（$\sqrt z$ の原点では値は 0 の 1 つ）。

### 2.4 確かめ方: リーマン・フルヴィッツ

表示範囲（位相的には円板 $D$）の上の $n$ 枚のリーマン面で、$D$ の中の分岐点 $p$ の分岐指数を $e_p$ とすると、作ったメッシュは

$$\chi = n \cdot \chi(D) - \sum_{p \in D} (e_p - 1) = n - \sum_{p \in D} (e_p - 1)$$

になるはず。U0 で測った $\chi$ がこれと合えば、つなぎ方が正しい。さらに無限遠での分岐も数えれば、閉じたリーマン面の種数 $g$ が

$$2g - 2 = -2n + \sum_{p \in \hat{\mathbb C}} (e_p - 1)$$

から出る（$\hat{\mathbb C}$ は無限遠を足した複素平面）。

### U0: 位相を測る

- **担当**: B（理由: 計算は単純だが、どの頂点を溶接するか（2.1）を間違えると数が全部ずれる）
- **平たい説明**（README にも書く）: 曲面を三角形に分けたとき、頂点の数 $V$・辺の数 $E$・面の数 $F$ から $\chi = V - E + F$ を作ると、
  曲面をどう三角形に分けても同じ値になる。球は 2、ドーナツ（トーラス）は 0、穴が $g$ 個のドーナツは $2 - 2g$。
  「向き付け可能」は表と裏の区別があること（メビウスの帯・クラインの壺には無い）。「縁」は面の端の輪
- **触るファイル**: 新しい `core/src/topology.rs`、`core/src/lib.rs`（`MeshResult` に結果を足す）、`web/src/lib/ExpressionItem.svelte`（⚙ のチェックと表示）、`core/tests/topology.rs`（新規）
- **やること**
  1. 入力は三角形の一覧と頂点（n 次元）。2.1 の規則で溶接する（媒介変数の曲面は格子の端どうし・1 点につぶれる行。許す誤差は表示範囲の大きさの $10^{-9}$ 倍）
  2. 面積が 0 の三角形を除き、同じ 3 頂点の三角形が 2 枚あれば 1 枚にする
  3. 辺ごとに使っている三角形の数を数える。1 つなら縁の辺、2 つなら内側の辺、3 つ以上なら「つながり方が曲面になっていない所」（非多様体の辺）として数を知らせる
  4. 連結成分（union-find）ごとに、$V$・$E$・$F$・$\chi$・縁の輪の数 $b$（縁の辺をたどって数える）・向き付け可能か
     （三角形の向きを隣へ伝えていき、矛盾したら不可）を出す
  5. 種数: 向き付け可能なら $g = \dfrac{2 - \chi - b}{2}$、不可なら「クロスキャップの数」$k = 2 - \chi - b$
  6. ⚙ の「位相を調べる」（D4）でオンにする。式の下に、成分ごとに「$\chi = 0$ · 穴 1 個 · 向き付け可能 · 縁 0 本」。
     表示範囲の箱で切れた縁があれば「表示範囲の端で切れています（縁に数えています）」
  7. 測るのは媒介変数の曲面（`NdShape` の格子・`tris`）と陰関数。陽関数・曲線・立体は「位相は曲面だけ調べます」
- **やらないこと**: 媒介変数 3 つの立体の位相。自分と交わる所の検出
- **完了の条件**（`core/tests/topology.rs`）

  | 図形 | $\chi$ | 縁 | 向き付け | 種数 |

  | 球（陰関数 $x^2+y^2+z^2=4$） | 2 | 0 | 可能 | 0 |
  | トーラス（媒介変数） | 0 | 0 | 可能 | 1 |
  | 穴 2 つのトーラス（陰関数 $\left((x^2+y^2)^2 - x^2 + y^2\right)^2 + z^2 = 0.01$ など、実装時に表示範囲に収まる式を選ぶ） | $-2$ | 0 | 可能 | 2 |
  | 円柱（媒介変数、上下は開いたまま） | 0 | 2 | 可能 | 0 |
  | メビウスの帯 | 0 | 1 | 不可 | — |

  | 表示範囲から半分はみ出た球（陰関数） | 1 | 1（「端で切れています」） | 可能 | — |

### R1: 多価関数の値の集合

- **担当**: A（理由: 合成した式の枝の組み合わせと重複の扱いを間違えると、枚数が合わないまま描けてしまう）
- **触るファイル**: 新しい `core/src/branch.rs`、`core/src/expand.rs`（または `eval.rs` の `ProgramSet` を使う所）
- **やること**
  1. 式の木の中の多価の関数に「枝の番号」を付けた式の並びを作る。規則:

     | 関数 | 枝 $k$ の値 | 枝の数 |
     |---|---|---|
     | $\sqrt u$ | $(-1)^k \sqrt u$ | 2 |
     | $u^{p/q}$（$p/q$ は既約な有理数の定数） | $e^{2\pi i k p/q} \cdot u^{p/q}$（主値） | $q$ |
     | $\log u$、$u^a$（$a$ が有理数でない） | $\operatorname{Log} u + 2\pi i k$、$e^{a(\operatorname{Log} u + 2\pi i k)}$ | D2 の枚数 |
     | $\arcsin u$ など逆三角関数・逆双曲線関数 | 対数の形（$\arcsin u = -i \log\!\left(iu + \sqrt{1-u^2}\right)$ など）に直してから上の規則 | 組み合わせ |
     | $W_k(u)$（ランベルト W） | 今の関数に枝の引数を足せるか確かめる。足せなければ対象外 | D2 の枚数 |

  2. 合成した式では、内側の枝と外側の枝の組み合わせを全部作る（$\sqrt{1 + \sqrt z}$ は 4 通り）。**上限 64 通り**。超えたら「枝が多すぎます（64 まで）」

  4. 対象外の関数（`floor`・`abs`・`arg`・場合分け・ゼータなど、枝の規則が無い関数を、多価の関数の**内側に**含む式）は「リーマン面にできない関数が入っています（floor）」
- **やらないこと**: 規則の表に無い多価の特殊関数（多重対数・超幾何関数の解析接続）
- **完了の条件**: 枝の数が $\sqrt z$: 2、$z^{2/3}$: 3、$\sqrt{1+\sqrt z}$: 4、$(\sqrt z)^2$: 1、$\log z$: D2 の枚数、$\arcsin z$: 2 × D2 の枚数。
  各枝の値が、別の式で計算した正解と $10^{-12}$ 以内（例: $\arcsin$ の枝は $(-1)^m \operatorname{Arcsin} z + m\pi$）

### R2: リーマン面のメッシュ

- **担当**: A（理由: 分岐点の扱いと対応の失敗の検出が、この計画でいちばん難しい所）
- **触るファイル**: `core/src/branch.rs`、`core/src/mesh.rs`（`NdShape` を返す新しい関数）、`core/src/lib.rs`、`web/src/lib/ExpressionItem.svelte`（⚙）、`core/tests/riemann.rs`（新規）
- **やること**
  1. 分岐点を探す: 値の差の積 $\Delta(z) = \prod_{i<j} (w_i(z) - w_j(z))^2$ は、枝の入れ替えで変わらないので枝の切れ目で飛ばない。
     格子で $\lvert\Delta\rvert$ が小さい所から始めてニュートン法で零点を求める（$\Delta$ の導関数は差分でよい）。値が発散する所（$\log$ の原点・極）は「穴」として扱い、頂点にしない
  2. 格子（1 辺は今の陽関数の細かさ）に分岐点を頂点として入れ、近くの三角形を作り直す（扇形）
  3. 対応: 三角形の辺ごとに、両端の値の集合を最小の距離の和で対応させる（枝の数が 8 以下なら全部の並べ方、それより多ければ近い順に貪欲に）。
     三角形の 3 辺の対応を一周してもとの値に戻らないとき、または対応した値の差が周りの差の 4 倍を超えるときは、その三角形を二分して細かくする
     （`adaptive.rs` と同じ二分。6 回まで）。それでも直らなければ、その三角形は描かず、数を知らせる

### R3: 分岐点・モノドロミー・種数の表示

- **担当**: A（理由: 無限遠での分岐の数え方を間違えると、種数が黙って違う）
- **触るファイル**: `core/src/branch.rs`、描画（分岐点の印）
- **やること**
  1. 分岐点ごとに、半径（ほかの分岐点までの距離の半分）の円に沿って、値を小さな刻みで続け（となりに一番近い値を選ぶ）、1 周後の値の入れ替え（置換）を求める。
     置換の巡回の長さが分岐指数 $e_p$
  2. 全部の分岐点を囲む大きな円でも同じことをし、無限遠での分岐を求める
  3. 式の下に表: 分岐点・分岐指数・（枚数が有限なら）閉じたリーマン面の種数 $g$（2.4 の式）。分岐点に印を付ける
  4. 枚数が無限（$\log$）なら、種数は出さず「対数の分岐点（枚数は無限）」
- **完了の条件**: 種数が $\sqrt{z(z-1)}$: 0、$\sqrt{z^3-1}$: 1、$\sqrt{(z^2-1)(z^2-4)}$: 1、$\sqrt[3]{z^3-1}$: 1、$\sqrt{z^5 - 1}$: 2。

### U3: 結び目（管・絡み数・有名な結び目）

- **担当**: B（理由: 管の向きの決め方（ねじれない枠）と、絡み数の正確な数え方に注意が要る）
- **平たい説明**: 紐の両端をつないだ輪が結び目。ほどけない輪（三葉結び目）と、ほどける輪がある。2 本の輪が何回からまっているかを数えたものが絡み数
- **触るファイル**: `core/src/mesh.rs`（または新しい `core/src/tube.rs`）、`core/src/topology.rs`、`samples.ts`、`latex.ts`
- **やること**
  1. `\operatorname{tube}(\gamma, r)`: 曲線 $\gamma(t)$ を半径 $r$ の管（曲面）にする。枠はねじれの少ない枠（回転最小化枠。二重反射法: Wang ほか 2008）。
     閉じた曲線（始点と終点が一致）なら、1 周でずれた枠の角度を全体に均等に配って、継ぎ目のねじれを無くす
  2. `\operatorname{lk}(\gamma_1, \gamma_2)`: 2 本の閉じた曲線の絡み数。曲線を折れ線（細かく取った点）にし、ある向きに射影した図の交差を符号付きで数えて 2 で割る（整数が正確に出る）。
     射影の向きは、交差が頂点や接する所に重ならない向きを選ぶ（乱数の向きを数回試す）。式の下に値
  3. サンプル（「位相幾何」の群）: 三葉結び目、8 の字結び目、トーラス結び目 $(p, q)$（$p$・$q$ はスライダー）、ホップ絡み目（$\operatorname{lk} = 1$）、
     ホワイトヘッド絡み目（$\operatorname{lk} = 0$ だが、ほどけない。絡み数で分からない例）、ボロミアン環（どの 2 本も $\operatorname{lk} = 0$ なのに、3 本ではほどけない）
- **やらないこと**: 結び目の不変量（ジョーンズ多項式など）、ほどけるかの判定
- **完了の条件**: 管が閉じた曲線で継ぎ目無く描ける（U0 で $\chi = 0$・縁 0 本のトーラス）。絡み数がホップ 1、ホワイトヘッド 0、
  $(2, 2k)$ トーラス絡み目の 2 成分で $k$。曲線の点の数を 2 倍にしても同じ値
- **README**: 「結び目」の段落

## 6. 危ない所

- **2.1 の溶接**: 媒介変数の端どうしの溶接を、位置だけで（3 次元で）してしまうと、クラインの壺の自分と交わる所がつながって $\chi$ が狂う。
  必ず「格子の端どうし」と「n 次元での一致」の両方を条件にする
- **R2 の分岐点の見落とし**: $\Delta$ の零点探しが分岐点を見落とすと、その周りで対応が一周して合わず、三角形が抜ける。抜けた数を必ず知らせ、
  テストでは $\chi$ が合うことで見落としが無いことを確かめる
- **R1 の枝の爆発**: 多価の関数を何重にも合成すると、組み合わせが 64 を超える。重複を除く前に数えて打ち切る
- **R0 が失敗したとき**: R1〜R5 はやらない。U0〜U4 は R と関係なく進められる
- **見た目の自己交差**: リーマン面は 3 次元に射影すると自分と交わって見えるのが普通（$\sqrt z$ も）。README に「交わって見えるのは射影のせいで、
  4 次元では交わっていない。4 次元の回転で確かめられる」と書く
