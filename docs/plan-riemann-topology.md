## 2. 全体の決めごと

### 2.1 位相は「射影する前の形」で測る

クラインの壺は 3 次元に入れると自分と交わるが、位相（つながり方）は交わりとは関係ない。
**頂点の位置が 3 次元で重なったからといって、つなげてはいけない**:

- 媒介変数の曲面: 格子のつながり（`NdShape` の格子・`tris`）で測る。溶接するのは**格子の端どうし**（$u = u_0$ の列と $u = u_1$ の列、$v$ も同じ）と、
  **格子の 1 行が 1 点になる所**（球の極）だけ。端どうしの点が **n 次元で**一致すれば溶接する
- 陰関数: メッシュはもともと頂点を共有している（Surface Nets）。そのまま測る。表示範囲の箱で切れた所は「縁」になるので知らせる
- 陽関数: 定義域の四角で必ず縁があり $\chi$ はほぼ 1（円板）なので、測らない

### 2.2 リーマン面は「点ごとの値の集合」と「となりどうしの対応」で作る

1. **値の集合**: 格子の各点 $z$ で、多価関数の値を**全部**（有限個）求める。$\sqrt z$ なら $\{\pm\sqrt z\}$、$\log z$ なら $\{\operatorname{Log} z + 2\pi i k\}$
2. **対応**: 格子の三角形ごとに、3 頂点の値の集合を「一番近いものどうし」で対応させる。対応した組が 1 枚の三角形になる

どの点にも「何枚目のシート」という番号を付けない。分岐点の周りを 1 周すると別の値に移る（モノドロミー）ことは、
三角形ごとの対応をつないだ結果として、メッシュのつながりに自然に現れる。**枝の切れ目という考えが要らない**。

### 2.3 分岐点は格子の頂点にする

分岐点（値が重なる所）を含む三角形では「一番近いもの」が決まらない。分岐点の位置を先に求めて格子の頂点として入れ、周りを扇形の三角形にする。
分岐点の頂点では、重なった値を 1 つにまとめる（$\sqrt z$ の原点では値は 0 の 1 つ）。

### 2.4 確かめ方: リーマン・フルヴィッツ

表示範囲（位相的には円板 $D$）の上の $n$ 枚のリーマン面で、$D$ の中の分岐点 $p$ の分岐指数を $e_p$ とすると、作ったメッシュは

$$\chi = n \cdot \chi(D) - \sum_{p \in D} (e_p - 1) = n - \sum_{p \in D} (e_p - 1)$$

になるはず。無限遠での分岐も数えれば、閉じたリーマン面の種数 $g$ が

$$2g - 2 = -2n + \sum_{p \in \hat{\mathbb C}} (e_p - 1)$$

から出る（$\hat{\mathbb C}$ は無限遠を足した複素平面）。

  - カップの陰関数: 外側の円柱の殻 $\max\!\left(\lvert\sqrt{x^2+y^2} - 1\rvert - 0.1,\ \lvert z\rvert - 1\right)$ と底、取っ手のトーラスを、なめらかな最小
    $\operatorname{smin}_k(a, b) = -\dfrac{1}{k} \log\!\left(e^{-ka} + e^{-kb}\right)$ でつなぐ（$k = 8$ くらい）。式はサンプルの中に書く（新しい関数は足さない）
  - 球 → トーラス: $F_s = \left(\sqrt{x^2+y^2} - 2s\right)^2 + z^2 - (1 - 0.5 s)^2$。穴が開くのは $2s = 1 - 0.5s$、つまり $s = 0.4$
- **完了の条件**: 2 つのサンプルが描け、2 つ目で $\chi$ が 2 → 0 に変わる $s$ が $0.4$ と格子の間隔の範囲で一致

### U3: 結び目（管・絡み数・有名な結び目）

- **担当**: B（理由: 管の向きの決め方（ねじれない枠）と、絡み数の正確な数え方に注意が要る）
- **平たい説明**: 紐の両端をつないだ輪が結び目。ほどけない輪（三葉結び目）と、ほどける輪がある。2 本の輪が何回からまっているかを数えたものが絡み数
- **触るファイル**: `core/src/tube.rs`（新規）、`core/src/topology.rs`（絡み数）、`equation.rs`（`tube`・`lk` の行の判定）、`samples.ts`、`latex.ts`
- **やること**
  1. `\operatorname{tube}(\gamma, r)`: 曲線を半径 $r$ の管（曲面）にする。枠はねじれの少ない回転最小化枠（二重反射法: Wang ほか 2008）。
     閉じた曲線なら、1 周でずれた枠の角度を全体に均等に配って継ぎ目のねじれを無くす
  2. `\operatorname{lk}(\gamma_1, \gamma_2)`: 2 本の閉じた曲線の絡み数。式の下に値
  3. サンプル（「位相幾何」の群）: 三葉結び目、8 の字結び目、トーラス結び目 $(p, q)$（スライダー）、ホップ絡み目（$\operatorname{lk} = 1$）、
     ホワイトヘッド絡み目（$\operatorname{lk} = 0$ だがほどけない）、ボロミアン環（どの 2 本も $\operatorname{lk} = 0$ なのに、3 本ではほどけない）
- **実装の土台**

  ```rust
  /// 曲線の点の列 p[0..n]（閉じていれば p[n-1] ≈ p[0]）から管の NdShape（3 次元、格子 n × m）を作る
  pub fn tube(p: &[[f64; 3]], r: f64, m: usize, closed: bool) -> NdShape {
      // 接線 t_i = (p_{i+1} − p_{i−1}) の正規化。最初の法線 r_0 は t_0 に垂直な任意の単位ベクトル
      // 二重反射: v1 = p_{i+1} − p_i; c1 = v1·v1; rL = r_i − (2/c1)(v1·r_i) v1; tL = t_i − (2/c1)(v1·t_i) v1;
      //           v2 = t_{i+1} − tL; c2 = v2·v2; r_{i+1} = rL − (2/c2)(v2·rL) v2
      // 閉じていれば、r_{n−1} と r_0 の角度 φ を求め、i 番目の枠を −φ·i/(n−1) だけ接線の周りに回す
      // 点 = p_i + r (cos θ_j r_i + sin θ_j (t_i × r_i))、θ_j = 2πj/m
  }
  /// 絡み数: 折れ線どうしの射影の交差を符号付きで数えて 2 で割る
  pub fn linking_number(a: &[[f64; 3]], b: &[[f64; 3]]) -> Result<i64, String> {
      // 射影の向き d を乱数で選び（種は固定、3 回まで）、d に垂直な平面に射影した線分どうしの交差を全部調べる（n·m の総当たり。点は 2,000 まで）
      // 交差ごとに、どちらが上か（d 方向の高さ）と向きから ±1。交差が線分の端に近すぎる・平行に近いなら、別の d でやり直す
      // 合計は必ず偶数になるはず（奇数なら Err）。合計 / 2
  }
  ```

- **やらないこと**: 結び目の不変量（ジョーンズ多項式など）、ほどけるかの判定
- **完了の条件**: 管が閉じた曲線で継ぎ目無く描ける（U0 で $\chi = 0$・縁 0 本）。絡み数がホップ 1、ホワイトヘッド 0、$(2, 2k)$ トーラス絡み目の 2 成分で $k$。
  曲線の点の数を 2 倍にしても同じ値

## 6. 危ない所

- **2.1 の溶接**: 位置だけで（3 次元で）溶接すると、クラインの壺の自分と交わる所がつながって $\chi$ が狂う。必ず「格子の端どうし」と「n 次元での一致」の両方を条件にする
- **R2 の分岐点の見落とし**: $\Delta$ の零点探しが分岐点を見落とすと、その周りで対応が一周して合わず三角形が抜ける。抜けた数を必ず知らせ、テストでは $\chi$ が合うことで見落としが無いことを確かめる
- **R1 の枝の爆発**: 多価の関数を何重にも合成すると、組み合わせが 64 を超える。重複を除く前に数えて打ち切る
- **R0 が失敗したとき**: R1〜R5 はやらない。U0〜U4 は R と関係なく進められる
- **見た目の自己交差**: リーマン面は 3 次元に射影すると自分と交わって見えるのが普通。README に書く
