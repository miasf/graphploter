# 計画: 定積分の数値計算（第2段階 2b: #109 #110 #111 #112 #113 #159）

実装済み（6 章に、決めたことと、計画から変えた所）。

対象は計算エンジン（`core/`）の数値積分。値が定数になる積分は `expand.rs` の `closed_integral_value` → `nested_integral` → `quad.rs` の適応型積分（ガウス・クロンロッド 7–15 点、無限区間は変数変換と Wynn の $\varepsilon$ 加速）で 1 つの数にする。端や中身が座標で変わる積分（$\int_0^x$）は、`expand.rs` の `integral` で、ガウス・ルジャンドルの 16 点 × 2 区間の和の式にする。

手で確かめた原因:

- **A. 端の特異点の扱い**: 有限の端で被積分関数が大きくなるとき、15 点の公式どうしの差（誤差の見積もり）が小さく出て、積分を早く打ち切る（測った時間は 0 ms）。発散しても、収束するのに遅い（$t^{-0.9}$）ものでも、そこそこの数を返す。端で発散するかどうかを確かめる処理が無い
- **B. 区間の中の特異点・境目**: 区間を分けるのは誤差の大きい所だけなので、特異点や場合分けの境目に点が乗らないと気づかない。**特異点・境目で手で区間を分けると、どれも正しい値になる**（$1 + \sqrt3$・$2\sqrt2$・0.01 を確認）
- **C. 振動する無限区間**: 零点の間ごとの積分の部分和を Wynn の $\varepsilon$ で加速している。$\sin t$ の部分和 $0, 2, 0, 2, \dots$ は収束しないのに、加速すると平均の 1 になる（アーベル和）。「零点の間の積分が 0 に近づいていく」ことを確かめていない
- **D. 端での 0/0**: 振動の処理（`quad.rs` の `oscillatory`）が、最初に下の端 $t = 0$ での値を計算し、$\frac{\sin 0}{0}$ が数でないので諦める。**下の端を $10^{-9}$ にずらすと $\pi/2$ になる**ことを確認
- **E. 変数上限の積分**: $\int_0^x$ は 32 点の決まった和なので、$x$ が大きく振動が速いと点が足りない。端の $\frac{1}{\sqrt t}$ も 32 点では足りない。誤差を見積もっていないので、ずれていても何も出ない

## 2. 方針

### 2.1 区間を、式から分かる特異点・境目で分ける（B: #110 #159 と、A の区間の中の分）

被積分関数の式（展開した後の `Expr`）から、値が飛ぶ・発散する・折れる可能性のある場所の「もとになる式」 $g$ を集め、積分の区間の中で $g = 0$ になる点を求めて、そこで区間を分ける（QUADPACK の QAGP と同じ考え方。分ける点を利用者が書く代わりに、式から自動で見つける）。

| 式の形 | 調べる $g$ |
|---|---|
| $a / b$、$a^{c}$（$c$ が負・整数でない） | $b$、$a$ |
| $\ln a$、$\sqrt a$、$\lvert a\rvert$、$\operatorname{sign} a$ | $a$ |
| $\tan a$、$\sec a$ | $\cos a$（$\cot a$・$\csc a$ は $\sin a$） |
| 場合分けの条件 $p < q$、$\min(p, q)$、$\max(p, q)$ | $p - q$ |
| $\lfloor a\rfloor$・$\lceil a\rceil$・$\operatorname{round}$・$\operatorname{mod}$ | $a$ が整数をまたぐ所 |

$g = 0$ の点は、区間を 512 等分した点の符号の変わり目を二分法で詰めて求める。$t^2$・$(t - c)^2$ のように符号が変わらずに 0 に触れるものは、$\lvert g\rvert$ の小さい所を黄金分割で詰め、ほぼ 0（$10^{-12}$ 倍以下）なら点として使う。点が 200 個を超えたら分けず、「誤差の見積もりが目標に届いていません」の注意を出す（今の動き）。

### 2.2 端で発散するかを確かめる（A: #109 と、#112 の端）

区間の両端（2.1 で分けた点も、その小区間の端になる）ごとに、端に向かって幅が半分ずつになる区間 $[a + h 2^{-k-1}, a + h 2^{-k}]$（$k = 0, 1, \dots, 40$。$h$ は小区間の幅の半分）に分けて、それぞれを適応型で積分する（今の `integrate_wide` が原点の近くでしている分け方と同じ）。

端で $f(t) \approx C (t - a)^p$ なら、$k$ 番目の区間の積分 $c_k$ は公比 $r = 2^{-(p+1)}$ の等比数列になる:

$$
c_k \approx C' \, 2^{-k(p+1)}
$$

- $r < 0.97$（$p > -0.956$ くらい）: 収束する。最後の区間から先の分は、等比級数の和 $c_K \frac{r}{1 - r}$ を足す
- $r \ge 1$（$p \le -1$。$\frac1t$ は $c_k$ がどれも $\ln 2$）: 発散する。「$t = 0$ の近くで $\lvert f\rvert$ が $\lvert t\rvert^{-1.00}$ のように大きくなるので、積分は発散します」と出し、値と平面は出さない
- $0.97 \le r < 1$、または $c_k$ が等比数列にならない（比がそろわない）: 「収束を確認できません」と出し、値と平面は出さない

$f$ が端で有限なら $c_k$ は公比 $\frac12$ なので、ふつうの積分の値は変わらない（区間が増えるだけ）。端のすぐ近くで、$a + \delta$ の桁が足りなくなる所（$\delta < 10^{-12} \lvert a\rvert$）より先は計算せず、等比級数で足す。

$\int_{-1}^{1} \frac1t\,dt$ のコーシーの主値（0）は出さない（Issue のとおり。主値は別の書き方にする場合だけ）。

### 2.3 振動する無限区間は、零点の間の積分が 0 に近づくことを確かめる（C: #111）

`oscillatory` で、零点の間ごとの積分 $p_k$（48 個）について、前半（$k = 8 \sim 15$）と後半（$k = 41 \sim 48$）の $\lvert p_k\rvert$ の平均を比べ、後半が前半の 0.8 倍より小さいときだけ、加速した値を使う。そうでなければ「振動が小さくならないので、積分は収束しません（または収束を確認できません）」と出す。

$\frac{\sin t}{t}$（$p_k \propto 1/k$）、$\sin(t^2)$（$\propto 1/\sqrt k$）、$e^{-t}\sin t$ は通り、$\sin t$・$\cos t$・$t \sin t$ は弾かれる。

### 2.4 端で値が数でない点を避ける（D: #112）

`oscillatory` の最初の点を、下の端から少し内側（$10^{-9}(1 + \lvert a\rvert)$）にする。下の端と最初の零点の間の積分は今までどおり適応型で計算するので（端の点そのものは使わない）、値は変わらない。$\frac1t$ のように端で発散する式は 2.2 で先に弾く。

### 2.5 変数上限の積分の図（E: #113。#109 の $\int_0^x \frac1t\,dt$ も）

決めてほしいこと（4.3）の答えで変える。おすすめは次の (a)。

**(a) 誤差を見積もり、合わない点は描かない（小さい変更）**
1. ガウス・ルジャンドル 16 点 × 2 区間を、ガウス・クロンロッド 15 点 × 4 区間にする。同じ点で 7 点の公式の値も作り、2 つの差を誤差の見積もりにする。差が表示の縦の範囲の $10^{-3}$ 倍より大きい点は値を出さない（グラフが途切れる）。式の説明に「$x$ の大きい所などは、積分の近似の誤差が大きいので描いていません」と出す
2. 端の特異点（$\frac{1}{\sqrt t}$）は、$t = a + (b - a)\frac{1 - \cos \pi s}{2}$ と置き換えて、端で点が密になるようにする（今の定数の積分で使っている置き換えと同じ考え方）
3. 下の端が数で、被積分関数が積分の変数とパラメータだけの式なら、2.2 の端の検査を一度だけする。$\int_0^x \frac1t\,dt$ は「下の端 0 で発散します」と出して描かない

被積分関数を計算する回数は、1 点あたり 32 回 → 60 回（約 1.9 倍）。$\int_0^x \sin(t^2)\,dt$ は、点が足りなくなる $x \approx 6$ より先が描かれなくなる（間違った振動は出ない）。

**(b) 1 変数の曲線だけ、積み上げて正確に描く（大きい変更）**
$y = \int_a^x f(t)\,dt$ の形（$f$ が $t$ とパラメータだけの式）なら、表示範囲の $x$ を細かく分け、$F(x_{k+1}) = F(x_k) + \int_{x_k}^{x_{k+1}} f$ を適応型で積み上げた表を作って描く。$x = 100$ でも固定上限の値と合う。式を表で持つ道が計算エンジンに無いので、新しく作る。曲面 $z = \int_0^x f(t, y)\,dt$ は (a) のまま。

## 6. 決めたことと、実装の記録

### 6.1 決めたこと（2026-11-24）

1. ふつうの積分ではコーシーの主値を出さない。主値は関数のように `\operatorname{PV}\int_a^b` と書いたときだけ（計算エンジンの `@pvint`）
2. 収束が遅すぎて確かめられない場合は、そう書いて値を出さない
3. #113 は (a)。描かない点があることを、式の説明に書く
4. #159 の見落としの防止は、式から分かる境目だけ

### 6.2 計画から変えた所

- **端の検査**（2.2）: $p$ の見積もりの「そろっているか」は、最後の 8 区間と真ん中の 8 区間の傾きで比べる（最後の 16 区間の前半・後半では、
  $\frac{1}{t \ln^2 t}$ の傾きの変わり方が 0.01 より小さく、見逃した）。端の近くで、区間の積分が目標に届かなかった（激しく振動して区間の数の上限に届いた）
  ときは、$t = a + 1/u$ と置き換えて ∞ までの積分にし直す（$\int_0^1 \sin \frac1t\,dt$ が $10^{-8}$ まで合う）。
  $f$ が有限で、残りが無視できるほど小さくなったら、先の区間は計算せずに等比級数で足す
- **振動の検査**（2.3）: 前半と後半の $|p_k|$ の比ではなく、$|p_k| \propto |t|^{-q}$ の $q$ で決める（比で決めると、Σ のオイラー・マクローリンの残り
  $\int_{1024}^\infty \frac{\sin x}{x^2}\,dx$ のように始まりが遠い積分を弾いてしまった）。$q \le 0.05$ は「収束しません」、$q < 0.3$ は「確かめられません」
- **変数上限の積分**（2.5 (a)）: 4 区間ではなく、両端に向かって幅を半分ずつにした 8 区間（曲面は 4 区間）。4 等分だと $\int_0^x e^{-t^2}\,dt$ が
  $x = 100$ で描けなかった。描かない点の印は、場合分けではなく、名前で呼べない関数 `Guard(v, m)`（$m \ge 0$ なら $v$、そうでなければ NaN）。
  場合分けにすると、値が飛ぶ所を探す処理が曲面の全体で動いて 70 倍遅くなった。誤差の基準は $10^{-5}(1 + |K|)$（$10^{-4}$ では、QUADPACK の見積もりで
  K の誤差が 0.3% まで残る）。中に積分がある入れ子は、式が 10 倍になるので今までの和のまま
- **主値**: 両側をまとめる幅は、隣が区間の端ならその端まで、隣も分ける点ならその点との中点まで（区間の半分にすると、残りを別々に積分した丸めが残り、
  $\mathrm{PV}\int_{-1}^1 \frac{dt}{t}$ が $2 \times 10^{-16}$ になった）。$c + u$ の丸めで打ち消し合いがずれる分は 0 とみなし、$u$ は $10^{-6}|c|$ までにする

- 値が定数になる積分の時間: 表の 10 式の合計 155 ms（いちばん遅いのは $\int_0^1 \sin\frac1t\,dt$ の 76 ms。100 ms 以内）
- 変数上限の積分を描く時間（`graph_core::plot`、3 回のうち最も速いもの）:

  | 式 | 前 | 後 |

  | $y = \int_0^x \sin(t^2)\,dt$（2D） | 3.1 ms | 15.5 ms |
  | $y = \int_0^x e^{-t^2}\,dt$（2D） | 2.5 ms | 8.5 ms |
  | $y = \int_0^x \frac{dt}{\sqrt t}$（2D、$x \le 100$） | 2.4 ms | 7.5 ms |
