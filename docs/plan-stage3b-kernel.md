# 計画: ほぼ特異な行列の階数・零空間（第3段階 3b: #124）

実装済み（4 章の 4 つとも、おすすめのとおりに決めてもらった。5 章に、計画から変えた所）。3b のほかの Issue（#115 #116 #117 #123 #139 #141 #149 #161）も直した。

## 1. 調べた結果（今の版で測った値）

`@ker(A)`・`@rank(A)` だけの行の説明（`graph_core::plot`）。

| 行列 | 今の結果 | 正しい結果 |
|---|---|---|
| $\begin{pmatrix}1&1\\1&1+10^{-8}\end{pmatrix}$ | $\{0\}$ | $\{0\}$ |
| $\begin{pmatrix}1&1\\1&1+10^{-12}\end{pmatrix}$ | 1 次元、span$\{(1,-1)\}$ | $\{0\}$（$\det = 10^{-12}$） |
| $\begin{pmatrix}1&1\\1&1\end{pmatrix}$ | 1 次元、span$\{(1,-1)\}$ | 同じ |
| 上の $1+10^{-12}$ の行列を $10^{6}$ 倍・$10^{-6}$ 倍 | どちらも 1 次元 | $\{0\}$ |
| スライダー $k = 10^{-12}$ の $\begin{pmatrix}1&1\\1&1+k\end{pmatrix}$ | 1 次元 | $\{0\}$ |
| $\begin{pmatrix}1&2&3\\4&5&6\\7&8&9.000000001\end{pmatrix}$ | 1 次元、span$\{(1,-2,1)\}$ | $\{0\}$（$\det = -3\times10^{-9}$） |
| $\begin{pmatrix}\sqrt2&1\\2&\sqrt2\end{pmatrix}$ | 1 次元 | 1 次元（ちょうど特異。成分の丸めで $\det \approx 4\times10^{-16}$） |
| `@rank` $\begin{pmatrix}1&1\\1&1.000000000001\end{pmatrix}$ | 1 | 2 |

原因: `core/src/linalg.rs` の `reduce_tol` が、掃き出しのピボットの絶対値が「成分の最大の絶対値 × $10^{-9}$」以下なら 0 とみなす。
行列全体を定数倍しても判定は変わらない（しきい値も同じ倍率）が、**丸め誤差でちょうど特異な行列**（$\sqrt2$ の例）と、
**本当に特異に近いだけの行列**（$10^{-12}$ の例）を区別していない。0 とみなしたことは説明に出ない。

同じ掃き出しを使う所: `rank`・`dim`・`ker`・`Im`（説明と図）、固有空間（$A - \lambda I$。しきい値 $10^{-7}$）、
`logic.rs` の連立 1 次方程式、`equation.rs` の 3 つの平面の交わり。

## 2. 直し方の案

### 2.1 成分が有限桁の小数なら正確に（案 A）

#123 で行列式に入れた `exact_det` と同じく、成分が全部「整数か小数点以下 15 桁までの小数」（打った数・刻みのスライダーの値）なら、
$10^d$ 倍した整数で、割り算の無い掃き出し（Bareiss 法、i128。あふれたら案 B へ）をして、階数と零空間を正確に求める。
$10^{-12}$ の例・3×3 の例・スライダーの例は $\{0\}$、$k = 0$ は直線になる。基底のベクトルは分数になるので、今の書き方（有効 6 桁、整数は整数）で出す。

### 2.2 それ以外の成分（$\sqrt2$・$\pi$・三角関数の値）は数値の階数（案 B）

特異値（2×2〜6×6 なのでヤコビ法で十分速い）で決める。$\sigma_1 \ge \dots \ge \sigma_n$ に対して:

| $\sigma_k / \sigma_1$ | 扱い | 説明に出すこと |
|---|---|---|
| $\le 16 n \varepsilon$（$\approx 10^{-14}$。丸め誤差の程度） | 0 | なし（今と同じ見た目） |
| $16 n\varepsilon$ 〜 しきい値 $\tau$ | 0 とみなす（近似） | 「≈」と判定基準（下の例） |
| $> \tau$ | 0 でない | なし |

例: `ker A ≈ span{(0.707107, −1)}（数値の階数。最小の特異値 3.1×10⁻¹² が最大の 10⁻⁹ 倍以下なので 0 とみなした）`

ピボットより特異値のほうが、行の入れ替え・行の定数倍に左右されにくい（Issue の「閾値だけで次元が変わりにくくする」）。

## 4. 決めてもらうこと

1. **有限桁の小数の行列を正確に扱うか（案 A）**。おすすめ: する。打った数・スライダーの値はこれで正しい次元になる
2. **それ以外の行列のしきい値 $\tau$**。おすすめ: $10^{-9}$（今と同じ大きさ。$\sin$ などで計算した成分の丸めを吸収できる）。
   丸め誤差の程度（$\approx 10^{-14}$）だけにすると、計算した成分の行列（$\cos(\pi/3)$ を含むなど）で本当は特異なのに「$\{0\}$」と出ることがある
3. **「≈」と判定基準を出す範囲**。おすすめ: `ker`・`Im`・`rank`・`dim` の説明。固有空間（$A - \lambda I$。$\lambda$ が数値なので、もともと近似）と、
   `logic.rs`・`equation.rs` の中の連立 1 次方程式は今のまま
4. **「≈」の文**。上の例の形でよいか

## 5. 実装（決めたことと、計画から変えた所）

決めたこと: 1. 有限桁の小数の行列は正確に扱う。2. それ以外のしきい値は $\tau = 10^{-9}$。3. 「≈」と判定基準は `ker`・`Im`・`rank`・`dim` の説明だけ
（固有空間と、`logic.rs`・`equation.rs` の中の連立 1 次方程式は今のまま）。4. 「≈」の文は 2 章の例の形。

- `core/src/linalg.rs` の `reduce_exact`（有理数の掃き出し。有理数はグレブナー基底の `Rat` を使う）・`singular_values`（片側ヤコビ法）・
  `reduce_judged`（正確にできなければ、特異値で決めた階数 $r$ と、ちょうど $r$ 本のピボットになるしきい値での掃き出し）
- 正確に扱える小数を、小数点以下 15 桁から 22 桁（$n \le 2^{53}$）に広げた（`Rat::from_f64`）。$10^{-6}$ 倍した行列の成分 $0.000001000000000001$ は 18 桁で、
  15 桁までだと数値の道に落ちて「≈」になっていた（数値の判定自体は特異値の比なので、倍率によらない）
- 文: `ker A ≈ span{(0.707107, −1)}、…（1 次元。直線。数値の階数。特異値 4.7×10⁻¹³ が最大（3）の 10⁻⁹ 倍以下なので 0 とみなした）`。
  0 とみなした特異値が 2 つ以上なら、そのうち最大のものを出す。`rank ≈ 1（数値の階数。…。高さがこの値の平面）`
- 回帰のテストは `core/tests/numeric_judgements.rs` の `nearly_singular_kernels`（3 章の表）
