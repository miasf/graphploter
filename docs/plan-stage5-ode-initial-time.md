# 計画: 常微分方程式の初期時刻（第5段階: #131）

実装済み（4 章の 4 つとも、おすすめのとおりに決めてもらった。6 章に実装）。

## 1. 調べた結果

初期時刻 $t_0$ は、解く範囲（1 本の式なら横の表示範囲、連立なら $t$ の範囲の欄）から毎回決めている（`core/src/lib.rs` の `ode_built`）:

$$
t_0 = \begin{cases} 0 & (\text{範囲に } 0 \text{ がある}) \\ \text{範囲の始まり} & (\text{無い}) \end{cases}
$$

初期値の欄の見出しは、いつも `y(0) =`・`y′(0) =`（`web/src/lib/ExpressionItem.svelte` の `prettyOde`）。

| 操作 | 今の結果 | 正しい結果 |
|---|---|---|
| `y''+y=0`、$y(0)=1$、$y'(0)=0$、横 $[-1, 2]$ | $y = \cos x$。$x = 2$ で $-0.4161468$ | 同じ |
| 横を $[1, 2]$ に動かす | 初期時刻が 1 に移り、$y = \cos(x - 1)$。$x = 2$ で $0.5403022$ | 同じ $\cos x$ の切り取り（$x = 2$ で $-0.4161468$） |
| 見出し | `y(0) =` のまま | 実際の初期時刻と一致 |

表示範囲を動かす（パン・ズーム）だけで別の解になり、見出しとも合わない。保存・共有したグラフも、開いたときの表示範囲で解が変わる。

## 2. 直し方の案

### 案 A: 初期時刻をいつも 0 にする

見出し `y(0) =` と一致する。0 が表示範囲の外なら、0 から表示範囲まで解いて（途中の点は描かない）、範囲の中だけを描く。
初期時刻を変える方法は無い（$y(1) = 2$ を描きたい人は、式を $y(x - 1)$ に書き換えるしかない）。

### 案 B: 初期時刻を独立した欄にする（既定 0）

初期値の欄の上に「初期時刻 $x_0 =$」（連立なら $t_0 =$）の欄を足す。空欄なら 0。式・スライダーの文字を書ける。
見出しは欄の値に合わせる（$x_0 = 1$ なら `y(1) =`・`y′(1) =`。スライダーの文字なら `y(a) =`）。
解き方は案 A と同じ（$t_0$ から表示範囲まで解いて、範囲の中だけ描く）。保存・共有に欄の値を含める。

### 案 C: 今の規則のまま、見出しだけ実際の初期時刻にする

`y(1) =` のように出す。見出しは一致するが、表示範囲を動かすと解が変わる問題は残る（Issue の期待する動作を満たさない）。

## 3. 共通にすること（案 A・B）

- **表示範囲の外の初期時刻**: $t_0$ から表示範囲の端まで解く（範囲の外の点は描かない）。今の上限（1 本 20 万歩・合計 100 万歩、
  状態が表示範囲の 8 倍の箱を出たら止める）はそのまま。表示範囲に届く前に止まったら、説明に
  「初期時刻 x = 0 から x = 1000 まで解く途中、x = 3.2 で値が表示範囲の 8 倍を出たので、表示範囲には描けません」のように出す
- **#132（初期時刻に右辺が定義されない）**: 今と同じく、その初期値は描かずに説明に出す（初期時刻の値で判定）
- **傾きの場**: 初期時刻と関係ないので今のまま

## 4. 決めてもらうこと

1. **案 A・B・C のどれにするか**。おすすめ: **B**。空欄なら A と同じ（0）なので、ほとんどの人には変わらず、
   初期時刻を動かしたい人は欄で明示できる（Issue の「独立した値として明示し、ラベルと一致させる」）
2. **前に保存・共有したグラフ**（初期時刻の欄が無い）。おすすめ: **保存したときの規則で読む**
   （保存した表示範囲に 0 が無ければ、初期時刻 = 範囲の始まり、を欄に入れて開く）。開いたときの絵が今までと同じになる。
   もう 1 つの案は「欄が無ければ 0」（単純だが、0 を含まない範囲で保存したグラフは、開くと別の解になる）
3. **表示範囲に届く前に止まったときの出し方**。おすすめ: 3 章の文を説明に出す（エラーにはしない。今の「発散で止める」と同じ扱い）
4. **欄の名前**。おすすめ: 1 本なら「初期時刻 x₀ =」（横の座標の名前 + ₀）、連立なら「初期時刻 t₀ =」

## 5. 実装の見込み（案 B のとき）

- `web/src/lib/types.ts`: `odeT0?: string` を足す。`ExpressionItem.svelte`: 欄と、見出しを欄の値に合わせる。保存・共有（`odeInit` と同じ所）
- `web/src/lib/plot.worker.ts`: `ode_init` と一緒に初期時刻の式を渡す（スライダーの値で数にする）
- `core/src/lib.rs` の `ode_built`: $t_0$ を受け取り、$t_0 \to$ 範囲の各端まで解いて、範囲の中の点だけを残す（範囲の外から入るときは、境目の点を補間して足す）
- テスト: Issue の表（$[-1, 2]$ と $[1, 2]$ で $x = 2$ の値が同じ）、$x_0 = 1$ の見出しと解、0 が範囲の外のとき、表示範囲に届く前に発散するとき、
  前の保存の読み込み

## 6. 実装（決めたこと）

決めたこと: 1. 案 B（初期時刻の欄。空なら 0）。2. 前の保存データは、保存したときの規則で読む。3. 範囲に届く前に止まったら説明に出す。4. 欄の名前は「初期時刻 x₀ =」（連立なら t₀）。

- 計算エンジン: `ode_start(src, legacy)`（`core/src/lib.rs`）で初期時刻の欄を受け取り、`Ode::t0`（`core/src/equation.rs`）にする。
  `ode_built` は初期時刻から範囲の両端へ（範囲の外なら範囲を通って遠い端まで）解き、範囲の中の点と外側の 1 点ずつだけを描く。
  解いた初期時刻と独立変数の名前を `PlotResult::ode_t0`・`ode_var` で返す
- 画面: `item.ode.t0`（LaTeX）と欄（`ExpressionItem.svelte`）。見出しは、欄の値が数か 1 つの名前ならそれ（`y(1) =`・`y(a) =`）、式なら `y(x₀) =`
- 前の保存データ: 保存データに `odeT0: true` の無いもの。初期時刻の欄が空の式は `odeLegacy` で開き、最初の計算で前の規則の初期時刻を返してもらって欄に入れる（0 なら空欄のまま）
- テスト: `core/tests/stage5.rs` の `ode_initial_time_is_fixed`（Issue の表、x₀ = 1、範囲 [100, 101]、前の保存データ、範囲に届く前の発散、連立）
