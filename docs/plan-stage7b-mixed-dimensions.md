第7段階の前半（2D の陰関数の曲線・陽関数。#140 #142 #158 と、#119・#120・#175・#206 の 2D の分）は実装済み。
ここに残りの Issue と、決めてもらうことをまとめる。実装済み（6 つともおすすめのとおりに決めてもらった。5 章に実装）。

## 1. 前半で直したもの（参考）

- 2D の陰関数を因数に分けてから描く（$|A|$・$\sqrt A$・$A^n$・積・分数）。元の式の零点でない所は切り落とす
- 0 に接するだけの所・点を、区間演算で「本当に 0 になりうるか」確かめてから描く（$(x^2+y^2-1)^2+10^{-7}=0$ は空）
- 格子のマスより小さい閉じた曲線、段差の飛ぶ線の上だけの解（`floor(x) + floor(-x) = 0`）、恒等式の塗り
- 2D の連立方程式の接するだけの交点（`y = cos x, y = 1`）、等号つきの不等式の境目に接する点（`x^2+y^2=1, x≥1`）
- `y = f(x)` の細い山・谷、場合分けで 1 点だけ定義した値（黒丸と白丸）

## 3. 直し方の案と、決めてもらうこと

### 3.1 1 つの式で、面と線・点を一緒に描く（#120・#121）

- **案 A（おすすめ）**: 計算の結果に「添えの線」「添えの点」を足す（今の 2D の不等式の境目の線と同じ作り）。面・領域と同じ色で描く。
  GPU で描くときも、添えの線・点はメッシュで重ねる。#120 は因数ごとに「面」「線だけ」「点だけ」を分けて、面以外を添えに入れる。
  #121 は集合の枝ごとに同じ
- 案 B: 式を自動で何行かに分ける（画面の行が勝手に増えるので分かりにくい）

**決めること 1**: 案 A でよいか。

### 3.2 複素数の陰関数で Re F と Im F が同じ面になるとき（#122）

- **案 A（おすすめ）**: Re F = 0 の面を作り、その頂点で |Im F| がほぼ 0（まわりの値の 10⁻⁶ 倍以下）なら、その部分は「面の解」として描く。
  Im F = 0 の面でも同じ。どちらも当てはまらない所は今までどおり交わりの曲線。
  `iF = 0`（Re F ≡ 0）・`F + iF = 0`（定数倍）・`F + iF² = 0`（Im F が Re F = 0 の上で 0）が全部入る
- 数値で決めきれない（|Im F| が小さいが 0 とは言えない）ときは、説明に「Re F と Im F がほぼ同じ面になる所は、面として描いた（近似）」と出す

**決めること 2**: 案 A でよいか。

### 3.3 格子より薄い領域（#143）

- **案 A（おすすめ）**: 不等式ごとの境目の面（$x^2+y^2+z^2 = 1$ と $= 1.0001$）を別々に作り、ほかの不等式で切る（2D の領域の境目の線と同じ）。
  2 枚がほとんど重なって見えるので、説明に「（厚さ約 5×10⁻⁵。格子より薄い）」と出す
- 案 B: 1 枚だけ描き、説明に薄いことを出す（Issue の「片面だけを出す場合にも薄さの情報を保持」）

**決めること 3**: 案 A（2 枚とも描く）か、案 B（1 枚と説明）か。

### 3.4 3D の連立方程式の、接する解・従属な式（#119・#206）

決めることは無い（正しい答えが決まっている）。やり方:

- 従属な式: 2 本目の式が 1 本目の面の上でほぼ 0 なら（頂点で |F₂| ≤ 10⁻⁶ × まわり）、面そのものが解。恒等式（`z = z`）は除く
- 接する点・接する線: 1 本目の面の上で、|F₂| が符号を変えずに 0 に触れる所を、2D の前半と同じ「極小を詰めて区間演算で確かめる」やり方で探す
  （点なら点、面の上の線（赤道の円）なら線）。等号つきの不等式の境目に接する点（`z ≥ 1`）も同じ

### 3.5 段差の飛ぶ面の上だけの解（#175 の残り）

- 3D: 前半の 2D と同じく、飛ぶ面 $s = k$ の上で段差を固定した式が 0 になる所を描く
- GPU: 画素の中で面積 0 の線は塗れない。**案 A（おすすめ）**: GPU で描くときも、飛ぶ線・面の上の解はメッシュで重ねる（3.1 の添えの線と同じ）。
  案 B: こういう式は自動でメッシュに切り替える（今の「自動」の判断に加える）

**決めること 4**: 案 A か案 B か。

### 3.6 定義域の外で、途中だけ複素数になる式（#206 の `sqrt(x)=sqrt(x)`）

今の計算エンジンは、途中の値が複素数でも、最後の値が実数なら描く（`y = \sqrt{x}^2` は $x < 0$ でも $y = x$ を描く）。
そのため `sqrt(x) = sqrt(x)` は、前半の変更で平面全体を塗る（Issue の期待は $x \ge 0$ の半平面）。

- **案 A（おすすめ）**: 今の決まり（最後の値が実数なら描く）のまま。説明文に書く。式全体の決まりを変えると、ほかの式の見た目が広く変わる
- 案 B: 陰関数・不等式だけ、途中で実数でなくなる点を「定義されない」とする（`y = \sqrt{x}^2` と食い違う）

**決めること 5**: 案 A か案 B か。

### 3.7 面積・体積のある解（参考。前半で見つけた）

`floor(x) + floor(y) = 0` の解は、正方形の集まり（面積がある）。今は境目の線を描いている。段差の枝ごとに、枝を固定した式が恒等的に 0 なら
その枝の範囲を塗る、で直せる。Issue は無いので、3.5 と一緒にやるか決めてほしい。

**決めること 6**: 一緒にやるか。おすすめ: やる（3.5 と同じ仕組みの上でできる）

## 5. 実装（決めたこと）

決めたこと: 1. 添えの線・点（案 A）。2. Re F・Im F が同じ面なら面（案 A）。3. 薄い領域は 2 枚とも描き、説明に厚さ（案 A）。
4. GPU でも飛ぶ線はメッシュで重ねる（案 A。3D の光線は、その式だけメッシュにする）。5. 途中だけ複素数になる式は今の決まりのまま（案 A）。
6. 面積のある解も塗る。

- 添えの線・点: `MeshResult::extra`（`take_extra`・`take_extra_target`）。描画側は式の色の線と点の球で、GPU で描く式でも隠さない
  （`Viewer.ts` の `extras`）。添えのある式は、回転だけ変わったときの射影し直しを使わない
- #134: 平方の和の判定で、定数の項の和が 0 なら認める（`nonneg_terms`）
- #120: `Program::lower_dim_parts`（面の因数と混ざる、平方の和の因数）を `common_zero_sets` で描いて添えに
- #121: 集合の像の、面積の無い枝（点・線。2D の陰関数の点を含む）を添えに
- #122: Re F = 0（Im F = 0）の面の頂点を面の上へ寄せ、もう片方がどこでも 10⁻⁷ × 最大 以下なら面（`system::vanishes_on`）。2D は曲線
- #143: 領域の面を切るとき、頂点を自分の面の上へ寄せてから、ずらす量 10⁻³・10⁻⁵・10⁻⁷ マスのどれかで中なら中。重なる面を消すのは、
  寄せた点で他方の面からの距離が 10⁻⁹ マス以下のときだけ。厚さ（境目どうしの距離の中央値）がマスの 1/10 より薄ければ説明に出す
- #119・#206: `system::touching_points`・`touching_mesh`（谷の頂点からガウス・ニュートン法、区間演算で確かめる）、`vanishes_on`（同じ面）
- #175: `mesh::jump_surfaces`（3D）、2D の飛ぶ線は添えに。面積のある解は `mesh::branch_regions_2d`（3D の面積・体積のある枝は、まだ塗らない）
