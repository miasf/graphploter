# S20 の残りの課題（やり直し用）

S20（段差の交わる所の針をなくし、低い段差も切り分ける。コミット `d75f9c2`）の後に残った課題。
計画の完了の条件はすべて満たしているが、完了の条件に無い式で悪くなった数字や、確かめていない所がある。
指示書は `docs/plan-hard-tasks.md` の S20。全ステップ共通の決まり（7.3 の後の箇条書き）も同じく守る。

数字は `shape_report`（7.1 と同じ設定: $x, y \in [-10, 10]$、$z \in [-6.4, 6.4]$、細かさ 150、$128^3$ 箱）の S20 前 → S20 後。

## 1. `nCr(x, y)` の破片が増えた（優先度: 高）

| 回転 | 破片 | 余計1 | 欠け1 |
|---|---|---|---|
| なし | 1 → **45** | 7.81 → 7.94 | 0.00 → 0.00 |
| $zw$ 0.6 | 1 → **45** | 8.04 → 8.19 | 0.00 → 0.00 |
| 混ぜた回転 | 0 → 1 | 3.58 → 4.58 | 0.00 → 0.00 |

- 推測: 極が並ぶ所で、前は描かなかった「3 辺とも飛ぶ三角形」の角の三角形（頂点ごとに、その頂点の側の値で描く。S20 で計画から外した所）を描くようになったため。**原因は確かめていない**
- やること: 破片になっている三角形がどの描き方（角の三角形・1 辺だけ飛ぶ・細分で増えた所）から出たかを数えて原因を決める。
  角の三角形なら、例えば「隣の三角形とつながらない角は描かない」「値が極に近い（$|\hat h|$ が表示範囲の外）角は描かない」などを試す
- 条件の目安: 破片 ≤ 2（S20 前と同じくらい）、余計と欠けは今より悪くしない。`round(x) round(y) / 8` の余計 0% を崩さない

## 2. 回した式で、余計が増えたもの（優先度: 中）

| 式 | 回転 | 余計1 | 欠け1 |
|---|---|---|---|
| `gamma(x) / 5 + y/5` | $xw$ 0.6 | 0.00 → **18.95** | 14.29 → 0.00 |
| `gamma(x) / 5 + y/5` | $xy$ 0.5 | 11.29 → **22.12** | 8.91 → 0.03 |
| `gamma(x) / 5 + y/5` | $xz$ 0.4 | 11.31 → **24.34** | 7.79 → 0.12 |
| `nCr(x, y)` | $xy$ 0.5 | 3.36 → 7.15 | 0.26 → 0.08 |
| `nCr(x, y)/nCr(y, x)` | $xy$ 0.5 | 3.30 → 8.62 | 24.73 → 23.56 |
| `nPr(x, y)/10` | $xy$ 0.5 | 6.91 → 13.72 | 19.37 → 17.39 |
| `nPr(x, y)/10` | $xz$ 0.4 | 4.71 → 10.09 | 15.46 → 13.63 |
| `nCr(floor(x), floor(y))/10` | 混ぜた回転 | 0.17 → 1.26 | 0.00 → 0.00 |

- `gamma` については、S20 の報告で「左の極（$x \approx -7$）の本当の壁の幅は $|x + 7| < 7 \times 10^{-6}$ しかなく、正解（物差し）の側が細かさ不足で捉えられていない」と説明した。
  **これは推測で、確かめていない**。確かめ方: 余計の箱の位置を出し、それが極の近く（$x$ が負の整数の近く）だけにあるかを見る。
  極の近くだけなら物差しの限界として README か計画 7.4 に書く。それ以外の所にもあればメッシュの誤りなので直す
- `nCr`・`nPr` の回転での余計の増え方は、まだ何も調べていない。同じく余計の箱の位置から始める
- 回転なしの `nCr(x, y)/nCr(y, x)`（54.25 → 17.99）、`nPr(x, y)/10`（34.37 → 19.29）は良くなっているので、悪くなるのは回したときだけ

## 3. $xw$ の `3 sin(1/x)` の欠けが増えた（優先度: 低。S21 で扱う）

- 欠け1: 5.26 → **8.70**（$xw$ 0.6）
- S20 の報告での説明: 前は極 $x = 0$ が格子点にちょうど乗って値が定義されず、その周りが細かくされていたので偶然埋まっていた。
  S20 で計算する範囲を幅の $10^{-7}$ ほど内側に縮めたので、その偶然が消えた
- 格子より細かい振動は S21（区間演算で見つけて細かくする）の範囲。S21 の完了の条件にこの式が入っているかを確かめ、入っていなければ足す

## 4. 細分が増えた式の時間（優先度: 中）

ベンチマークの条件（`sin(x) cos(y)` 0.77 倍、`x^2 - y^2` 0.69 倍、`floor(x) + floor(y)` 1.68 倍）は満たしたが、条件に無い式で 2〜3 倍になったものがある（`shape_report` の ms）。

| 式 | 回転 | ms |
|---|---|---|
| `floor(x) + floor(y)` | なし | 14 → 35（ベンチマークでは 1.68 倍） |
| `round(x) round(y) / 8` | 混ぜた回転 | 37 → 111 |
| `round(x) round(y) / 8` | $xy$ 0.5 | 72 → 147 |
| `gamma(x) / 5 + y/5` | $xz$ 0.4 | 147 → 370 |
| `ln(x y)` | $xz$ 0.4 | 46 → 123 |
| `nCr(x, y)` | 混ぜた回転 | 403 → 682 |
| `nCr(x, y)/nCr(y, x)` | $xz$ 0.4 | 766 → 1098 |

- `shape_report` の ms は他の計測と並行で回した時のものが混じっているので、まず CPU が空いている時に測り直す
- それでも 2 倍を超えるなら、どの処理（交わる所の細分の 5 回の繰り返し・しきい値を $0.005\,h$ に下げて増えた段差の候補・中点の値の計算）に時間を使っているかを測る。
  特に `ln(x y)` には段差が無いのに 2.7 倍になっているので、なめらかな所で候補が外れていない疑いがある（1 回目・2 回目の二分の中点による外し方の条件を確かめる）

## 5. 計画から外れた所の見直し（優先度: 中）

S20 では次の 3 点で計画と違うことをした。どれも理由はあるが、他の式への影響を全部は見ていない。

1. **段差とみなす条件**を「12 回二分しても差が半分より多く残る」→「0.3 倍より多く残る」に緩めた（1 本の辺が段差を 2 つまたぐと、残る差がちょうど半分になるため）。
   見つけた段差の残りの側に、もう 1 つ段差がありそうかも調べる（`Jump::multi`）。
   → 急でなめらかな所（`tan(x + y)`、`1/(x y)` の極の近く、`x^y / 10`）を段差と間違えていないか確かめる。
   テストを足す: なめらかで急な式で、段差（壁）が 1 つも出ないこと
2. **3 辺とも飛ぶ三角形**を、計画の「切らずにそのまま描く」ではなく「頂点ごとに角の三角形を描き、真ん中の約 1/4 は描かない」にした。
   → 値が細かく暴れる所に穴が空かないか（計画がそのまま描くとした理由）。`complex_pole_has_no_holes` 以外に、
   `3 sin(10/(x^2+y^2+0.1))` の中心のような所で、欠けが増えていないことを確かめる。上の 1 の破片もここから来ている疑いがある
3. **陽関数の計算する範囲を、幅の $10^{-7}$ ほど内側に縮めた**（下端と上端で量を変える）。格子点が 0 や整数にちょうど乗ると、$\operatorname{sign}(0) = 0$ や $\lfloor 10 \rfloor = 10$ の幅の無い帯を描いていたため。
   → 縮めたことで、範囲の端の頂点の値が端の値とわずかにずれる。表示範囲の端のふた（S16）・範囲で重ねた立体・2D の切り口・回した陽関数の傾いた座標系（S19）で、継ぎ目や隙間が出ていないか確かめる

## 6. 見た目で確かめていない所（優先度: 高）

- S19 の後、ユーザーのスクリーンショット（$xw$ を $-180^\circ$ に回した `floor(x) + floor(y)`、壁あり）で
  **壁の端の白い細い三角形** と **段の角の白い穴** が見つかり、S20 で直す予定だった。
  S20 の報告は物差しの数字だけで、**ブラウザで同じ条件を描いて消えたかを見ていない**
- やること: Playwright で、回転なしと $xw = -180^\circ$ の `floor(x) + floor(y)`（壁あり）、`round(x) round(y) / 8`、`2 sign(sin(x) sin(y))` を拡大して撮り、白い三角形・穴・針が無いことを確かめる。
  `nCr(x, y)` の破片（上の 1）もついでに撮る
- 白い穴が残っていたら、角の三角形（5 の 2）と壁のつながり（壁が段差の線の端で止まっていないか）を疑う

## 7. ときどき落ちるテスト（優先度: 低）

- `field_split_matches_whole`（陰関数）が 1 回だけ落ちた。重い計測を並行で回していた時で、その後 3 回続けて通った。原因は確かめていない
- S20 は陰関数を触っていないので無関係の見込みだが、時間で打ち切る処理や、Worker・スレッドの分け方で結果が変わる所が無いかを読む。
  負荷をかけて（`stress` や他のテストと並行で）20 回ほど回し、再現するかを見る
