# G0: 陰関数を光線で描く速さ（計画 12 章）

`g0.html` は、計画 `docs/plan-hard-tasks.md` 12.4 の G0 の測定ページ。アプリとは別の単独のページで、WebGL2 だけで書いてある（three.js を通さないので、光線の計算そのものの時間が出る）。

- 6 式（球・`sin(x) = cos(y) z`・`tan(x) = z y`・`floor(x y) = z floor(z)`・`mod(x y, z) = 1`・ジャイロイド）を、決まった歩幅で進めて符号が変わったら 10 回二分する素朴な光線で描く
- 1280 × 720 と 1920 × 1080、歩数 128・256・512 で、1 コマの時間を測る（`EXT_disjoint_timer_query_webgl2` があれば GPU の時間、無ければ 1 画素読んで描き終わりを待つ時間）
- 判断: 歩数 256・1280 × 720 で、最も遅い式が 50 ms を超えるか（計画 G0 の判断の分かれ目）

ファイルは Artifact（claude.ai の公開ページ）の形式で、`<!doctype>`・`<head>` を書いていない。手元で開くときは、そのままブラウザで開けばよい（互換モードになるが動く）。

この環境（GPU なし。SwiftShader）での参考値: 1280 × 720・歩数 128 で 107〜173 ms。実機の数字ではない。
